## 5. 공통 규칙 (모든 개발 세션)

1. 지시서와 `V01` 만 보고 구현한다. **지시서에 없는 기능은 넣지 않는다**
2. **소유 파일만 수정한다.** 남의 파일을 고쳐야 하면 고치지 말고 「전달 요청」으로 남긴다
3. 수치를 코드에 직접 쓰지 않는다. 전부 ScriptableObject(`V01` 4장)에서 읽는다
4. 옛 `UnityEngine.Input` 금지 — 이 프로젝트는 `activeInputHandler: 1`(Input System 전용)이다
5. 커밋·푸시는 사람이 `/finish` 할 때만 한다
6. 끝나면 ① 완료 체크리스트 결과 ② 사람이 직접 봐야 할 것 ③ 전달 요청 을 출력한다

## 6. 전달 요청 형식

받는 세션은 이 작업의 맥락을 모른다. **요청 하나하나가 그것만 읽고도 실행 가능한 문단**이어야 한다. R1\~R6 전부 적고, 없으면 "없음".

```
## 전달 요청

### → R1 기획
**[차단] L03 머지 표 4번 행이 GridModel 상태와 어긋난다**
- 위치 : `05_Docs/WorkOrders/L03_머지판정.md` 완료 체크리스트 3번
- 현재 : …
- 문제 : …
- 요청 : …
- 근거 : `Assets/02_Scripts/Core/Grid/MergeRule.cs:42`
- 출처 : L03 작업 완료 시점

### → R2 코어
없음
### → R3 클라
없음
### → R4 연출
없음
### → R5 아트
없음
### → R6 성능
없음
```

- **\[차단\]** 처리 전에는 다음 작업 불가 / **\[일반\]** 나중에 처리해도 됨
- 규칙 · 수치 자체를 바꾸는 요청은 무조건 **R1**. 개발 세션이 규칙을 정하지 않는다
- 받을 세션이 아직 차례가 아니면 R1 이 `05_Docs/_전달요청_보류함.md` 에 옮겨 적고, 그 세션 차례에 지시서에 녹인다
