# Quarantine Line — 게임 시스템 기획서

Nov 10, 2026 · @진

## 개요

**컨셉 기획서의 규칙을 구현 가능한 수준의 시스템 · 수치 · 데이터 구조로 정리한 문서다.** 개발 중 판단이 필요할 때 이 문서를 기준으로 한다.

- 플랫폼: PC (Windows), 16:9 가로, 마우스 조작, 3D 고정 쿼터뷰
- 용어: 드론 = 플레이어 유닛, 점액 = 적, 격리 해치 = 지켜야 할 방어선
- 단위: 거리 = 칸, 시간 = 초, 재화 = 코인
- 모든 수치는 **초기값**이며, ScriptableObject에서 플레이 테스트로 조정한다
- 연출(DOTween)은 컨셉 기획서를 따르고, 이 문서는 규칙과 데이터만 다룬다

## 시스템 구성도

&#91;embedded content: 시스템 구성도 · 8개 시스템\]

그리드 · 머지가 핵심이다. 모든 시스템의 수치는 ScriptableObject(데이터 구조 절)에서 읽고, 시스템 사이는 이벤트로 연결해 서로 직접 참조하지 않는다.

## 게임 상태 흐름

&#91;embedded content: 게임 상태 흐름 · 5개 상태\]

패배는 웨이브 진행 중에만 일어난다. 소환 · 머지는 준비와 웨이브 진행 두 상태에서 모두 가능하다.

## 그리드 · 배치

**해치 앞 바닥에 5레인 × 3줄, 총 15칸. 레인 번호가 곧 드론의 공격 레인이다.** 칸은 3D 바닥 위의 타일이며, 마우스 위치는 화면 → 바닥 평면 레이캐스트로 칸을 찾는다.

| 칸 상태 | 의미 | 소환 | 드롭 |
| --- | --- | --- | --- |
| Empty | 비어 있음 | 가능 | 이동 |
| Occupied | 드론 있음 | 불가 | 머지 또는 교체 |
| Contaminated | 점액 오염 (선택 기능) | 불가 | 머지면 청소, 아니면 거부 |

**드래그 규칙**

1. 드론을 클릭한 채 끌면 바닥 위로 떠오르고, 원래 칸은 비지 않은 상태로 유지한다 (드래그 중 그 칸에 소환 불가)
2. 드래그 중에도 웨이브는 진행되며, 집어 든 드론은 공격하지 않는다
3. 그리드 밖이나 같은 칸에 놓으면 원래 칸으로 돌아간다
4. 놓은 칸에 따라 이동 · 머지 · 교체 중 하나가 일어난다 (머지 절 참고)
5. 우클릭 또는 Esc로 드래그를 취소할 수 있다

## 소환

**소환 버튼(또는 Space)을 누르면 코인을 내고 빈 칸 중 무작위 한 곳에 1등급 드론이 투입된다.** 종류(흡입 · 소각 · 냉각)는 같은 확률(각 1/3)로 고른다.

```latex
\text{cost}_n = 30 + 5 \cdot n
```

n = 지금까지 소환한 횟수(0부터). 머지로 사라진 드론은 n을 줄이지 않는다.

| 조건 | 결과 |
| --- | --- |
| 코인 ≥ 비용, 빈 칸 있음 | 소환 |
| 코인 부족 | 버튼 비활성, 비용 숫자 빨강 |
| 빈 칸 없음 | 버튼 비활성, "칸이 가득 찼습니다" |

웨이브 진행 중 · 준비 시간 모두 소환할 수 있다.

## 머지

**드롭한 칸에 따라 아래 순서로 판정한다. 먼저 맞는 규칙 하나만 적용한다.**

| 순서 | 놓은 칸 | 조건 | 결과 |
| --- | --- | --- | --- |
| 1 | Empty | — | 드론이 그 칸으로 이동 |
| 2 | Occupied | 같은 종류 · 같은 등급 · 등급 < 3 | **머지**: 놓은 칸에 등급 +1 드론 1대, 원래 칸은 Empty |
| 3 | Occupied | 그 외 (종류 다름, 등급 다름, 둘 다 3등급) | **교체**: 두 드론 위치를 바꿈 |
| 4 | Contaminated | 같은 종류 · 같은 등급 드론이 있음 | 머지 + 청소 |
| 5 | Contaminated | 그 외 | 거부, 원래 칸으로 복귀 |

- 머지 결과 드론의 공격 쿨다운은 0부터 다시 시작한다
- 머지는 코인을 쓰지 않는다
- 머지 판정 로직은 순수 C# 클래스(MergeRule)에 두고, 뷰는 결과만 받아 3D 모델 교체와 연출을 한다

## 유닛 전투

**드론은 자기 레인에서 사거리 안에 있는 점액 중 해치에 가장 가까운 점액을 자동 공격한다.** 사거리는 드론 칸부터 먼 쪽으로 센다.

| 드론 | 공격 타입 | 등급 | 피해 | 간격 (초) | 사거리 (칸) | 특수 |
| --- | --- | --- | --- | --- | --- | --- |
| 흡입 드론 | 단일 흡입 빔 | 1 | 10 | 0.5 | 6 | — |
| 흡입 드론 | 단일 흡입 빔 | 2 | 22 | 0.4 | 6 | — |
| 흡입 드론 | 단일 흡입 빔 | 3 | 45 | 0.35 | 6 | 관통: 같은 레인 2마리 |
| 플라즈마 소각 드론 | 부채꼴 범위 | 1 | 6 | 0.6 | 3 | 자기 레인만 |
| 플라즈마 소각 드론 | 부채꼴 범위 | 2 | 12 | 0.6 | 3 | 양옆 레인까지 |
| 플라즈마 소각 드론 | 부채꼴 범위 | 3 | 25 | 0.6 | 3 | 양옆 레인 + 잔열 초당 5, 2초 |
| 냉각 분사 드론 | 단일 + 감속 | 1 | 4 | 0.8 | 5 | 감속 30%, 1.5초 |
| 냉각 분사 드론 | 단일 + 감속 | 2 | 8 | 0.8 | 5 | 감속 45%, 1.5초 |
| 냉각 분사 드론 | 단일 + 감속 | 3 | 15 | 0.8 | 5 | 4초마다 반경 1.5칸 빙결 1초 |

- 감속은 중첩하지 않고 가장 강한 값 하나만 적용, 지속 시간은 갱신
- 공격 방식은 IAttack 인터페이스로 분리 (SingleBeam, Cone, Slow) — 새 드론 = 구현체 1개 + UnitData 1개

## 적 · 웨이브

**점액은 화물칸 쪽 먼 끝의 스폰 지점에서 무작위 레인으로 나와 직선으로 다가온다. 스폰 지점부터 해치까지 10칸.** 레인을 바꾸지 않는다.

| 점액 | 체력 | 속도 (칸/초) | 해치 피해 | 처치 보상 |
| --- | --- | --- | --- | --- |
| 점액 덩어리 | 40 | 1.2 | 1 | 5 코인 |
| 변이 점액 | 300 | 0.5 | 3 | 20 코인 |

| 웨이브 | 점액 덩어리 | 변이 점액 | 스폰 간격 (초) | 변이 점액 등장 |
| --- | --- | --- | --- | --- |
| 1 | 15 | 0 | 1.0 | — |
| 2 | 25 | 3 | 0.8 | 웨이브 후반 1/3 |
| 3 | 60 | 8 | 0.4 | 전체에 고르게 |

- 웨이브 사이 준비 시간 5초, 첫 웨이브 전 준비 시간 8초
- 웨이브 종료 = 그 웨이브의 점액이 모두 제거되거나 해치에 도달함
- 점액 · 투사체 · 데미지 숫자는 모두 오브젝트 풀에서 꺼내고 반납한다 (3웨이브 동시 존재 최대 수십 마리 기준으로 미리 생성)
- 같은 종류의 점액은 머티리얼을 공유하고 GPU 인스턴싱으로 그린다

## 경제

**재화는 코인 하나. 시작 120코인으로 1등급 드론 3대(30 + 35 + 40)를 소환할 수 있다.** 코인은 웨이브 사이에 이월된다.

| 구분 | 항목 | 코인 |
| --- | --- | --- |
| 획득 | 시작 코인 | 120 |
| 획득 | 점액 덩어리 제거 | 5 |
| 획득 | 변이 점액 제거 | 20 |
| 획득 | 웨이브 클리어 보너스 | 50 |
| 획득 | 오염 칸 청소 (선택 기능) | 10 |
| 소비 | 소환 | 30 + 5 × 소환 횟수 |

코인이 바뀔 때만 이벤트(OnCoinChanged)로 HUD를 갱신한다. 매 프레임 텍스트를 다시 만들지 않는다.

## 격리 해치 · 승패

**격리 해치 HP 20. 점액이 해치에 닿으면 그 점액의 해치 피해만큼 HP가 줄고, 점액은 사라진다(보상 없음).**

| 판정 | 조건 | 결과 |
| --- | --- | --- |
| 패배 | 해치 HP ≤ 0 | 즉시 게임 정지, 패배 화면 |
| 승리 | 3웨이브 종료 시 HP > 0 | 승리 화면 |
| 위기 경고 | HP ≤ 5 | 해치 경고등 붉게 점멸, HUD HP 강조 |

결과 화면: 남은 해치 HP, 제거한 점액 수, 최고 등급 드론 수, 다시 하기 버튼. HP는 웨이브 사이에 회복하지 않는다.

## UI 시스템

**화면 4개, HUD 요소 5개. 모든 UI는 값이 바뀔 때만 이벤트로 갱신하고, 모든 입력에 0.1초 안에 시각 반응을 준다.**

| 화면 | 들어가는 조건 | 구성 |
| --- | --- | --- |
| 타이틀 | 실행 | 게임 제목, 시작 버튼, 해상도 · 창 모드 설정 |
| 인게임 | 시작 버튼 | HUD, 3D 무대 · 그리드, 소환 버튼, 일시정지 버튼 |
| 일시정지 | 일시정지 버튼 또는 Esc | 계속하기, 다시 하기 (게임 시간 정지) |
| 결과 | 승리 · 패배 | 승패 문구, 남은 HP, 제거 수, 최고 등급 드론 수, 다시 하기 |

| HUD 요소 | 표시 | 갱신 조건 | 연출 |
| --- | --- | --- | --- |
| 웨이브 | 2 / 3 | 웨이브 시작 | 홀로그램 배너 진입 |
| 남은 점액 | 숫자 | 점액 제거 · 도달 | 줄어들 때 펀치 |
| 해치 HP | 게이지 + 숫자 | 피해 | 흔들림, HP ≤ 5면 붉게 점멸 |
| 코인 | 숫자 | 획득 · 소비 | 숫자 굴러감 (DOCounter) |
| 준비 시간 | 초 카운트다운 | 준비 상태 1초마다 | 3초부터 크게 |

| 입력 | 상태 | 시각 피드백 |
| --- | --- | --- |
| 소환 버튼 | 가능 / 코인 부족 / 칸 없음 | 기본 / 비용 빨강 + 흔들림 / 회색 + 안내 문구 |
| 드론 위 마우스 호버 | 집을 수 있음 | 외곽선 강조, 사거리 레인 미리보기 |
| 드론 집기 | 드래그 시작 | 바닥 위로 떠오름, 원래 칸 반투명 표시 |
| 드래그 중 칸 위 | 머지 가능 / 이동 / 교체 / 불가 | 초록 / 흰 / 노랑 / 빨강 바닥 하이라이트 |
| 놓기 | 결과에 따라 | 머지 펀치 · 이동 · 위치 교환 · 원위치 복귀 |

UI 텍스트는 TextMeshPro 무할당 포맷(SetText)으로 갱신하고, 매 프레임 문자열을 만들지 않는다.

## 오염 · 청소 (선택 기능)

**점액이 해치에 닿을 때마다, 그 점액이 지나온 레인의 칸 하나가 5초간 점액으로 오염된다.** 6일차에 품질 기준을 모두 통과했을 때만 구현한다.

| 규칙 | 값 |
| --- | --- |
| 오염 대상 | 해당 레인에서 아직 오염되지 않은 칸 중 무작위 1칸 (레인 전체가 오염됐으면 무시) |
| 오염 시간 | 5초, 이미 오염된 칸은 시간만 다시 5초로 |
| 오염 칸 드론 | 점액에 엉겨 공격 정지, 드래그로 꺼낼 수는 있음 |
| 오염 칸 소환 | 불가 |
| 청소 | 오염 칸 위에서 머지 성공 시 즉시 청소 + 10코인 |
| 자연 청소 | 5초 경과 (점액이 마름) |

오염 칸에 "지나온 레인"을 쓰는 이유: 플레이어가 어느 레인이 약한지 바로 알 수 있게 하기 위해서다.

## 데이터 구조

**수치는 전부 ScriptableObject 4종에 둔다. 코드에는 숫자를 직접 쓰지 않는다.**

| SO | 필드 | 개수 |
| --- | --- | --- |
| UnitData | droneType, grade, damage, attackInterval, range, attackKind, slowRate, slowDuration, special, prefab, tintColor | 9 (3종 × 3등급) |
| EnemyData | slimeType, maxHp, moveSpeed, hatchDamage, reward, prefab, scale | 2 |
| WaveData | waves\[\] → { entries\[\] → { slime, count, spawnInterval, startRatio }, prepTime, clearBonus } | 1 |
| GameConfig | laneCount, rowCount, pathLength, hatchMaxHp, startCoin, summonBaseCost, summonCostStep, contaminateDuration, cleanReward | 1 |

- startRatio: 그 점액이 웨이브의 어느 지점부터 나오는지 (0 = 처음, 0.66 = 후반 1/3)
- 머지 결과는 (droneType, grade + 1)로 UnitData를 찾는다 — 별도 머지 테이블 없음
- 등급 차이는 같은 프리팹에 tintColor와 부품 표시로 표현해 에셋 수를 줄인다

## 콘텐츠 추가 · 개발 툴

**새 콘텐츠는 코드 수정 없이 데이터로 추가한다. 기획자가 혼자 웨이브를 만들고 밸런스를 확인할 수 있게 한다.**

| 추가할 것 | 절차 | 코드 수정 |
| --- | --- | --- |
| 새 웨이브 | WaveData에 항목 추가 | 없음 |
| 새 점액 | EnemyData 1개 + 프리팹 | 없음 |
| 기존 공격 방식의 새 드론 | UnitData 3개(등급별) + 프리팹 | 없음 |
| 새 공격 방식의 드론 | IAttack 구현체 1개 + UnitData 3개 | 클래스 1개 추가, 기존 코드 무수정 |

**웨이브 미리보기 (에디터 툴)** — WaveData 인스펙터에서 웨이브별 총 적 체력, 총 보상 코인, 마지막 적 스폰까지 걸리는 시간을 자동으로 계산해 보여준다. 수치를 바꾸면 바로 다시 계산된다.

**디버그 패널 (F1)** — 웨이브 건너뛰기, 코인 추가, 무적 해치, 현재 점액 수 · 드로우콜 · FPS · 프레임당 GC 할당 표시. 시연 빌드에서는 빠진다.

## 예외 처리

**동시에 일어나거나 경계에 걸리는 상황은 아래 규칙으로 고정한다.**

| 상황 | 규칙 |
| --- | --- |
| 마지막 점액 제거와 해치 HP 0이 같은 프레임 | 패배 우선 |
| 드론을 드래그하는 중 게임 종료 | 드래그 취소, 원래 칸으로 복귀 후 결과 화면 |
| 드래그 중 원래 칸이 오염됨 | 드롭 결과대로 처리, 복귀 시 오염 칸으로 돌아가 공격 정지 |
| 투사체 · 빔 진행 중 대상 사망 | 투사체 즉시 풀로 반납, 피해 없음 |
| 같은 점액에 여러 드론이 동시 공격해 과잉 피해 | 허용 (예측 타겟팅 안 함) |
| 소환 버튼 연타 · Space 연타 | 한 프레임에 1회만 처리, 비용은 소환 직후 갱신 |
| 머지 대상이 머지 연출 재생 중 | 연출 중 칸은 드롭 불가 (연출 0.3초) |
| 웨이브 준비 시간에 모든 칸이 가득 참 | 정상 진행, 머지로 칸 확보 유도 |
| 드래그 중 창이 포커스를 잃음 (Alt+Tab) | 드래그 취소, 원래 칸으로 복귀 |
