# Quarantine Line — 업무 지원 카드 시스템 기획서

Nov 12, 2026 · @진

## 개요

**웨이브 1 · 2를 막을 때마다 "업무 지원 카드" 3장 중 1장을 골라, 그 판이 끝날 때까지 부대를 강하게 만든다.** 머지가 드론 하나를 키우는 성장이라면, 지원 카드는 부대 전체의 방향을 정하는 성장이다.

| 항목 | 내용 |
| --- | --- |
| 목적 | 한 판 안에서 강해지는 것을 눈으로 체감 + 판마다 다른 전략 |
| 횟수 | 한 판에 2번 (웨이브 1 클리어, 웨이브 2 클리어). 웨이브 3 클리어는 결과 화면으로 가므로 없음 |
| 지속 | 고른 카드는 그 판이 끝날 때까지 유지, 다음 판에는 초기화 |
| 카드 수 | 기본 13장 + 사원 승진 시 3장 추가 (총 16장). 이름은 모두 회사 업무 용어 |
| 세계관 | 카드 = 본사에 올리는 "지원 신청서". 고르면 "승인" 도장이 찍힌다 |
| 범위 밖 | 영구 강화(장비 연구소)는 별도 시스템. 단, 같은 보정값 구조를 쓰도록 설계한다 |

모든 수치는 초기값이며 플레이 로그로 조정한다. 기본 수치(드론 · 점액 · 경제)는 게임 시스템 기획서를 따른다.

## 흐름

&#91;embedded content: 웨이브 사이 흐름 · 업무 지원 선택 위치\]

웨이브를 막으면 수당 영수증 → 업무 지원 선택 → 작업 지시서 순서로 서류 연출이 이어진다. 선택이 끝날 때까지 준비 시간은 시작하지 않는다.

## 카드 목록

**기본 13장은 공격 5 · 경제 4 · 방어 2 · 유틸 2로 나뉘고, 사원 승진 때 유틸 카드 3장이 더해진다.** 어느 카드도 혼자서 판을 끝내지 못하게, 효과 크기를 비슷하게 맞춘다.

| 번호 | 카드 | 분류 | 효과 | 종류 | 최대 중첩 |
| --- | --- | --- | --- | --- | --- |
| C01 | 흡입 노즐 교체 | 공격 | 흡입 드론 공격력 +20% | 지속 | 2 |

**효과 종류**

- 지속: 고른 순간부터 판이 끝날 때까지 적용. 이미 배치된 드론, 나중에 소환 · 머지된 드론 모두 적용
- 횟수형: 정해진 횟수를 다 쓰면 사라짐. 남은 횟수를 HUD에 표시
- 즉시: 고르는 순간 한 번 적용하고 끝

**효과 크기 비교 (코인 환산, 웨이브 1 클리어 때 고른 경우)**

| 카드 | 가치 |
| --- | --- |
| C06 성과급 선지급 | 60 코인 즉시 (소환 약 1.5회) |
| C05 사내 할인 | 15 × 3 = 45 코인, 대신 빠르게 투자 가능 |
| C07 청소 수당 인상 | 웨이브 2 · 3 점액 96마리 × 1 = 약 96 코인, 대신 늦게 들어옴 |
| C11 결합 장려금 | 머지 8\~12회 × 5 = 40\~60 코인, 머지를 많이 할수록 이득 |

경제 카드는 총액이 비슷하고 들어오는 시점만 다르다. "지금 급한가, 나중을 보는가"가 선택의 기준이 된다.

## 뽑기 규칙

**해금된 카드 중 쓸모 있는 것만 남기고, 서로 다른 카드 3장을 뽑되 분류가 최소 2가지 섞이게 한다.**

1. **후보 만들기** — 해금된 카드 전부(기본 13장, 사원 이상이면 16장)
2. **제외** — 아래 제외 조건에 해당하는 카드를 뺀다
3. **가중치 조정** — 아래 가중치 표대로 나올 확률을 바꾼다
4. **3장 뽑기** — 같은 카드는 한 번만. 3장이 모두 같은 분류면 마지막 장을 다른 분류에서 다시 뽑는다
5. **후보가 3장 미만이면** — 있는 만큼만 보여주고, 0장이면 선택 화면을 건너뛴다 (사실상 일어나지 않음)

**제외 조건**

| 조건 | 빠지는 카드 |
| --- | --- |
| 이미 최대 중첩만큼 고름 | 해당 카드 |
| 해치 HP가 가득 참 (20/20) | C08 긴급 수리 |
| 빈 칸이 없음 | C09 예비 드론 지급 |
| 아직 해금 안 된 직급 | C09 · C10 · C11 |

**가중치 (기본 1.0)**

| 상황 | 대상 | 가중치 |
| --- | --- | --- |
| 그리드에 해당 종류 드론이 0대 | C01 · C02 · C03 | 0.4 |
| 해치 HP 10 이하 | C08 긴급 수리 | 2.0 |
| 해치 HP 5 이하 | C08 긴급 수리 | 3.0 (3장 중 반드시 포함) |

쓸모없는 카드를 완전히 빼지 않고 확률만 낮춘다. "이번엔 흡입 드론을 키워 볼까"처럼 카드가 배치를 바꾸는 경우도 남기기 위해서다.

**다시 뽑기** — 사원 승진 시 해금. 판당 1회 무료. 제시된 3장을 모두 버리고 위 규칙으로 다시 뽑되, 방금 본 3장은 제외한다. 후보가 부족하면 제외한 카드를 다시 넣는다.

**재현성** — 뽑기는 판 시작 때 정한 시드를 쓴다. 같은 시드 + 같은 선택이면 같은 카드가 나오므로 버그 재현과 이후 "오늘의 근무" 모드에 그대로 쓸 수 있다.

## 효과 적용 구조

**카드는 드론을 직접 바꾸지 않는다. "이번 판 보정값 목록"에 한 줄을 추가하고, 드론은 공격할 때마다 최종 수치를 물어본다.** 그래서 이미 배치된 드론, 나중에 소환 · 머지된 드론에 따로 처리할 필요가 없다.

```latex
\text{최종 값} = (\text{기본 값} + \Sigma \text{더하기}) \times (1 + \Sigma \text{백분율})
```

**적용 순서** — 기본 값(UnitData) → 영구 강화(장비 연구소, 추후) → 이번 판 지원 카드. 백분율끼리는 곱하지 않고 더한다 (+20% 두 장 = +40%, +44% 아님).

**보정 대상 스탯**

| 스탯 키 | 대상 | 상한 |
| --- | --- | --- |
| Damage | 드론 종류별 또는 전체 | 백분율 합계 +50% |
| AttackInterval | 전체 | 백분율 합계 −30% |
| Range | 전체 | +1칸 |
| SlowDuration · SlowRate | 냉각 드론 | 감속률 최대 70% |
| SummonCost | 소환 (횟수형) | 비용 최소 10 |
| KillReward | 점액 처치 보상 | — |
| MergeReward | 머지 보상 | — |

**숫자로 따라가 보기** — 웨이브 1 뒤 C01, 웨이브 2 뒤 C01을 또 골랐을 때, 3등급 흡입 드론(기본 피해 45)이 변이 점액(체력 300)을 잡는 경우

| 시점 | 보정 | 최종 피해 | 필요한 발 수 | 걸리는 시간 (0.35초 간격) |
| --- | --- | --- | --- | --- |
| 웨이브 1 | 없음 | 45 | 7 | 2.45초 |
| 웨이브 2 | +20% | 54 | 6 | 2.10초 |
| 웨이브 3 | +40% | 63 | 5 | 1.75초 |

**업무 지원 카드와 장비 연구소는 같은 구조를 쓴다.** 나중에 연구소를 붙일 때 보정값 공급원만 하나 추가하면 된다.

## 선택 화면 UI · 연출

**카드는 본사에 올리는 "지원 신청서"다. 하나를 고르면 "승인" 도장이 찍히고, 카드가 작아져서 HUD의 "적용 중 지원"으로 들어간다.** 결재 도장 · 작업 지시서와 같은 서류 톤을 쓴다.

| 요소 | 내용 |

| 조작 | 마우스 클릭 또는 숫자 키 1 · 2 · 3. 다시 뽑기는 R |
| 분류 색 | 공격 주황 · 경제 청록 · 방어 초록 · 유틸 보라 (카드 위 태그) |

## 데이터 구조

**카드 1장 = SupportCardData SO 1개. 새 카드는 SO를 하나 만들어 카드 풀에 넣으면 끝난다.** 효과 종류가 기존에 없는 것일 때만 코드가 필요하다.

| SO | 필드 | 설명 |
| --- | --- | --- |
| SupportCardData | id, displayName, category, icon | C01, "흡입 노즐 교체", 공격 · 경제 · 방어 · 유틸 |
|  | description | `{value}` 자리에 수치가 들어감 ("흡입 드론 공격력 {value}") |
|  | effects\[\] | 효과 목록 (아래 CardEffect) — 한 카드에 여러 개 가능 (C03처럼) |
|  | maxStacks | 최대 중첩 수 (즉시형은 0 = 제한 없음) |
|  | unlockRank | 해금 직급 (인턴 · 사원 …) |
|  | baseWeight | 기본 가중치 1.0 |
|  | drawCondition | 제외 · 가중치 규칙 종류 (HatchFull, NoEmptyTile, DroneTypeAbsent, HatchLow) |
| CardEffect | kind | Modifier(지속) · Counted(횟수형) · Instant(즉시) |
|  | stat | Damage · AttackInterval · Range · SlowDuration · SlowRate · SummonCost · KillReward · MergeReward · HatchHeal · CoinGrant · FreeDrone · HatchShield · SummonChoice · MergeGradeBoost · FreeSummon |
|  | target | 드론 종류 또는 전체 |
|  | op · value | Add 또는 Percent, 값 |
|  | count | 횟수형일 때 횟수 (C05 = 3) · activeWave: 효과가 켜지는 웨이브 (C12 = 3, 0이면 항상) |
| SupportCardPool | cards\[\] | 모든 카드 목록 |
| GameConfig (추가) | supportOfferCount, statCaps | 제시 장 수(3), 스탯별 상한 |

**실행 중 객체 (저장하지 않음)**

| 클래스 | 역할 |
| --- | --- |
| RunModifiers | 이번 판에 고른 카드와 중첩 수, 횟수형의 남은 횟수 — 판이 끝나면 비움 |
| StatResolver | `Get(드론 종류, 스탯)` — 기본 값 + 보정값 상한 적용 후 최종 값. 보정값이 바뀔 때만 다시 계산해 캐시 |
| SupportCardDrawer | 뽑기 규칙 · 시드 · 다시 뽑기 — 순수 C# 클래스 (단위 테스트 대상) |
| SupportCardView | 선택 화면 · HUD 칩 연출만 담당 |

드론은 공격할 때마다 StatResolver에 물어보되, 값은 캐시되어 있어 매 프레임 계산 · 할당이 없다. 보정값이 바뀌면 OnModifiersChanged 이벤트로 캐시를 비운다.

## 예외 처리

**애매한 상황은 아래 규칙으로 고정한다.**

| 상황 | 규칙 |
| --- | --- |
| 웨이브 2 클리어와 동시에 해치 HP 0 | 패배 우선 (기존 규칙) — 카드 선택 없이 결과 화면 |
| 선택 화면에서 Esc | 휴게 시간이 열리고, 닫으면 선택 화면으로 돌아옴. 카드를 건너뛸 수는 없음 |
| 창이 포커스를 잃음 (Alt+Tab) | 선택 화면 상태 그대로 유지 (준비 시간도 이미 멈춰 있음) |
| 두 카드를 동시에 클릭 · 연타 | 첫 입력만 처리하고 연출이 끝날 때까지 입력을 막음 |
| C08 긴급 수리로 HP가 20을 넘음 | 20에서 멈춤. 남는 수리량은 버려짐 |
| C09 예비 드론을 고른 뒤 연출 중 빈 칸이 사라짐 | 선택 시점에 빈 칸을 예약해 두므로 일어나지 않음 |
| C05 사내 할인 횟수가 남은 채 판 종료 | 사라짐 (다음 판으로 넘어가지 않음) |
| C05 중첩 2장 | 횟수가 합쳐짐 (6회), 할인액은 그대로 15 |
| 할인으로 소환 비용이 상한 아래로 내려감 | 최소 10에서 멈춤 |
| C16 법인 카드와 C05 사내 할인이 함께 있음 | 무료가 먼저 쓰이고, 할인 횟수는 줄지 않음 |
| C14 결재 라인 단축 — 종류 고르는 창을 닫음 | 소환 취소, 코인 · 횟수 모두 그대로 |
| C15 사내 교육 이수 — 2등급끼리 머지 | 효과가 쓰이지 않고 남아 있음 (1등급 머지에서만 소모) |
| C13 시설 보험 — 점액 여러 마리가 같은 프레임에 도달 | 먼저 처리된 1마리 피해만 무효 |
| 머지로 생긴 새 드론 | 따로 처리 없이 StatResolver가 보정값을 적용 |
| 오염 칸의 드론 (선택 기능) | 보정값은 적용되지만 오염 중에는 공격 자체를 안 함 |

## 테스트 · 완료 기준

**뽑기 · 공식은 자동 테스트로, 체감은 플레이 로그로 확인한다.**

| 대상 | 방법 | 통과 기준 |
| --- | --- | --- |
| 뽑기 (SupportCardDrawer) | EditMode 단위 테스트, 시드 1,000개 | 중복 0, 분류 2가지 이상 100%, 제외 조건 위반 0 |
| 해치 위기 규칙 | 단위 테스트 | HP 5 이하일 때 C08이 항상 포함 |
| 다시 뽑기 | 단위 테스트 | 방금 본 3장이 다시 안 나옴 (후보 부족 시 제외) |
| 보정값 공식 (StatResolver) | 단위 테스트 | 효과 적용 구조 표의 숫자(45 → 54 → 63)와 상한이 그대로 나옴 |
| 적용 범위 | PlayMode 테스트 | 배치된 · 새로 소환된 · 머지된 드론 모두 같은 최종 값 |
| 성능 | Profiler, 3웨이브 최대 구간 | 카드 2장 적용 후에도 매 프레임 GC 할당 0 |
| 체감 | 플레이 로그 (고른 카드, 승패, 해치 HP) | 한 카드의 선택률이 60%를 넘거나 10% 미만이면 수치 조정 |
