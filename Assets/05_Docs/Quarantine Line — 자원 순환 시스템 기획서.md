# Quarantine Line — 자원 순환 시스템 기획서

Nov 14, 2026 · @진

## 개요

**한 문장:** 오염을 정화하면, 그 오염이 방어 자원이 된다. 처치한 점액을 재활용해 다시 점액을 막는 드론을 소환한다.

- **목적:** 지금의 "처치하면 코인" 보상을 세계관(괴생명체 정화·격리 사원)에 맞는 자원 순환으로 바꾸고, 드론 조합과 배치에 "언제 자원을 챙길지"라는 판단을 더한다.
- **플레이어:** 괴생명체를 정화하고 격리하는 회사 사원.
- **방향 (C안):** 자원은 바로 쓰는 돈(정제 점액)과 모아 쓰는 게이지(재활용 탱크)로 나눈다. 둘은 처치 한 번에 함께 찬다.

| 구분 | 지금 | 바뀐 뒤 |
| --- | --- | --- |
| 처치 보상 | 코인 +1 | 정제 점액 +1 (바로) + 탱크 게이지 +5% |
| 드론 투입 비용 | 코인 | 정제 점액 |
| 모아 쓰는 보상 | 없음 | 탱크 100% → 일괄 지급 또는 정화 펄스 |
| 오염 칸 | 없음 | 오염 웅덩이 → 같은 드론 머지로 정화 → 칸 복구 + 소량 반환 |

## 용어 정의

| 용어 | 뜻 | 비고 |
| --- | --- | --- |
| 정제 점액 | 드론 투입에 쓰는 자원. 처치 즉시 들어옴 | 기존 코인(Wallet)을 이름만 바꾼 것 |
| 재활용 탱크 | 처치할 때마다 차오르는 보너스 게이지 (0\~100%) | 정제 점액과 별도. 돈이 아니라 게이지 |
| 잔해 | 점액을 처치한 칸에 남는 덩어리 | 흡입 사거리 안이면 자동 흡수 (3단계 구현) |
| 오염 웅덩이 | 드론을 둘 수 없게 된 오염 칸 | 거두지 못한 잔해가 굳어 생김 |
| 머지 정화 | 같은 드론을 합칠 때 나오는 충격파가 옆 칸 웅덩이를 없앰 | 웅덩이를 되돌리는 기본 수단 |
| 정화 펄스 | 탱크 100%를 소모해 쓰는 1회성 스킬 | 점액 감속 + 웅덩이 전부 정화 |

## 큰 순환 흐름

&#91;embedded content: 자원 순환 · 큰 순환 4단계 + 탱크 게이지\]

처치하면 정제 점액은 바로 들어오고, 같은 처치가 탱크 게이지도 채운다. 탱크는 큰 순환 밖의 곁가지로, 100%가 되면 일괄 지급으로 자원에 힘을 보태거나 정화 펄스로 위기를 넘긴다.

## 최종 인게임 화면

웨이브 3 전투 중 재활용 탱크가 100%가 된 순간이다. 처치 한 번에 정제 점액 +1(HUD)과 탱크 +5%가 함께 뜬다. 아래 선택 패널에서 일괄 지급과 정화 펄스 중 하나를 고른다.

## 흡입 조건과 드론별 잔해

점액은 처치한 드론 종류에 따라 남는 양이 다르다. 빠르게 쓸어내면 자원을 잃고, 조합을 맞추면 자원을 더 거둔다.

**최종 규칙 (3단계 구현 기준)**

1. 점액을 처치하면 그 칸에 잔해가 남는다.
2. 흡입 드론 사거리 안의 잔해는 자동으로 빨려 들어간다 → 정제 점액 + 탱크 게이지.
3. 사거리 밖 잔해는 3초 뒤 오염 웅덩이로 굳는다.

| 처치한 드론 | 잔해 비율 | 의미 |
| --- | --- | --- |
| 흡입 | 100% (바로 흡수) | 느리지만 자원을 온전히 거둠 |
| 소각 (범위) | 30% (타고 재만 남음) | 많이 잡지만 자원 손해 |
| 냉각 (감속) | 120% (얼어서 온전히 남음) | 흡입과 조합하면 이득 |

**생기는 판단**

- 위기일 때: 소각으로 빠르게 쓸어낸다. 자원은 적게 남는다.
- 여유 있을 때: 냉각 + 흡입 조합으로 자원을 최대로 거둔다.
- 배치: 흡입 드론을 둘 자리가 곧 "어느 통로의 자원을 거둘지"가 된다.

## 재활용 탱크 (보너스 게이지)

탱크는 돈이 아니라 게이지다. 처치할 때마다 정제 점액과 함께 차오르고, 100%가 되면 플레이어가 쓸 곳을 고른다.

1. 처치 1회마다 게이지 +5% (잔해 비율을 곱함: 소각 처치는 +1.5%).
2. 100%가 되면 탱크가 빛나고 "정제 완료" 버튼이 켜진다. 100%에서는 더 차지 않는다.
3. 플레이어가 둘 중 하나를 고른다.
   - **일괄 지급:** 정제 점액 +30 → 드론을 더 뽑는다.
   - **정화 펄스:** 화면 전체 점액 2초 감속 + 오염 웅덩이 전부 정화 → 위기를 넘긴다.
4. 사용하면 게이지는 0%로 돌아가 다시 찬다.

선택을 미루면 게이지가 멈춰 있어, "자원으로 쓸까, 위기를 위해 아낄까"라는 짧은 판단이 생긴다. 웨이브가 끝나도 게이지는 유지된다(미정 사항 참고).

## 보조 순환 · 오염 정화

놓친 자원은 웅덩이가 되고, 웅덩이는 다시 자원으로 돌아온다. 막힌 칸이 곧 되찾을 자원이다.

1. **칸 오염:** 흡입 사거리 밖 잔해가 3초 뒤 웅덩이로 굳는다. 그 칸에는 드론을 둘 수 없다.
2. **머지로 정화:** 같은 드론 두 대를 합치면 충격파가 퍼져 바로 옆(상하좌우 1칸) 웅덩이를 씻어낸다.
3. **칸 복구 + 소량 반환:** 정화된 칸은 다시 드론을 둘 수 있고, 정제 점액 +3을 돌려받는다.

정화 펄스(탱크 100%)를 쓰면 웅덩이가 전부 한 번에 정화되고, 칸마다 같은 보상을 받는다.

## 수치 초안

모두 플레이테스트 전 초안이다. 드론 투입 비용과 처치당 지급량은 지금 코인 값을 그대로 쓴다.

| 항목 | 값 | 조정 포인트 |
| --- | --- | --- |
| 처치당 정제 점액 | 기존 코인 값 × 잔해 비율 | 경제가 느려지면 소각 30%를 올림 |
| 탱크 게이지 | 처치 1회 +5% × 잔해 비율 | 웨이브당 1\~2회 차는 정도가 목표 |
| 일괄 지급 | 정제 점액 +30 | 드론 1대 투입 비용 안팎 |
| 정화 펄스 | 점액 2초 감속 + 웅덩이 전부 정화 | 감속률은 냉각 드론과 같게 |
| 잔해 → 웅덩이 | 3초 | 너무 자주 막히면 5초로 |
| 웅덩이 정화 반환 | 정제 점액 +3 | 머지를 유도할 만큼만 |

## 구현 단계

앞 단계만 넣어도 게임이 돌아가도록 나눠 진행한다. 1단계는 표시만 바꾸므로 비용이 가장 낮다.

| 단계 | 내용 | 건드리는 곳 |
| --- | --- | --- |
| 1. 이름 바꾸기 | 코인 → 정제 점액. 아이콘·UI 문구·CoinFlyFx 목적지 변경 | Wallet 흐름은 그대로, UI·FX만 |
| 2. 드론별 비율 | 처치한 드론 종류에 따라 지급량 × 잔해 비율 | 처치 이벤트에 드론 종류 전달 |
| 3. 재활용 탱크 | 게이지, 100% 선택 패널, 일괄 지급·정화 펄스 | 새 컴포넌트 + HUD 패널 |
| 4. 잔해·웅덩이 | 잔해 오브젝트, 흡입 사거리, 3초 뒤 웅덩이, 칸 배치 불가 | Grid 상태에 오염 추가, 풀링 |
| 5. 머지 정화 | 머지 순간 옆 칸 웅덩이 제거 + 반환 | MergeRule 결과 이벤트에 구독 |

판정은 MergeRule·Grid에, 연출은 GameEvents를 듣는 쪽에 둔다. 지금의 "판정과 연출 분리" 구조를 그대로 따른다.

## 검증 항목과 미정 사항

**검증 (플레이테스트에서 확인)**

- [ ] 웨이브당 탱크가 1\~2회 찬다
- [ ] 소각만 쓰면 자원이 부족하다는 걸 플레이어가 느낀다
- [ ] 웅덩이가 칸을 너무 많이 막지 않는다 (동시 3칸 이하)
- [ ] "점액 → 자원" 흐름을 설명 없이 이해한다 (튜토리얼 단계에 추가 필요 여부)
- [ ] 일괄 지급과 정화 펄스가 비슷한 비율로 선택된다

**미정 사항**

- 웨이브가 끝날 때 탱크 게이지를 유지할지, 자동으로 일괄 지급할지
- 탱크 화면 위치 (해치 옆 기준, 실제 해치 위치 확인 필요)
- 머지 정화 범위를 상하좌우 1칸으로 할지, 드론 등급에 따라 넓힐지
- 흡입 드론 사거리 값
