## 이미 규칙으로 바꾼 것
| 레퍼런스 | 반영 |
|---|---|
| 격리선(주황 레이저 + 노랑 · 검정 줄무늬)이 드론 칸 **앞**, 점액은 선에서 막힘 | `V01` 3장 개정 — 칸 `z = -(row+1)`, 격리선 `z = 0` |
| 드론이 줄과 상관없이 레인 앞쪽을 쏨 | 사거리 = **격리선부터** `range` 칸 |
| 5레인 × 3줄, 카메라는 칸 뒤 위에서 앞쪽(점액 쪽)을 내려다봄 | G01 그대로 (방향 유지, 배치만 G08 에서 전환) |

## R3 클라 (G08 · G04 · G05)
- 격리선은 **낮은 턱 + 레이저 라인**이다 (드론 쪽 시야를 가리지 않음). 줄무늬 띠는 바닥 위 얇게
- 점액은 격리선에 닿는 순간 사라지고 해치 HP 감소
- 드론 공격은 격리선 너머로 쏜다: 흡입 = 레인 직선 빔 / 소각 = 부채꼴 / 냉각 = 하얀 분사

## R4 연출 (U01~U10) — 기획서에 없던 UI 요소 포함
| 위치 | 요소 | 기획서 대비 |
|---|---|---|
| 좌상단 패널 | `WAVE · C-3 화물칸` · `2 / 3` 큰 숫자 · `남은 점액 17 / 28` + 진행 막대 | 웨이브 · 남은 점액 HUD 를 한 패널로 묶음 |
| 상단 가운데 | `격리 해치 무결성` **칸 나뉜 게이지**(빨강 → 주황 → 노랑) + `14 / 20` | 해치 HP 게이지 형태 확정 |
| 상단 가운데 아래 | 경고 띠 `! 변이 점액 접근 — 3레인` | **새 요소** — 변이 점액이 나올 때 레인 알림 (이벤트 필요 → R3) |
| 우상단 | `보급 코인 240 +5`, 처치 지점에서 코인이 **점선 궤적**으로 날아와 꽂힘 · 일시정지 버튼 | 보급 연출과 같음 |
| 좌하단 | `청소 드론` 범례 — 흡입(단일 흡입) · 소각(부채꼴 범위) · 냉각(감속) 색 점 | **새 요소** — 첫 30초 가이드 보조 |
| 우하단 | `DEPLOY 드론 투입` 큰 버튼 · 비용 `65` · 부제 `빈 칸 4 · 무작위 1등급` · `SPACE` | 소환 버튼에 **빈 칸 수** 표시 추가 |
| 드래그 중 | 커서까지 **점선 곡선**, 대상 칸 위 말풍선 `결합 가능 → 흡입 드론 2등급`, 칸 초록 테두리 | 머지 미리보기에 **결과 이름 말풍선** 추가 |
| 오염 칸 | 초록 점액 웅덩이 + `오염 3.2초` 타이머 말풍선 | 선택 기능(O03) 그림 |
| 전투 숫자 | 피해 숫자 색 = 드론 종류 색 (흡입 청록 `-45` · 소각 주황 `-12`) · `감속 30%` 라벨 · `+5` 코인 | 데미지 숫자 색 구분 추가 |
| 칸 | 어두운 바닥에 **청록 발광 테두리** 칸, 빈 칸은 테두리만 | 칸 하이라이트 스타일 |
| 톤 | 홀로그램 단말 패널: 어두운 반투명 + 청록 테두리 + 굵은 숫자 | 컨셉 기획서 UI 방향과 같음 |

## R5 아트
- 드론: **둥근 접시형** 흰 기체 + 가운데 종류 색 발광 (흡입 청록 · 소각 주황 · 냉각 하늘), 등급 오르면 링 · 부품 추가
- 점액: 반투명 형광 초록 덩어리, 변이 점액은 크고 울퉁불퉁 · 내부에 어두운 핵
- 무대: 화물칸 복도 — 양옆 벽에 **청록 발광 띠**, 어두운 금속 바닥, 레인 구분 발광선. 격리선 = 노랑 · 검정 줄무늬 + 주황 레이저 + 양끝 경고등

## R6 성능
- 동시 점액 수십 + 빔 · 숫자 · 코인 궤적이 겹치는 그림이 3웨이브 측정 기준 화면
