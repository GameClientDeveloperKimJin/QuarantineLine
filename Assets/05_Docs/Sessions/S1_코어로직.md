## 이 세션만의 규칙
1. `QL.Core` 는 `noEngineReferences: true`. `UnityEngine` 을 쓰면 컴파일이 깨지게 해 둔다
2. 규칙 클래스는 **상태를 가진 모델 + 판정만 하는 정적 규칙**으로 나눈다 (예: `GridModel` + `MergeRule.Resolve`)
3. 시간은 `Tick(float dt)` 로 받고, 난수는 `IRandom` 으로 받는다 (`V01` 7 · 8장)
4. 모든 규칙에 EditMode 테스트. 테스트 이름은 `방법_조건_결과` (예: `Resolve_SameTypeSameGrade_Merges`)
5. Unity MCP 는 **스크립트 컴파일 확인 · 테스트 실행 · SO 에셋 생성**에만 쓴다. 씬을 열거나 고치지 않는다
6. 시스템 기획서 수치는 **SO 에셋 값**으로만 들어간다. 테스트도 숫자를 직접 쓰지 말고 테스트용 `RuleConfig` 를 만들어 쓴다 (기대값 계산은 공식으로)
