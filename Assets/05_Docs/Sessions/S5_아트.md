# S5. 아트 세션 (R5 · VARCO 3D 전용 · 상시)

> 🎯 **이 세션은** 드론 · 점액 · 해치 3D 모델을 만들어 전달 폴더에 놓는다. 개발 세션과 동시에, 첫날부터 끝까지 돈다.

## 세션 시작 시 붙여넣을 것
```
너는 Quarantine Line 의 아트 제작(R5)이다.
세션 규칙: D:\UnityProject\3D\QuarantineLine\QuarantineLine\Assets\05_Docs\Sessions\S5_아트.md
VARCO 3D MCP 만 쓴다. Unity MCP · Unity 프로젝트 폴더는 절대 건드리지 않는다.
```

## 절대 규칙
1. **Unity MCP 를 절대 쓰지 않는다.** `D:\UnityProject\3D\QuarantineLine\QuarantineLine\` 아래 파일을 읽지도 쓰지도 않는다
2. 작업은 VARCO 3D flow **한 곳**에서만: https://3d.varco.ai/flow/shared/65d78990-8bd9-42da-9328-862583de9b80
3. 완성본은 다운로드해 **`D:\UnityProject\3D\QuarantineLine\_ArtDelivery\`** 에 둔다. import 는 R3 가 한다
4. 에셋 하나 끝날 때마다 R1 에 보고 (아래 양식)
5. 관절 · 리깅 없음. 움직임은 R4 가 DOTween 으로 만든다 → **떠 있는 기체 · 덩어리** 형태만
6. 크레딧 사용 전 `get_account_and_pricing` 으로 잔액 확인, 한 에셋에 시안 3개까지

## 공통 스타일
- 로우폴리, 쿼터뷰에서 읽히는 큰 실루엣. 폴리곤 목표: 드론 ≤ 5k tris, 점액 ≤ 2k tris (대량 스폰)
- 드론: **흰 기체 + 종류별 포인트 색** (흡입 청록 · 소각 주황 · 냉각 하늘), 발광 링 자리
- 점액: 반투명 형광 초록 덩어리. 재질 발광은 Unity 에서 R4 가 입히므로 **형태 위주**
- 원점 = 바닥 중심, 정면 = +Z, 1 유닛 = 1 칸 기준 크기 (드론 약 0.7 칸 폭)
- 형식: `.fbx` 또는 `.glb` + 텍스처. 파일명 `QL_<종류>_<버전>.fbx` (예: `QL_Drone_Suction_v1.fbx`)
