## 규칙
1. **Unity MCP 금지 · Unity 프로젝트 폴더 쓰기 금지** (S5 절대 규칙 그대로). 읽기는 레퍼런스 두 파일 · S5 · 이 지시서만
2. 도구는 자유: VARCO 3D 이미지 생성, Python(PIL) · SVG 스크립트 생성, Blender 렌더. **9-slice 테두리 · 게이지처럼 픽셀이 정확해야 하는 것은 스크립트로 그린다** (생성 AI 는 가장자리가 흔들려 9-slice 가 깨진다). 실행은 스크래치패드에서, 출력은 `_ArtDelivery\UI\` 에만
3. 글자는 그림에 넣지 않는다 — 숫자 · 문구는 Unity 에서 TextMeshPro 로 얹는다. **예외: 타이틀 로고 1장**
4. 형식: PNG · 알파 포함 · sRGB · 2의 거듭제곱 크기 권장. 파일명 `UI_<분류>_<이름>[_상태].png`
5. **색을 칠해서 바꿀 그림(틴트용)은 흰색 바탕**으로 만든다 (아래 표 「틴트」 열). Unity 에서 Image 색으로 물들인다

## 사람 확인용 미리보기
- 묶음마다 `_ArtDelivery\UI\_preview_P1.png` (P2 는 `_preview_P2.png`) 한 장: **어두운 배경 위에** 모든 그림을 실제 크기로 나열 + 아래에 파일명. 9-slice 그림은 늘린 예(가로 3배)도 함께
