## 규칙
1. **VARCO 3D 만으로 만든다** (사람 지시). Blender 금지 · Unity MCP 금지. 텍스처 정리(색 단순화 · 마스크 생성)는 이미지 편집 스크립트(Python PIL) 허용 — 실행은 스크래치패드
2. Unity 폴더 쓰기는 **`Assets/04_Resources/Model/Stage/` 하나만**. 그 밖 Unity 파일은 읽기만(레퍼런스 · S5 · 이 지시서)도 위 목록만
3. 형식: **OBJ + mtl + png** (Blender 금지 · glTF 패키지 없음). 파일명 `QL_Stage_<이름>.obj`
4. 커밋하지 않는다 — Unity 가 `.meta` 를 만든 뒤 R1 이 커밋한다
5. VARCO 작업은 S5 의 flow 한 곳에서. 크레딧은 시작 전 `get_account_and_pricing` 확인, 모듈 하나에 시안 3개까지
6. 3D 드론 · 점액은 `R5 아트 세션`, 2D UI 는 `R5 아트_UI 세션` 몫 — 섞지 않는다

```
       z = 10  ┌─ 스폰 게이트 (점액이 나오는 화물칸 입구) ─┐
               │                                            │
  벽  x=-3.5   │   레인 5개 (x = -2 … +2), 점액 길 z 0~10    │  벽 x=+3.5
               │                                            │
       z = 0   ┝━━ 격리선 턱 + 양끝 경고등 기둥 ━━━━━━━━━━━┥
       z = -1~-3   드론 칸 3줄
                        카메라 (뒤 위)
복도 안쪽 폭 7 · 길이 약 15 (z -4 ~ 11)
```

## 만들 것 — 우선순위 순서

| # | 파일 | 크기 (유닛, 가로 x × 높이 y × 깊이 z) | tris | 설명 |
|---|---|---|---|---|
| M1 | `QL_Stage_LineSill` | 1.0 × 0.25 × 0.2 | ≤ 800 | **격리선 턱 한 칸분** (레인 1개 폭). 노랑 · 검정 사선 줄무늬 윗면 · 앞면, 윗면 가운데에 레이저 홈. 5개 이어 붙인다 — **좌우 끝이 이어져 보이게**. (구 A06 — 높은 문이 아니라 낮은 턱. 드론 시야를 가리지 않는다) |
| M2 | `QL_Stage_LinePost` | 0.4 × 1.2 × 0.4 | ≤ 1,500 | 격리선 양 끝 **경고등 기둥**. 꼭대기 주황 경고등, 안쪽 면에 레이저 발사구. 좌우 공용 (Unity 에서 뒤집는다) |
| M3 | `QL_Stage_WallPanel` | 0.3 × 2.5 × 2.0 | ≤ 3,000 | **복도 벽 한 토막**. 어두운 금속 판 + 가로 **청록 발광 띠** 1~2줄 + 패널 이음매 · 볼트. 안쪽 면이 **+X**. z 방향으로 이어 붙여 8토막 → 이음이 자연스러워야 한다 |
| M4 | `QL_Stage_SpawnGate` | 7.0 × 3.0 × 0.8 | ≤ 4,000 | 복도 끝 **화물칸 입구**. 큰 문틀 + 열린 셔터, 안쪽에서 **초록 점액 빛**이 새어 나옴 (발광 마스크), 문틀에 `C-3` 같은 화물칸 표기 자리(글자는 텍스처로 넣어도 됨). 정면 = **−Z** (카메라 쪽) |
| M5 | `QL_Stage_FloorTile` | 2.0 × 0.05 × 2.0 | ≤ 300 | 어두운 금속 **바닥 판** 한 장. 가장자리 이음선, 반복해 깔아도 무늬가 튀지 않게 (이어 붙임 확인). 칸 테두리 발광은 UI 세션 `UI_Cell_Outline` 이 맡으니 **넣지 않는다** |
| M6 (선택) | `QL_Stage_Prop_Crate` · `QL_Stage_Prop_Pipe` | 각 ≤ 1.0 크기 | ≤ 1,000 | 벽 앞에 둘 화물 상자 · 배관. 시간 남을 때만 |

공통:
- 원점 = **바닥 중심** (M3 벽은 바닥 · 안쪽 면 중심), 위 = +Y, 단위 1 = 1칸
- 쿼터뷰 위에서 읽히는 큰 형태 우선. 작은 디테일은 텍스처로
- 레퍼런스처럼 **어둡고 차가운 금속 + 청록 · 주황 포인트** — 밝은 회색 · 흰 벽 금지 (드론 흰색과 대비가 사라진다)

## 진행 순서 (모듈마다)
1. VARCO 이미지 생성으로 **콘셉트 이미지** — 레퍼런스를 참조 이미지로 넣는다
2. **사람에게 보여 주고 통과**받는다 (안 되면 고쳐서 다시)
3. 이미지 → 3D 생성, 크기 · 원점 · tris 맞추기, 텍스처 정리 + 발광 마스크
4. **미리보기**: 모듈 렌더(VARCO 화면 캡처 가능) + M1 5개 · M3 8개처럼 **이어 붙인 모습** 1장 → `_ArtDelivery\Stage\_preview_<이름>.png`
5. 사람 통과 → `Assets/04_Resources/Model/Stage/` 에 두고 백업 → R1 에 보고

M1 · M2 를 먼저 끝내 보고한다 (격리선은 G08 에서 노란 상자로 임시로 서 있다). 그다음 M3 → M4 → M5 → M6.
