## 규칙 (A08 과 같음)
1. Unity MCP 금지. Unity 폴더 쓰기는 **`Assets/04_Resources/UI/` · `Assets/04_Resources/FX/` 두 곳만** (사람 지시 납품 위치). 커밋 · `.meta` 는 R1 · Unity 몫
2. 픽셀이 정확해야 하는 것(위젯 · 그라데이션 · 반복 무늬)은 **스크립트(PIL)** 로. 앱 아이콘 · 엠블럼처럼 그림 맛이 필요한 것은 VARCO 이미지 생성 → 스크립트 정리 허용
3. 글자는 그림에 넣지 않는다 — **예외: 결과 엠블럼 2종** (로고처럼 선 글자로 직접 그림, 폰트 쓰면 상업 이용 가능 폰트만 · 보고에 명시)
4. PNG · 알파 · sRGB · 2의 거듭제곱. 파일명 `UI_…` / `FX_…`
5. 팔레트는 A08 그대로 (청록 `#2EE0E0` · 경고 주황 `#FFB020` · 위험 빨강 `#FF4A3D` · 머지 초록 `#4CFF7A` · 패널 `#0B1418`). 드론 종류색: 흡입 청록 · 소각 주황 `#FF9A2E` · 냉각 하늘 `#7CC8FF`
