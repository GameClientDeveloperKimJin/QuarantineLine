## 지금 화면 (문제)
- 게임 카메라는 위에서 비스듬히 내려다본다 (FOV 40). 복도는 x −3.5 ~ +3.5 · z −4 ~ 12, 벽 높이 2.5
- **화면 좌우 각각 약 1/4 이 벽 바깥 — 지금은 Unity 기본 회갈색 배경**. 위에서 보므로 바깥의 **바닥 쪽 · 아래쪽**이 주로 보이고, 벽 너머 먼 수평 풍경은 거의 안 보인다
- 21:9 화면에서는 바깥이 더 넓게 드러난다
- 확인용 화면: `D:\UnityProject\3D\QuarantineLine\QuarantineLine\_Verify\U03\p1_cells.png` (읽기 허용 — 이 폴더만 예외)

## 1단계 — 콘셉트 3안 (이미지만, 크레딧 아낌)
같은 카메라 각도(위에서 내려다봄, 가운데 복도 + 좌우 바깥)로 그린 콘셉트 이미지 3장. 가운데 복도는 지금 화면 그대로 두고 **바깥만** 다르게:
| 안 | 방향 |
|---|---|
| A | **심연 위 격납 시설** — 복도가 허공에 걸린 다리. 벽 바깥 아래로 깊은 수직 공간, 멀리 아래층 조명 · 파이프 다발 · 컨베이어, 아래로 갈수록 어둠 |
| B | **우주 화물선** — 벽 바깥 바닥이 두꺼운 관측 유리. 유리 아래로 별 · 행성 가장자리 · 우주 어둠 |
| C | **격리 시설 단지** — 양옆에 같은 격리 복도가 더 있고(멀리 · 어둡게), 사이에 크레인 · 화물 컨테이너 · 경고등 |
- 톤 규칙: 레퍼런스처럼 **어둡고 채도 낮게**. 청록 · 주황 발광 몇 점만. 복도(게임 영역)보다 눈에 띄면 안 된다 — HUD 패널이 그 위에 올라간다
- 시안 3장 + 셋을 나란히 붙인 비교 이미지를 사람에게 보여 주고 추천과 함께 고르게 한다 → 결정을 R1 에 보고
- **사람 결정 전 3D 생성 금지**

## 2단계 — 3D (사람이 고른 안으로)
- 모듈로 나눈다 (예: 바깥 바닥/유리 판 · 파이프 다발 · 크레인 · 먼 복도 덩어리). 반복 배치로 넓은 면적을 채울 수 있게
- **예산: 바깥 전체 합 ≤ 20k tris** (무대 모듈 A09 와 합쳐도 성능 여유 — P 단계 측정 대상). 모듈당 VARCO 최소 1,000 허용
- 원점 바닥 중심 · 1 유닛 = 1 칸. 형식 OBJ + mtl + png (+ 발광 마스크 `_Emission.png`)
- 배치 좌표 제안을 `_아트납품.md` 양식처럼 보고에 적는다 (x 범위 · y 높이 — 심연이면 음수 y)
- 위에서 본 조립 미리보기 `10_조립_위에서.png` (지금 복도 미리보기와 합쳐서) → 사람에게 보여 줌 → 사람 통과 → 납품
