## 목록 (★ = U12 에 먼저 필요 → 가장 먼저)
| 파일 | 크기 | 내용 (시안 기준) | 9-slice |
|---|---|---|---|
| ★ `UI_Cup` | 256 | 흰 머그 · 청록 띠 · 갈색 커피 윗면 (1-5) | — |
| ★ `UI_Steam` | 48×128 | 김 한 줄, 흰색 알파 (틴트용) — 3장 겹쳐 씀 | — |
| `UI_Stamp_Cleaned` | 512×256 | 사각 도장 「청소 완료」 + 작은 줄 「결재 · C-3 관제실」, 주홍 잉크 · 번짐 · 빈틈 (1-2) | — |
| `UI_Stamp_Rework` | 512×256 | 사각 도장 「재작업 요청」 같은 잉크 (1-2) | — |
| `UI_Stamp_Received` | 320 | 둥근 도장 「접수」 + 둘레 「C-3 관제실」 (1-1) | — |
| `UI_Stamp_Paid` | 256 | 둥근 도장 「지급」 (1-4) | — |
| `UI_Paper` | 256 | 크림색 종이, 위쪽 가는 점선 · 약한 그림자 | ✅ (Border 보고) |
| `UI_Paper_TornBottom` | 256×32 | 영수증 아래 톱니 가장자리 (알파) | — |
| `UI_Barcode` | 256×64 | 검정 바코드 (알파) | — |
| `UI_Slot` | 512×32 | 프린터 슬롯 · 청록 발광 선 (1-1 지시서 위) | ✅ 가로 |
| `UI_Avatar_Ops` | 128 | 헤드셋 쓴 관제실 직원 원형 아바타 (1-3), 단순 플랫 | — |
| `UI_Bubble` | 128 | 말풍선 판 — 어두운 바탕 · 주황 테두리 (1-3 강조 말풍선). 흰 테두리 변형 `UI_Bubble_Dim` (지난 메시지) | ✅ |

- 도장 글자는 **그림에 구워 넣는다** (글꼴은 Bagel Fat One 하나 규칙 — 도장 글씨는 그림이라 예외 아님. 손도장 느낌의 굵은 고딕을 PIL 로, 라이선스 자유 글꼴만, 보고에 적기)
- 도장은 정면(회전 0°)으로 그린다 — 기울기는 Unity 에서 무작위로 돌린다
- 색 · 톤: 레퍼런스처럼 어두운 홀로그램 UI 위에 올라가는 **종이 · 잉크만 따뜻한 색**. 나머지는 A08 키트 청록 톤
