# A13. 드론 발광 마스크 (종류색 Emission)
> 🎯 **이 작업은** 드론 3종의 종류색 부분(흡입 청록 · 소각 주황 · 냉각 하늘)만 빛나게 할 `_Emission.png` 마스크를 만든다. 위에서 보면 흰 몸체라 종류가 구분이 안 된다는 사람 지적(2026-11-11 · 보류함 10)을 U07 조명 · 블룸에서 해결하기 위한 재료.

| | |
|---|---|
| 역할 | R5 아트 (`R5 아트 세션`) — Unity 를 쓰지 않아 다른 개발 세션과 동시에 가능 |
| 입력 (읽기 허용 — 이 지시서 · 아래 파일만 예외) | `Assets/04_Resources/Model/Drone/QL_Drone_{Suction,Incinerator,Cryo}_{Body,Part_G2,Part_G3,Tool}_BaseColor.png` (드론 3 × 4장) · 각 `.obj` (UV 확인용) |
| 산출 | 같은 폴더에 `QL_Drone_<종류>_<부위>_Emission.png` (BaseColor 와 같은 크기 · 같은 UV) — 빛날 곳은 **종류색 그대로**, 나머지 **검정**. 부위에 빛날 곳이 없으면 그 파일은 만들지 않는다 · 백업 `_ArtDelivery/Drone/A13/` · 미리보기 `_ArtDelivery/Drone/A13/_preview.png` (BaseColor · Emission 나란히 + 위에서 본 느낌) |
| 쓰는 곳 | R4 U07 (재질 `_EMISSION` 켜기 · 블룸) |
| 검증 | 사람이 미리보기로 통과 → 납품 → R1 보고 |
| 만드는 법 | 이미지 편집 스크립트 (PIL — BaseColor 에서 종류색 영역을 색상 범위로 뽑아 다듬기). VARCO 불필요 · Blender · Unity MCP 금지. **`.obj` · `.mtl` · BaseColor 는 고치지 않는다** (mtl 에 map_Ke 줄 추가도 하지 않음 — 재질 연결은 U07) |

## 빛날 곳 (레퍼런스 `Reference/ingame_reference.png` 「드론 종류색 발광 링」)
| 부위 | 빛날 곳 |
|---|---|
| Body | 가운데 종류색 점(눈) · 테두리 종류색 링 · 돔 윗면 종류색 띠 (있으면) |
| Part_G2 | G2 링 안쪽 종류색 |
| Part_G3 | G3 포드 · 띠 종류색 |
| Tool | 노즐 끝 · 흡입구 안쪽 종류색 (소각 = 주황 · 냉각 = 하늘 · 흡입 = 청록) |

- 가장자리 1~2px 부드럽게 (블룸 번짐 대비)
