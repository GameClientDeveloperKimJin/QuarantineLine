## 만들 것
| 파일 | 크기 | 내용 |
|---|---|---|
| `UI_Card_Icon_C01` ~ `C16` (16장) | 256 | 카드 가운데 원형 아이콘 — 시안처럼 분류 색 원 테두리 + 단색 심볼 (C12 야근 = 달 + 시계, C16 법인 카드 = 카드, C13 보험 = 방패 체크 …). 흰 배경 위 선명하게, 64px 로 줄여도 읽히게 (HUD 칩) |
| `UI_Card_Frame` | 512×720 | 종이 카드 틀 (크림색 · 아래 결재란 · 9-slice 가능하게 Border 보고) |
| `UI_Card_Tag` | 512×80 | 위쪽 분류 띠 (흰색 — Unity 에서 분류 색 틴트: 공격 주황 · 경제 노랑/청록 · 방어 초록 · 유틸 보라) |
| `UI_Stamp_Approved` | 512×256 | 「승인」 도장 (기존 `UI_Stamp_*` 와 같은 주홍 · 같은 톤) |
| `UI_Chip` | 256×64 | HUD 「적용 중 지원」 칩 배경 (어두운 청록 · 발광 테두리, 9-slice) |
| `UI_Chip_Count` | 96×48 | 칩 오른쪽 「발동 중 · 남은 n」 배지 (흰색 틴트용) |
- 분류 색은 기획서 표 기준. 시안의 경제 = 노랑 카드라 **경제 색은 사람 미리보기에서 확정** (청록 vs 노랑 2안 나란히)
- 글자는 그림에 넣지 않음 (Unity TMP — Bagel Fat One)

## 만드는 법

- 아이콘 16장은 한 스타일로 (선 굵기 · 원 테두리 · 색 수 통일)
