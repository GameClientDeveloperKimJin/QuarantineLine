# A15. 인트로 컷신 그림 (로고 · 정거장 외부 · 사원증 · 교육 이수 도장)
> **사람 피드백 2026-11-12: 우주 · 별 · 행성 X → 컷 2 = 화물 격납고 입구 (A11 톤) · 로고에 별 모티프 없음 · 사원증 사진 = 검은 실루엣** (파일 이름 `CIN_Station_*` 은 그대로)

> 🎯 **이 작업은** M01 인트로 컷신(사람 스토리보드 `Reference/intro_storyboard.png`)에 필요한 2D 그림 4종을 만든다.

| 기준 | 스토리보드 · M01 계획 `_Verify/M01/계획.md` · 기존 A12 서류 톤 · A11 화물 격납고 · 게임 조명 톤 (어두운 남색/청록 + 형광 초록 점액) |
| 산출 | `Assets/04_Resources/Cinematic/` (사람 통과 뒤) · 백업 · 미리보기 `_ArtDelivery/Cinematic/A15/` |

## 만들 것
| 파일 | 크기 | 내용 |
|---|---|---|
| `CIN_Logo_CCC` | 1024×512 (투명) | **C.C.C. Cosmo Clean Co.** 회사 로고 — 밝고 친절한 청소 회사 (청록 · 흰색, 작은 별/물방울 심볼). 글자 구워도 됨 (로고라서) — 폰트 라이선스 보고 |
| `CIN_Station_Far` · `_Mid` · `_Near` | 2048×1024 각 (투명, 레이어 3장) | **우주 정거장 외부 2D 원경 — 패럴랙스 3층** (먼 별 · 행성 / 정거장 몸체 / 격납고 입구 열린 부분 가까이). 컷 2 카메라가 격납고 입구로 다가가는 7초용. 입구 안쪽은 A11 격납고 톤 |
| `CIN_IdCard` | 1024×640 | 관제실 **신입 사원증** — C.C.C. 로고 자리 · 사진 칸 (메신저 아바타 `UI_Avatar_Ops` 톤의 신입 얼굴 또는 빈 실루엣) · 이름 · 부서 「격리 1팀」 글자칸은 **비움** (TMP) |
| `CIN_Stamp_Trained` | 512×512 | 「신입 교육 이수」 도장 — 기존 `UI_Stamp_*` 와 같은 주홍 · 같은 잉크 처리 · 원형 |
| (선택) `CIN_ControlRoom_Bg` | 1920×1080 | 관제실 배경 흐림 (컷 6 사원증 뒤) |

## 만드는 법
- 기존 A12 · A14 와 같은 방법 (이미지 생성 · PIL). VARCO 쓰면 크레딧 보고. Blender · Unity MCP 금지
- 원경 3층은 같은 시점 · 같은 광원 (패럴랙스로 겹쳐도 어긋나지 않게)
