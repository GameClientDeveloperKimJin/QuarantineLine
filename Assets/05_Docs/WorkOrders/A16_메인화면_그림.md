# A16. 메인 화면 그림 (관제실 배경 · 새 로고)
> 🎯 **이 작업은** 사람 시안 `Reference/title_main_mockup.png` (3840×2160) 의 메인 화면을 Unity 에서 똑같이 만들 수 있게 **UI 를 걷어 낸 배경 그림**과 **새 로고**를 만든다.

| | |
|---|---|
| 역할 | R5 아트 (`R5 아트 세션`) — Unity · Blender 안 씀 |
| 기준 | 시안 `Reference/title_main_mockup.png` (사람 2026-11-12 「똑같이」, 배경은 이미지 써도 됨) |
| 산출 | `Assets/04_Resources/UI/Title/` (사람 통과 뒤) · 백업 · 미리보기 `_ArtDelivery/UI/A16/` |
| 쓰는 곳 | R4 U20 (메인 화면) |

## 만들 것
| 파일 | 크기 | 내용 |
|---|---|---|
| `UI_Title_Bg` | 3840×2160 | 시안 그대로의 관제실 장면 (왼쪽 어두운 벽 · 가운데 창문 너머 복도 · 책상 · 키보드 · 머그컵 · 스탠드 · 천장 조명) — **UI 전부 지움**: 로고 · 출근하기 버튼 · 메뉴 3줄 · 오른쪽 위 사원 카드 · 아래 단축키 안내 · 「Prototype v0.1」 글자. 지운 자리는 주변 배경으로 자연스럽게 채움 (왼쪽은 거의 검은 벽 · 위 카드 자리는 천장 · 조명) |
| `UI_Title_Bg_Glow` (선택) | 3840×2160 투명 | 창문 너머 초록 해치 발광 · 천장 조명만 따로 (Unity 에서 은은하게 깜빡이게) |
| `UI_Logo_Main` | 2048×1024 투명 | 시안 로고 — 흰 「QUARANTINE」 (외곽 청록 발광) + 초록 「LINE」 (점액이 흘러내리는 방울). 글자 구워도 됨 (로고) — 폰트 라이선스 보고. 기존 `UI_Logo_Title` 은 지우지 않음 |
| `UI_Title_Card` | 960×360 | 오른쪽 위 사원 카드 배경 (반투명 어두운 판 · 둥근 모서리 · 9-slice Border 보고) — 글자 · 진행 바는 Unity |
| `UI_Title_RankBadge` | 128×128 | 「사원」 직급 배지 틀 (청록 테두리 사각, 글자 비움) |
| `UI_Btn_Primary` | 1200×260 | 「출근하기」 큰 버튼 (청록 · 둥근 모서리 · 바깥 발광, 9-slice) — 글자 · ▶ · ENTER 칸은 Unity |
| `UI_KeyCap` | 160×64 | 단축키 틀 (ENTER · ↑↓ · ESC — 글자 비움, 9-slice) |

## 만드는 법
- 배경: 시안 이미지에서 UI 영역 지우기 (PIL · 이미지 생성 인페인팅). 원본 해상도 유지
- 로고: 시안과 같은 모양으로 다시 그리기 (투명 배경 · 발광 포함)
- VARCO 쓰면 크레딧 보고. Blender · Unity MCP 금지
