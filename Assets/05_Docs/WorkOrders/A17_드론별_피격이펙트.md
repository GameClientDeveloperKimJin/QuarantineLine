## 규칙 (A10 과 같음)
1. Unity MCP 금지 · Unity 폴더 쓰기는 통과 뒤 `Assets/04_Resources/FX/` 만. 커밋 · `.meta` 는 R1 · Unity 몫
2. PNG · 알파 · sRGB · 2의 거듭제곱 · 파일명 `FX_…`
3. **흰색 (또는 흰 → 투명)** 으로 그림 — 색은 Unity 에서 입힘. 단 점액 방울은 초록 그대로 가능
4. 모양이 정확해야 하는 것 (고리 · 물결 · 그라데이션) 은 스크립트 (PIL), 그림 맛이 필요한 것 (얼음 결정 · 연기) 은 VARCO → 스크립트로 배경 제거 · 정리 허용
5. 이미 있는 것 재사용 우선: `FX_Glow_Dot` · `FX_Spark` · `FX_Ring` · `FX_Frost_Burst` · `FX_Slime_Splat` — 겹치면 새로 안 만듦
6. 종류색: 흡입 청록 `#2EE0E0` · 소각 주황 `#FF9A2E` · 냉각 하늘 `#7CC8FF`
7. 게임 카메라는 위에서 비스듬히 내려다봄 (쿼터뷰) · 점액 지름 화면 약 40~80px → **작게 봐도 모양이 읽히게** 굵고 단순하게
