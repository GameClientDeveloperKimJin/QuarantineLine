## 1. 머지 구분 (사람: 「같은 드론 합치기가 안 됨 → 겹치면 자리만 바뀜」)
- 판정은 정상으로 추정: 다른 종류 · 등급이면 Swap (MergeRule). **드론 종류가 화면에서 구분이 안 되는 게 원인** (흰 몸체 + 작은 색 점, 보류함 10)
- 먼저 **진짜 판정 확인**: Play 중 같은 종류 · 같은 등급 둘을 MCP 로 끌어 Merge 가 나는지 1회 확인 → 안 나면 즉시 멈추고 R1 보고 (R3 버그)
- 고칠 것 (둘 다):
  1. **드래그 중 머지 가능 드론 표시** — 집는 순간 같은 종류 · 같은 등급 드론 칸에 초록 테두리 + 드론 밑 초록 링 (U03 칸 테두리 · U04 링 재사용). 하나도 없으면 아무것도 안 뜸. 놓으면 꺼짐. `DragStarted` · `DragEnded` 구독, R3 `GridModel` 읽기만
  2. **종류색 강화 (보류함 10 일부 앞당김)** — 드론 발밑에 종류색 링(흡입 청록 · 소각 주황 · 냉각 하늘, FX_Ring 가산, 작게 · 은은하게) 상시 표시. 등급은 지금 부품(G2 링 · G3 포드)으로 구분. 위에서 봐도 세 종류가 한눈에 갈려야 함. 재질 발광은 U07 그대로
- 시안 1-3 「결합 가능 → 흡입 드론 2등급」 말풍선은 이번엔 안 함 (나중 판단)

## 2. 히트 플래시 안 보임 (U06, 사람: 「맞은 점액만 하얗게 번쩍이지 않는 것 같다」)
- 원인 조사 — U06 📷 에서 MPB 값은 확인됐음. 실제 플레이에서 안 보이는 이유 (0.08초가 너무 짧음 · U05 납작 대역/U04 Model 전환과 충돌 · MPB 덮어쓰기 · 점액 Variant A/B 중 한쪽만 등) 를 찾고 고친다
- 필요하면 0.12초쯤 + 흰 비율 올림 (FxConfig). 「맞은 점액이 확실히 깜빡인다」 가 기준

## 3. 영수증 전에 코인이 이미 올라감 (U14, 사람: 「애초에 코인이 올라가 있는 상태」)
- 웨이브 클리어 순간 HUD 표시값이 붙잡히지 않고 바로 지갑값이 됨 — 원인 조사 (HudCoin 구독 순서 · `WaveCleared` 보다 `CoinChanged` 처리가 먼저 · U05 「delta>0 처치 아닌 것 = 즉시 굴림」 경로가 남아 있음 등)
- 기대: 클리어 순간 숫자 그대로 → 영수증 끝(1.9초)에 굴러 오름 + 「+합계」

## 4. 잔열 불꽃 확인 (U05, 사람: 「불꽃이 안 붙음」)
- 잔열은 **소각 3등급만** (`Unit_Plasma_G3.burnDps 5`, G1 · G2 = 0). 사람은 머지를 못 해 3등급이 없었을 가능성 큼 → 3등급 소각으로 실제 플레이에서 불꽃 확인만. 정상이면 코드 변경 없음

## 테스트
- 드래그 시작 → 같은 종류 · 등급 칸에만 표시 · 끝나면 0
- 히트 플래시: 실제 공격 경로(DroneCombat → SlimeDamaged)로 맞힌 점액에서 표시 확인 (이벤트 직접 발행 말고)
- 코인: 진짜 GameLoop 로 웨이브 클리어 → 그 프레임 HUD 표시 = 클리어 전 값 · 2.0초 뒤 = 지갑
- 기존 테스트 전부 통과
