## 1. 메신저 빈 창 없애기 (T1 5 — 사람: 「거슬림」)
- 사각 패널(머리 줄 · 배경 · 입력 줄 영역) **없앰**. 말풍선(아바타 · 이름 · 본문)만 왼쪽 아래에 떴다가 사라짐
- 「입력 중 ●●●」 은 말풍선 자리에 작은 점 풍선으로 0.5초 → 말풍선으로 바뀜 (원래 시퀀스 유지)
- 말풍선 최대 2 · 쿨다운 · 우선순위 · 핑은 그대로. 관제실 채널 · 시간 표시는 없앰 (필요하면 말풍선 이름 줄에 「관제실」 만)
- 말풍선 없을 땐 화면에 아무것도 없어야 함

## 2. 오염 표시 (T1 4)
- 「오염 n초」 → **숫자만** (`3.2`). 말풍선 크기 줄이고 칸 안쪽 · 웅덩이 위에 (아래 줄 드론 안 가리게)
- 1초 남은 깜빡임 · 마름 · 청소 링은 그대로

## 3. 히트 플래시 강화 (T1 3 — 「깜빡이긴 하나 직관적이지 않음」)
- 길이 · 흰 비율 올림 (FxConfig) + 맞는 순간 점액 `Model` 작은 펀치 스케일 (U17 MMTween 곡선 재사용, 할당 0)
- 「맞았다」 가 한눈에 — 너무 번쩍여 피곤하지 않게. 여러 마리 동시 히트에서 캡처로 확인

## 4. 드론 종류 링 (T1 2 — 「구분은 되나 잘 안 보임」)
- F01 발밑 종류색 링 알파 · 굵기 · 세기 올림. 2 · 3등급도 링이 부품에 묻히지 않게
- **U07b 합침 (A13 사람 통과 2026-11-12)**: 드론 3종 재질 `_EMISSION` 켜고 `QL_Drone_<종류>_<부위>_Emission.png` 연결 (흡입은 Tool 없음). 냉각(하늘)은 블룸에 흰색으로 날아가지 않게 `_EmissionColor` 세기 낮춤. 링과 발광을 같이 보고 둘 다 과하면 링을 줄임

## 5. 바로 시작 버튼 (G11 연결)
- 준비 시간에만 보이는 「작업 시작 (Enter)」 버튼 — 카운트다운 근처 또는 드론 투입 버튼 위 (겹침 금지, U15 지시서 · U14 영수증 · U09 가이드와 안 겹치게)
- 누르면 `GameLoop.RequestStartWave()`. 웨이브 · 일시정지 · 결과 중엔 숨김
- U09 가이드 문구에 Enter 안내는 넣지 않음 (짧게 유지)

## 5b. 최고 등급 청소 표시 (G11 3번)
- F01 머지 가능 표시: 최고 등급 드론을 집으면, 같은 종류 · 최고 등급 드론이 있는 **오염 칸**에도 초록 표시 (씻을 수 있음). 오염 아닌 칸의 최고 등급끼리는 표시 없음

## 6. 가이드 기록 재발 방지 (T1 1)
- 원인: 캡처 · 테스트 중 머지로 에디터 PlayerPrefs `QL.GuideDone = 1` 저장 → 사람 Play 때 가이드 안 뜸
- 테스트 · 캡처가 끝나면 키를 원래 값으로 되돌리는 것을 **모든 R4 PlayMode 테스트 공통 정리**로 (SetUp 에서 저장 · TearDown 에서 복원) + 마감 체크리스트에 「GuideDone 키 없음」 한 줄

## 테스트 (바꾼 클래스만 — 전체는 마감 직전 1번)
- 메신저: 말풍선 없을 때 화면 오브젝트 0 · 트리거 → 말풍선 → 4.5초 뒤 사라짐
- 오염 표시: 텍스트 = 숫자만 · 위치가 칸 사각형 안
- 히트 플래시: 실제 공격 경로로 맞힌 점액 표시 · 할당 0
- 바로 시작 버튼: 준비 중에만 보임 · 클릭 → 웨이브 시작
- 전체 실행 뒤 GuideDone 키가 실행 전과 같음
