## 만들 것

### 1. `Stage/GridSpace.cs` — 칸 ↔ 월드 변환 유일한 곳 (`QL.Game.Stage`, 일반 C# 클래스)
```csharp
public sealed class GridSpace
{
    public GridSpace(in RuleConfig config);
    public float CellSize { get; }
    public Vector3 CellToWorld(int index);              // 칸 중심, y = 0
    public Vector3 CellToWorld(int lane, int row);
    public Vector3 PathToWorld(int lane, float dist);   // 점액 위치 (dist = 해치까지 남은 칸, G04 가 씀)
    public int WorldToCell(Vector3 world);              // 칸 밖이면 -1
    public bool TryRaycastFloor(Ray ray, out Vector3 hit);   // y = 0 평면 교차. 평행 · 뒤쪽이면 false
    public Bounds StageBounds { get; }                  // 해치(z=0) ~ 스폰선(z=pathLength), 레인 폭 전체
}
```
**공식 — `V01` 3장 그대로, 칸 단위 × `CellSize`**
```
x(lane)   = (lane - (laneCount - 1) / 2f) * cellSize
z(row)    = (row + 1) * cellSize                // row 0 = 해치 바로 앞
z(dist)   = dist * cellSize                     // dist 0 = 해치, pathLength = 스폰선
index     = row * laneCount + lane
WorldToCell: lane = RoundToInt(x / cellSize + (laneCount - 1) / 2f), row = RoundToInt(z / cellSize) - 1 → 범위 밖이면 -1
```
- 마우스 판정은 **Collider 레이캐스트를 쓰지 않는다** — `TryRaycastFloor` → `WorldToCell` (G02 가 쓴다)
- 할당 없음 (구조체 반환만)

### 2. `Bootstrap/GameBootstrap.cs` — `MonoBehaviour`, 씬에 하나
- `[SerializeField] GameDataSet data` — **이것 하나만** 참조 (`V01` 4장. `Resources.Load` 금지)
- `Awake` 에서 생성해 읽기 프로퍼티로 내놓는다:
  `Config`(`RuleConfig`) · `Catalog`(`UnitCatalog`) · `Rng`(`SeededRandom(config.RandomSeed)`) · `Space`(`GridSpace`) · `Grid`(`GridModel`) · `Wallet`(`Wallet(config.StartCoin)`) · `Summoner`
- **싱글턴 · static 접근자를 만들지 않는다.** 다른 컴포넌트는 인스펙터로 `GameBootstrap` 을 참조한다
- `data` 가 비었으면 `Debug.LogError` 한 줄 + `enabled = false`
- 실행 순서: `[DefaultExecutionOrder(-100)]` 로 다른 Game 컴포넌트보다 먼저

### 3. `Stage/StageBuilder.cs` — 무대를 런타임에 생성
`Start` 에서 `GameBootstrap.Space` · `Config` 로 만든다. **씬 파일에 타일을 직접 두지 않는다** (수치가 바뀌면 따라오게).
| 오브젝트 | 형태 | 위치 · 크기 (전부 config 에서) | 머티리얼 |
|---|---|---|---|
| 바닥 | Cube 납작하게 | 레인 폭 + 양옆 여백 1칸, z = −1칸 ~ pathLength + 1칸 | `Mat_Floor` 어두운 회색 |
| 레인 5 | Quad, 바닥 위 0.005 | 레인 하나 폭의 90%, z = 0 ~ pathLength | `Mat_Lane` 조금 밝은 회색 |
| 칸 15 | `Cell.prefab` | `CellToWorld`, 한 변 = cellSize × 0.9 | `Mat_Cell` 옅은 청회색 (G02 · U03 가 하이라이트) |
| 격리 해치 | Cube | z = 0 뒤쪽, 레인 폭 전체, 높이 1.5칸 | `Mat_Hatch` 노랑 (줄무늬는 G07 · 아트) |
| 스폰선 | Quad 가는 띠 | z = pathLength, 레인 폭 전체 | `Mat_SpawnLine` 형광 초록 |

- 머티리얼 5개는 **에셋으로 만들어 `StageBuilder` 직렬화 필드로 참조**한다 (런타임 `new Material` · `Shader.Find` 금지 — 빌드에서 셰이더가 빠지고 재질이 복제된다). 셰이더 `Universal Render Pipeline/Lit`, `Mat_Cell` 은 **GPU Instancing 켬**
- `GameObject.CreatePrimitive` 로 만든 오브젝트는 생성 직후 `Destroy(GetComponent<Collider>())` 로 Collider 를 지운다 (시작 시 1회라 허용)
- 칸 오브젝트를 `Renderer[] CellRenderers` 로 들고 있는다 — G02 하이라이트 · U03 이 인덱스로 쓴다
- 하이어라키: `[Stage]/Floor` · `[Stage]/Lanes/Lane_0..4` · `[Stage]/Cells/Cell_00..14` · `[Stage]/Hatch` · `[Stage]/SpawnLine`
- `OnDrawGizmos` 로 칸 인덱스 위치에 작은 구를 그린다 (Scene 뷰 확인용)

### 4. `Stage/CameraRig.cs` — 고정 쿼터뷰
- 직렬화 필드 (인스펙터 값, 연출 조정용): `pitch`(내려다보는 각도, 기본 55°) · `yaw`(기본 0°) · `fieldOfView`(기본 40°) · `margin`(여백 비율, 기본 0.08)
- 카메라는 **해치 뒤(−z) 위**에서 +z 를 향해 내려다본다 — 해치가 화면 아래, 스폰선이 화면 위
- `StageBounds` 의 여덟 꼭짓점이 **현재 화면비**에서 전부 화면 안(여백 포함)에 들어오는 가장 가까운 거리를 계산해 배치한다 (`Camera.WorldToViewportPoint` 로 이분 탐색 또는 해석식 — 방법은 자유, 결과 기준은 체크리스트)
- 화면비가 바뀌면 다시 계산: `LateUpdate` 에서 `Screen.width/height` 를 이전 값과 비교, 달라졌을 때만 (할당 0). 16:10 · 21:9 대응의 바탕 (U10)
- 원근(Perspective) 카메라. 직교 아님

### 5. `Cell.prefab`
Quad(눕힌 것) + `MeshRenderer`(`Mat_Cell`). **Collider 없음.** 스크립트 없음.

## 숫자를 코드에 쓰지 않는다
- 레인 수 · 줄 수 · 경로 길이 · 칸 크기 · 해치 위치는 전부 config / `GridSpace`
- **예외 (표시용 비율 · 연출값):** 타일 90% · 레인 띠 두께 · 해치 높이 1.5칸 · 바닥 여백 1칸 · y 오프셋 0.005 · 카메라 기본 각도. 이 값들은 `StageBuilder` · `CameraRig` 의 **`[SerializeField]` 필드 기본값**으로만 두고 `const` · 리터럴로 흩지 않는다
