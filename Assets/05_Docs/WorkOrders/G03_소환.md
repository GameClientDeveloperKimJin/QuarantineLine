## 목표
L04 `Summoner.TrySummon` 을 화면에 연결한다. **판정은 Core 가 한다** — 코인 부족 · 칸 없음 · 어느 칸 · 어떤 종류 전부 `SummonResult` 로 받는다.
UI 는 임시(IMGUI). 진짜 소환 버튼 · HUD 는 R4 의 U02 · U03 이 `GameEvents` 를 구독해 만든다 — 그래서 **이벤트를 빠짐없이 내는 것**이 이 작업의 핵심 산출물이다.

```
Space / TempHud 버튼 ─► SummonController.RequestSummon()   ← U03 의 진짜 버튼도 이걸 부른다
                           │ 한 프레임 1회 가드
                           ▼
                Summoner.TrySummon(Grid, Wallet, Rng) → SummonResult
                           │ 성공
                           ├─ DroneBoard.SyncCell(cell)
                           ├─ GameEvents.CoinChanged(now, -cost)
                           ├─ GameEvents.SummonCostChanged(nextCost)
                           ├─ GameEvents.DroneSpawned(cell, type, grade)
                           └─ 소환 가능 상태 다시 계산 → 바뀌었으면 SummonAvailabilityChanged
```

## 만들 것

### 1. `GameEvents.cs` — 4개 추가 (`V01` 5장 이름 · 인자 그대로)
```csharp
public static event Action<int, int> CoinChanged;                       // now, delta
public static event Action<int> SummonCostChanged;                      // cost
public static event Action<SummonBlock> SummonAvailabilityChanged;      // None · NoCoin · NoCell
public static event Action<int, DroneType, int> DroneSpawned;           // cell, type, grade
```
`internal Raise…` · `ClearAll()` 에 포함. 기존 이벤트는 건드리지 않는다.

### 2. `Summon/SummonController.cs`
| 멤버 | 하는 일 |
|---|---|
| `bool RequestSummon()` | **한 프레임 1회 가드** (`Time.frameCount` 가 마지막 요청과 같으면 무시하고 false — 시스템 기획서 예외 표 「연타」) → `TrySummon` → 성공 시 위 그림 순서로 처리. 실패면 아무것도 안 바꾸고 false |
| `SummonBlock CurrentBlock` | 마지막으로 계산한 소환 가능 상태 |
| `int CurrentCost` | `Summoner.CurrentCost` |
| 입력 | `Update` 에서 `Keyboard.current.spaceKey.wasPressedThisFrame` → `RequestSummon()` |
| 상태 다시 계산 | `Summoner.Check(Grid, Wallet)` 결과가 **이전과 다를 때만** `SummonAvailabilityChanged` 발행. 다시 계산하는 때: 소환 후 · `DroneMerged` 수신(칸이 빔) · `CoinChanged` 수신(코인 획득 — G05 부터) |
| 시작 | `Start` 에서 현재 코인 · 비용 · 가능 상태를 한 번씩 발행 (UI 가 첫 값을 받게) |

- 드래그 중에도 소환할 수 있다 (집은 드론의 원래 칸은 Core 가 이미 채워진 칸으로 본다)
- `Update` 할당 0. 이벤트 구독은 `OnEnable` / `OnDisable`
- 나중에 게임 흐름(G06)이 생기면 결과 화면 · 일시정지 중 소환 금지가 추가된다 — 지금은 넣지 않는다

### 3. `Summon/TempHud.cs` — **임시** 화면 표시 (U02 에서 지운다)
- IMGUI(`OnGUI`) 로 화면 왼쪽 위에 작은 상자 하나:
  `Coins 120 | Cost 30 | Block None` + 버튼 `[Summon (Space)]` + 버튼 `[+100 coins (debug)]`
- 글자는 **영어** (IMGUI 기본 글꼴은 한글이 안 나온다)
- 값은 `GameEvents` 구독으로 받아 필드에 저장해 두고 `OnGUI` 는 그리기만
- `+100 coins` 는 `Wallet.Add(100)` 후 `CoinChanged` 발행 — **사람이 Day1 을 확인하려면 필요하다** (시작 120코인으로는 3대까지라 같은 종류 4대를 못 모은다. 처치 보상은 G05). 100 은 디버그 버튼 값이라 `[SerializeField] debugCoinAmount` 로
- 파일 맨 위 주석: `// TEMP — U02(HUD) 에서 삭제. 디버그 코인은 P01 F1 패널로 옮긴다`
- `OnGUI` 의 할당은 임시라 허용 (P03 측정 전에 사라진다)

### 4. `Game.unity`
- `[Summon]` 빈 오브젝트 + `SummonController` · `TempHud` (참조: `GameBootstrap` · `DroneBoard`)
- **`DroneSeeder` 컴포넌트를 끈다** (`enabled = false`, 오브젝트 · 스크립트는 남김 — 테스트 · 디버그용). Day1 은 빈 판에서 시작한다

### 5. PlayMode 테스트 — `SummonFlowTests.cs`
`Game.unity` 로드 → 한 프레임 대기. 코인이 더 필요한 테스트는 `Wallet.Add` 로 채운다.
1. `RequestSummon_Success_PlacesViewPaysAndRaisesEvents` — 뷰 1개 생김 · 코인 = 시작 − 비용 · `CoinChanged` · `SummonCostChanged` · `DroneSpawned` 각 1회
2. `RequestSummon_TwiceSameFrame_OnlyOnce`
3. `RequestSummon_NotEnoughCoins_FailsAndRaisesNoCoin` — 코인을 비용 미만까지 소환으로 쓴 뒤
4. `RequestSummon_AllCellsFull_RaisesNoCell`
5. `Merge_AfterFull_AvailabilityBackToNone` — 꽉 찬 판에서 머지(드래그 흐름 메서드) 1번 → `SummonAvailabilityChanged(None)`
6. `Day1_SummonFifteenThenMergeToMaxGrade` — 코인을 넉넉히 넣고 칸 수만큼 소환 → **같은 종류 1등급이 `2^(MaxGrade-1)` 대 이상인 종류가 반드시 있다** (칸 15 · 종류 3 → 비둘기집) → `DragController` 흐름 메서드로 합쳐 `MaxGrade` 드론 1대를 만든다. 등급 수 · 칸 수는 Config · Catalog 에서
7. `Views_AlwaysMatchGrid` (G02 와 같은 확인, 매 테스트 끝)

### ★ 사람이 확인한다 — Day1 완료 판정
1. `Game.unity` 를 Play 한다. 판이 비어 있고 왼쪽 위에 `Coins 120 | Cost 30` 이 보이면 통과다.
2. Space 를 세 번 누른다. 누를 때마다 빈 칸 하나에 드론이 바로 나타나고, 비용이 30 → 35 → 40 → 45 로 오르고 코인이 15 가 되면 통과다. 네 번째 Space 에서는 아무것도 안 나오고 `Block NoCoin` 이 보여야 한다.
3. `+100 coins` 를 몇 번 눌러 코인을 채운 뒤 소환과 드래그로 같은 종류를 모아 **3등급 드론을 하나 만든다.** 막힘 없이 끝까지 되면 Day1 통과다.
4. 칸 15개를 전부 채운 뒤 Space 를 누르면 `Block NoCell` 이 되고, 아무 두 드론을 합쳐 칸을 비우면 다시 `None` 으로 돌아오면 통과다.
5. 손맛 메모: Space 를 빠르게 연타했을 때 한 번에 두 대가 나오거나 늦게 반응하는 느낌이 있으면 적어 둔다.
