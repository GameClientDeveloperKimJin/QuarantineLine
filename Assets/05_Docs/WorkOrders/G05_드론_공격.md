## 목표
L06 판정을 그대로 쓴다 — **누구를 때릴지 · 감속이 어떻게 겹치는지는 Core**. 이 작업은 드론마다 타이머를 돌리고, 판정 결과대로 피해를 주고, 표시를 띄우고, 보상을 준다.
새 드론 종류 = `IAttack` 구현체 1개 + `UnitData` 3개 (컨셉 기획서 「유닛 확장」) 가 되게 만든다.

```
DroneCombat.Advance(dt)            ← [DefaultExecutionOrder]: WaveRunner → SlimeRegistry → DroneCombat
  칸마다 (드론 있음 · 드래그 중 아님):
    timer.Tick(dt)
    timer.Ready → attack = AttackLibrary[stats.AttackKind]
                  hit = attack.Execute(ctx)          ← TargetRule.Select… → SlimeCombat.Apply…
                  hit 이 있으면 timer.Consume() + AttackFxView 표시
    (냉각 3등급) freezeTimer.Ready + 주 타겟 있음 → SelectInRadius → ApplyFreeze
  피해마다 GameEvents.SlimeDamaged(view, dmg, droneType)
  ApplyHit 이 처치를 돌려주면 SlimeRegistry.Despawn(view, Killed)
KillRewarder: GameEvents.SlimeKilled 구독 → Wallet.Add(view.Reward) → CoinChanged(now, +reward)
             (직접 처치 · 잔열 처치 모두 여기 한 곳)
```

## 만들 것 — 네임스페이스 `QL.Game.Combat`

### 1. `IAttack.cs` · `AttackContext.cs`
```csharp
public interface IAttack
{
    // 이번 공격으로 피해를 준 점액 수를 돌려준다 (0 이면 타겟 없음 → 타이머 소비 안 함)
    int Execute(ref AttackContext ctx);
}
```
`AttackContext` (struct): `int Cell` · `int Lane` · `DroneType Type` · `UnitStats Stats` · `SlimeRegistry Registry` · `int LaneCount` · `int[] Buffer`(미리 잡은 배열) · `int PrimaryTargetId`(출력: 주 타겟 Id, 없으면 −1)

### 2. 구현체 3개 — 판정은 `TargetRule`, 효과는 `SlimeCombat`
| 클래스 | `TargetRule` | 맞은 점액마다 |
|---|---|---|
| `SingleBeamAttack` (흡입) | `SelectSingle(lane, Range, PierceCount, …)` | `ApplyHit(Damage)` |
| `ConeAttack` (소각) | `SelectCone(lane, ConeLaneSpread, LaneCount, Range, …)` | `ApplyHit(Damage)` + `BurnDps > 0` 이면 `ApplyBurn(BurnDps, BurnDuration)` |
| `SlowAttack` (냉각) | `SelectSingle(lane, Range, PierceCount, …)` | `ApplyHit(Damage)` + `ApplySlow(SlowRate, SlowDuration)` |
- 맞힐 때마다 `GameEvents.SlimeDamaged(view, damage, Type)` — U05 데미지 숫자가 **드론 종류색**으로 쓴다 (레퍼런스)
- `ApplyHit` 이 `true`(이번에 죽음) 면 `Registry.Despawn(view, Killed)`. 이미 죽은 점액(스냅샷이 오래됨)은 `TryGet` 실패 또는 `Combat.Alive == false` 면 건너뛴다
- **즉시 명중 (R1 결정)** — 날아가는 투사체를 만들지 않는다. 시스템 기획서 예외 「진행 중 대상 사망 → 피해 없음」 이 생길 틈이 없다
- 구현체는 상태 없는 클래스. `AttackLibrary` 가 `AttackKind → IAttack` 를 시작 때 한 번 만들어 둔다 (배열 인덱싱, Dictionary 박싱 없음)

### 3. `DroneCombat.cs` — 칸별 타이머 · 공격 진행
- 칸 수만큼 `AttackTimer[]` · `AttackTimer[]`(빙결) 를 들고 있는다
- 타이머 이동 규칙 (`GameEvents` 구독):
  | 이벤트 | 타이머 |
  |---|---|
  | `DroneSpawned(cell)` | 그 칸 새 타이머 (경과 0 — 소환 직후 한 간격 대기) |
  | `DroneMoved(from, to)` | from 의 타이머를 to 로 옮김 |
  | `DroneSwapped(a, b)` | 두 칸 타이머 교환 |
  | `DroneMerged(from, to)` | to 를 새 등급 간격으로 **`Restart()`** (기획서 「머지 쿨다운 0부터」), from 비움 |
- 드래그 중 칸(`Grid.IsDragging`)은 공격 · 타이머 진행 안 함 (시스템 기획서 드래그 규칙 2)
- 오염 칸 공격 정지는 O02 — 지금 넣지 않는다
- `Update` → `Advance(Time.deltaTime)`. **테스트는 `Advance` 직접** (G02 · G04 와 같은 방식)

### 4. `KillRewarder.cs`
`GameEvents.SlimeKilled` 구독 → `Wallet.Add(view.Reward)` → `CoinChanged(Wallet.Coins, view.Reward)`. 보상 지급은 **여기 한 곳만**.
(소환 버튼 상태 갱신은 G03 `SummonController` 가 `CoinChanged` 를 이미 듣는다)

### 5. `AttackFxView.cs` + `AttackFx.prefab` — 자리표시 공격 표시 (연출은 U04~U06 이 다듬는다)

### ★ 사람이 확인한다
1. `Game.unity` 를 Play 하고 `+100 coins` 로 코인을 채운 뒤 드론을 여러 대 소환한다. `[Wave 1]` 을 누르면 드론이 사거리 안 점액을 때리고, 쓰러진 점액이 사라질 때마다 왼쪽 위 코인이 오르면 통과다.
2. 세 종류가 서로 다르게 보이는지 본다. 흡입은 레인을 따라 청록 선, 소각은 앞쪽 주황 부채꼴, 냉각은 하늘색 분사이고 맞은 점액이 눈에 띄게 느려지면 통과다.
3. 같은 종류를 합쳐 3등급을 만들어 본다. 흡입 3등급은 앞의 두 마리를 동시에 맞히고, 소각 3등급이 맞힌 점액은 잠시 뒤에도 피해를 입어 쓰러지고, 냉각 3등급은 주기적으로 주변 점액을 잠깐 멈추면 통과다.
4. 공격 중인 드론을 집어 들면 그 드론은 공격을 멈추고, 다른 레인에 내려놓으면 그 레인을 공격하면 통과다.
5. 손맛 메모: 공격이 너무 약하거나 강해서 1 · 2웨이브가 지나치게 쉽거나 어렵게 느껴지면 적어 둔다 (밸런스는 1차 플레이 테스트).
