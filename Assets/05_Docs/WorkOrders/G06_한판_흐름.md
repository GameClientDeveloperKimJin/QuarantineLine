## 목표
L07 `GameFlow` 를 무대에 연결한다. **판정은 `GameFlow`** — 이 작업은 프레임 순서를 고정하고, 알림을 넘기고, `FlowStep` 을 이벤트로 바꾼다.

## 핵심 — 프레임 순서를 `GameLoop` 한 곳으로 (R1 결정)
지금은 `WaveRunner` · `SlimeRegistry` · `DroneCombat` 이 각자 `Update` 를 돈다. 이것을 **`GameLoop.Update` 하나가 순서대로 부르게** 바꾼다.
```
GameLoop.Update → Step(Time.deltaTime):
  1. WaveRunner.Advance(dt)       — 스폰
  2. SlimeRegistry.Advance(dt)    — 이동 · 잔열 · 격리선 도달 → (이벤트) → flow.NotifySlimeReachedLine / NotifySlimeKilled
  3. DroneCombat.Advance(dt)      — 공격 · 처치 → (이벤트) → flow.NotifySlimeKilled
  4. step = flow.Tick(dt)         — 프레임 끝 판정 한 번 (패배 우선, 보류함 2번 ②)
  5. step 을 이벤트로 (아래 표)
```
- 이유: 같은 프레임 「마지막 처치 + 해치 HP 0」 의 패배 우선이 **실행 순서로 보장**되고, 테스트가 `Step(dt)` 하나로 시간을 넘길 수 있다
- 세 컴포넌트의 `Update` 는 지운다 (`Advance` 는 그대로). `[DefaultExecutionOrder]` 순서 의존도 사라진다
- `Grid.Tick`(머지 잠금, `GameBootstrap`) · 입력(`DragController` · `SummonController`) 은 각자 `Update` 그대로

## 만들 것

### 1. `Flow/GameLoop.cs` — `MonoBehaviour`, `[Flow]` 오브젝트
- `Start`: `flow = new GameFlow(Config, waveSpecs)` → `flow.StartGame()` → **`StateChanged(flow.State)` 직접 발행** (보류함 2번 ①). `Time.timeScale = 1`
  - 타이틀(`Title.unity`)은 U01 이 만든다. `Game.unity` 는 들어오자마자 준비 상태로 시작
- 구독 (`OnEnable`):
  | 이벤트 | 처리 |
  |---|---|
  | `SlimeKilled(view)` | `flow.NotifySlimeKilled()` → `RemainingSlimesChanged(flow.RemainingInWave)` |
  | `SlimeReachedHatch(view)` | `flow.NotifySlimeReachedLine(view.HatchDamage)` → `HatchHpChanged(Hatch.Hp, Hatch.MaxHp)` → `RemainingSlimesChanged(flow.RemainingInWave)` |
- `FlowStep` → 이벤트 (`V01` 5장, 보류함 2번)
  | `FlowStep` | 하는 일 |
  |---|---|
  | `PrepSecondChanged` | `PrepTick(PrepSecondsLeft)` |
  | `WaveStarted` | `WaveRunner.StartWave(WaveIndex)` → `WaveStarted(WaveIndex, WaveCount, BannerText)` → `RemainingSlimesChanged(flow.RemainingInWave)` |
  | `WaveCleared` | `Wallet.Add(ClearBonus)` → `CoinChanged(Wallet.Coins, ClearBonus)` (보류함 2번 ③) |
  | `StateChanged` | `StateChanged(State)` |
  | `Outcome != None` | 드래그 중이면 `DragController.Cancel()` (예외 표 「드래그 중 게임 종료」) → `ResultSummary` 집계 → `GameEnded(summary)` → `Time.timeScale = 0` |
  여러 개가 같이 오면 **위 표 순서대로** 낸다
- 일시정지 · Esc (**Esc 는 여기 한 곳만 받는다**):
  1. 드래그 중이면 `DragController.Cancel()` 하고 끝 (일시정지 안 함)
  2. 아니면 `Prep · Wave` → `flow.Pause()` 가 true 면 `Time.timeScale = 0` + `StateChanged(Paused)` / `Paused` → `flow.Resume()` 가 true 면 `Time.timeScale = 1` + `StateChanged(flow.State)` (보류함 2번 ①)
- `public bool CanAct` — `State` 가 `Prep` 또는 `Wave` 일 때만 true. **소환 · 드래그 시작은 이것을 본다** (일시정지 · 결과 중 금지)
- `public void Restart()` — `Time.timeScale = 1` → `SceneManager.LoadScene(현재 씬)` (L07 결정 「새 GameFlow」 — 씬을 다시 불러 모든 모델을 새로 만든다. `GameEvents.ClearAll` 은 `GameBootstrap.OnDestroy` 가 이미 함)
- `public void Step(float dt)` — 위 1~5. **테스트는 이것을 직접 부른다**
- `public GameFlow Flow` (읽기) — TempHud · U02 가 값 읽기용

### ★ 사람이 확인한다 — Day2 완료 판정
1. `Game.unity` 를 Play 한다. 왼쪽 위에 준비 카운트다운이 8 → 0 으로 줄고, 0 이 되면 1웨이브가 시작되며 점액이 나오면 통과다.
2. 드론을 소환하고 합쳐 웨이브를 막는다. 웨이브를 다 막으면 코인이 50 오르고 5초 준비 뒤 다음 웨이브가 시작되며, 3웨이브까지 막으면 `VICTORY` 와 처치 수 · 3등급 드론 수가 보이면 통과다.
3. `[Restart]` 를 누르고 이번에는 일부러 막지 않는다. 점액이 격리선에 닿을 때마다 해치 HP 가 줄고, 0 이 되면 즉시 모든 것이 멈추며 `DEFEAT` 가 보이면 통과다.
4. 웨이브 중 Esc 를 누르면 점액 · 공격이 멈추고 `PAUSED` 가 보이고, 다시 Esc 로 이어지면 통과다. 드론을 끄는 중에 Esc 를 누르면 일시정지 대신 드래그만 취소되어야 한다.
5. **밸런스 첫 플레이 메모 (중요):** 소환 · 머지만으로 3웨이브를 막을 수 있었는지, 어느 웨이브가 너무 쉽거나 어려웠는지, 시작 3대로 1웨이브가 어땠는지 적어 둔다. 디버그 코인 없이 해 본 결과로 적어 주면 1차 플레이 테스트 전 수치 조정 근거가 된다.
