## 위치 결정 (R1)
- **모델은 `Assets/04_Resources/Model/` 그대로 쓴다. 옮기지도 복사하지도 않는다.** `06_Art/` 는 쓰지 않는다 (README 8장, 사람 지시). V01 2장의 `06_Art/` 줄은 R1 이 같이 고쳤다
- 머티리얼 · 프리팹은 `03_Prefabs/Game/` 아래에 R3 가 만든다 (위 소유 표)
- 원본은 **OBJ + mtl + png** (FBX 아님 — Blender 금지). S2 문서의 「FBX」 는 「모델 파일」 로 읽는다

## 핵심 — 바꿔 끼워도 깨지지 않는 프리팹 구조
```
Drone_Suction (루트: DroneView · 콜라이더 등 기존 Drone_Placeholder 와 같은 구성)
└─ Model               ← OBJ 인스턴스 (여기만 모델에 묶임)
   ├─ Body
   ├─ Part_G2          ← 등급 토글: 이름으로 찾는다
   └─ Part_G3
```
- 스크립트 · 콜라이더 · 크기 보정은 **루트**에, 모델은 **자식 `Model`** 에. 같은 이름 OBJ 가 바뀌면 `Model` 만 새로 고쳐지고 루트는 그대로
- `Part_G2` · `Part_G3` 은 **`Init` 때 이름으로 한 번 찾아 캐시** (직렬화 참조 금지 — 모델이 바뀌면 끊김). 못 찾으면 경고 한 번 + 토글 없이 계속 (깨지지 않음)
- **등급 누적**: 1 = Body · 2 = Body + Part_G2 · 3 = Body + Part_G2 + Part_G3 (G3 포드는 링 위에 얹혀 있어 G3 만 켜면 공중에 뜬다)
- 렌더러 배열(`renderers`)도 `Init` 때 `Model` 아래에서 모아 캐시 (직렬화 배열 대신)

## 만들 것

### 1. import 설정 (`.meta` 만)
- 모든 모델: Scale Factor 1 (원본이 유닛 단위) · Read/Write 끔 · 노멀 Import · 애니메이션 · 리그 없음 · 콜라이더 생성 끔
- 머티리얼: OBJ 가 만든 재질 대신 **`Materials/Art/` 의 URP Lit 머티리얼로 Remap** (Search and Remap 또는 Material 탭 수동 지정). mtl 의 텍스처가 파일명만이라 자동 연결 안 되면 수동 지정
- 텍스처: BaseColor = sRGB · Emission = sRGB · 밉맵 켬 · 최대 크기 2048 (드론 · 점액 1024 로 줄여도 되면 줄이고 보고)

### 2. 머티리얼 (`Materials/Art/`) — URP Lit, **전부 Enable GPU Instancing**
- 이름 = 납품 mtl 재질 이름 기준 (`M_Drone_Suction_Body` · `_Part_G2` · `_Part_G3` · 소각 · 냉각은 `_Tool` 포함 · `M_Slime_Basic_A/B` · `M_Slime_Mutant_A/B` · `M_LineSill` · `M_LinePost` · `M_WallPanel` · `M_SpawnGate` · `M_FloorTile` · `M_Prop_Crate` · `M_Prop_Pipe`)
- Base Map = 납품 `_BaseColor.png`. **`_Emission.png` 은 Emission Map 칸에 꽂아 두되 Emission 은 끈다** — 켜고 세기 정하는 것은 R4 U07. 바닥 판 Emission 은 꽂지 않음 (전부 검정)
- 점액: Surface **Transparent** (알파 0.85 안팎, 납품 텍스처는 불투명) · metallic 0 · smoothness 높게. 반투명 세부 · 발광 · 변이 핵 비침은 U07
- 같은 종류는 머티리얼 공유 (프리팹 9개가 재질 3세트를 나눠 씀)

### 3. 드론 프리팹 3개 (`Drones/`)
- 위 구조. 원점 = 바닥 중심 · 정면 +Z (점액 쪽) — **그대로, 회전 없음**
- `Unit_*.asset` 9개의 `prefab` → 종류별 프리팹 (흡입 1~3 → `Drone_Suction` …). DroneBoard 는 프리팹별 풀이라 구조 변경 없음
- `DroneView` 수정:
  - `Show(type, grade, tint)` → `Part_G2.SetActive(grade >= 2)` · `Part_G3.SetActive(grade >= 3)`
  - **틴트**: 텍스처에 이미 종류색이 있다 → 아트 프리팹은 MPB `_BaseColor` 틴트를 **하지 않는다** (`[SerializeField] bool applyTint` — `Drone_Placeholder` 는 true, 아트 프리팹은 false). 등급 색은 R4 U04 · U07 이 발광으로
  - `gradeScale` 은 `{1, 1.08, 1.15}` 로 줄인다 (부품이 커져 보이므로). 3등급 전체 폭이 칸(0.9)을 넘지 않는지 확인
  - MPB · 무할당 규칙 그대로. `Show` 에서 할당 없음
- `Drone_Placeholder.prefab` 은 지우지 않는다 (임시 도형 대체용)

### 4. 점액 프리팹 2개 (`Slimes/`)
```
Slime_Blob (루트: SlimeView · 기존 Slime_Placeholder 와 같은 구성)
├─ Model_A   ← QL_Slime_Basic_A, **로컬 회전 Y 180°**
└─ Model_B   ← QL_Slime_Basic_B, **로컬 회전 Y 180°**
```
- **⚠ 점액 모델 얼굴이 +Z 다. 점액은 −Z(카메라 쪽)로 걸어오므로 모델 자식을 Y 180° 돌린다** (안 하면 카메라에 뒤통수). 루트는 돌리지 않는다 (이동 · 판정 방향 그대로)
- **A/B 변형**: 풀 생성 때 슬롯마다 하나를 정해 다른 하나를 끈다 (`SlimeView.SetVariant(int)`). 고르는 법 = 풀 만들 때 한 번 만든 `System.Random(고정 시드)` — 표현 전용이라 `IRandom` 아님. 스폰 때 할당 · 탐색 없음
- `Enemy_Blob` · `Enemy_Mutant` 의 `prefab` → 각 프리팹. 크기는 `EnemyData.scale` 그대로 (변이 1.5배 → 폭 0.9)
- `SlimeView` 의 `mutantTint` 도 드론과 같이 `applyTint` 로 끈다 (변이 점액은 텍스처에 보라 핵 · 색이 있다)
- 원점 바닥 중심 → 스쿼시 · 스트레치(U04)가 바닥 기준으로 된다. 피벗을 바꾸지 않는다

### 5. 무대 (`StageBuilder`) — 모듈 프리팹 + 없으면 임시 도형
- `StageBuilder` 에 모듈 프리팹 칸을 둔다: `lineSill` · `linePost` · `wallPanel` · `spawnGate` · `floorTile` · `propCrate` · `propPipe`. **칸이 비어 있으면 지금의 `CreatePrimitive` 를 그대로 쓴다** (안 온 것은 임시 도형 — 구조 규칙)
- 각 모듈 프리팹도 「루트 + 자식 `Model`」 구조 (`Stage/`)
- 배치 — 좌표는 `_아트납품.md` A09 표가 원본. **Config(`laneCount` · `rowCount` · `pathLength` · `cellSize`)로 계산**, 숫자를 코드에 쓰지 않는다 (아래는 지금 값 5 · 3 · 10 · 1 로 계산한 확인용):
  | 모듈 | 배치 (지금 값 기준) | 주의 |
  |---|---|---|
  | M1 격리선 턱 | 레인마다 1개, x = −2 … +2 · z = 0 | 지금 `Hatch` 큐브를 대신. 해치 판정 · 위치는 그대로 |
  | M2 경고등 기둥 | 격리선 양끝 x ≈ ±2.75 · z = 0. 왼쪽 그대로, **오른쪽 `scale.x = −1`** | **법선이 뒤집혀 보이면 Y 180° 회전으로 대신** (캡처로 확인 · 어느 쪽 썼는지 보고) |
  | 레이저 | 두 기둥 발사구 사이, **높이 y ≈ 0.75** (렌즈 중심) | 지금 `laserHeightCells 0.35` → 0.75 로. 큐브 레이저 그대로 (빔 연출은 U06 · U07) |
  | M3 벽 | x = −3.5 그대로 · x = +3.5 `scale.x = −1`, z = −3, −1, … 11 (2.0 간격 8토막 × 좌우) | 오른쪽 뒤집힘 같은 주의 |
  | M4 스폰 게이트 | x = 0 · **z = 10.4** (앞면이 z = 10 = 점액 길 끝) | 표기판에 **TMP 3D 텍스트 `GateSign`** 을 둔다 (중심 ≈ y 2.75 · 게이트 앞면 앞 살짝). 처음 글자 `C-1`. 웨이브마다 바꾸는 것은 U06 (이번엔 코드 없음) |
  | M5 바닥 판 | **y = −0.05** (윗면 0), x = −3, −1, 1, 3 × z = −3, −1, … 11 (4 × 8장) | 지금 `Floor` 큐브를 대신. 레인 · 칸 표시는 그대로 위에 |
  | M6 상자 | 벽 앞 x ≈ ±3.0, z 는 칸 · 레인 · 게이트를 가리지 않는 곳에 몇 개 (2단 쌓기 가능, 위 상자 y = 0.7) | 꾸밈. 개수 · 위치는 캡처 보고 정함 · 카메라에서 레인을 가리면 안 됨 |
  | M6 배관 | 벽 안쪽 면 x = −3.5 그대로 · +3.5 `scale.x = −1`, z 1.0 간격 이음 | 벽 띠 높이와 겹치지 않게 |
- 무대 모듈은 **Static** 표시 (움직이지 않음 — U07 조명 굽기 대비) · 콜라이더 없음 (드래그 레이캐스트는 칸 · 바닥 평면 그대로)
- `SpawnLine` 은 남긴다 (게이트 앞면과 같은 z 면 겹쳐 보이는지 확인, 겹치면 끈다 — 판정과 무관)

## 숫자를 코드에 쓰지 않는다
- 배치는 Config 와 `[SerializeField]` 비율 · 오프셋으로. 기둥 x(±2.75) 같은 것은 「격리선 끝 + 여백」 비율로 표현
- `gradeScale` · 알파 · 시드는 직렬화 필드
