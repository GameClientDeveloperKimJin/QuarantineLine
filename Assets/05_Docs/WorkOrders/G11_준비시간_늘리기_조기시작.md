## 1. 준비 시간 (데이터만)
- `Waves.asset` prepTime: 웨이브 1 **8 → 12**, 웨이브 2 · 3 **5 → 20** (영수증 · 지시서 3.7초를 빼도 16초 남게)
- 값은 사람이 T1 에서 다시 조정할 수 있게 그대로 데이터에 (코드에 숫자 금지)

## 2. 바로 시작
- Core `GameFlow.StartWaveNow()` (이름 자유): Prep 상태에서만 → 남은 준비 시간 0 으로, 다음 Tick 에 평소와 똑같은 경로로 웨이브 시작 (이벤트 순서 · 예보 · 스폰 그대로). Prep 아니면 무시
- `GameLoop.RequestStartWave()` 공개 + 키 입력 **Enter** (Space 는 소환이라 피함). 일시정지 · 결과 중엔 무시
- 웨이브 1 도 가능 (튜토리얼 가이드 U09 와 충돌 없음 — 가이드는 웨이브 2 시작 때 끝남)
- 이벤트: 기존 `WaveStarted` 로 충분하면 새 이벤트 없음. R4 버튼이 「지금 준비 중인지」 알아야 하므로 읽기 API (`IsPrep` · `PrepRemaining`) 가 GameLoop/Flow 에 이미 있는지 확인, 없으면 읽기 속성만 추가

## 테스트 (바꾼 클래스만 — 전체는 마감 직전 1번)
- Prep 중 `StartWaveNow` → 다음 Tick 에 `WaveStarted` 1번 · 예보 = 실제 스폰 그대로
- Wave · Paused · Result 중 호출 → 아무 일 없음
- Enter 키 → 바로 시작 (PlayMode 1개)
- 기존 GameFlowTests 의 준비 시간 단언이 데이터 값을 읽는지 확인 (픽스처 `WavePrepTime 2.5` 는 그대로)
