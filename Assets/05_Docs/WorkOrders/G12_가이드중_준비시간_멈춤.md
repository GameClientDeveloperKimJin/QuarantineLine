## 할 것
- `GameLoop.SetPrepHold(bool hold)` (이름 자유): Prep 상태에서 hold = true 면 **준비 시간이 줄지 않음** (`PrepRemaining` 고정 · `PrepTick` 은 남은 초 그대로 또는 발행 안 함 — 둘 중 HUD 가 깨지지 않는 쪽, 보고). 소환 · 드래그 · 머지 · 일시정지는 그대로 됨
- hold 중 `RequestStartWave()` (Enter · 바로 시작 버튼) → hold 풀고 바로 시작 (가이드를 건너뛰고 싶은 사람용)
- Wave · Result 에선 hold 무시. 판 재시작 · 결과 · 타이틀 이동 때 hold 자동 해제 (남아서 다음 판을 막지 않게)
- 읽기: `IsPrepHeld`
- 이벤트: 필요하면 `PrepHoldChanged(bool)` — HUD 카운트다운이 「가이드 중」 표시를 할 수 있게. 없으면 R4 가 `IsPrepHeld` 를 읽음 (보고)

## 2. 바닥 빈 곳 메우기 (사람 지적 2026-11-12 「카메라에서 Floor 공백」)
- U10 카메라(pitch 45 · FOV 55 · margin 0.16)로 바뀐 뒤 화면에 바닥 없는 검은 곳이 보임 (R1 확인 — `_Verify/G11/p2_enter_wave_start.png` · `_Verify/U10/p1_wave_21x9.png`):
  ① **화면 아래 가운데**: 복도 바닥이 끝나는 앞쪽(해치 쪽, 화면 y ≈ 965 아래) 가로 x ≈ 530~1400 — 좌우 데크 사이에 아무것도 없음
  ② **21:9 위 양 모서리**: 데크 줄 끝 너머 검정
- 기존 A11 데크 메시(`QL_Stage_Outer_Deck`) 를 더 깔아 메움 — 새 그림 · 새 메시 없음. 좌표는 G10 처럼 직렬화 데이터 (코드에 숫자 금지). ① 복도 앞쪽 끝 아래 가운데 줄 추가 (x 0 근처 · 복도 앞쪽 z 바깥) ② 먼 쪽 · 바깥 열 한 줄씩 더
- 복도 · 칸 · 격리선과 겹치거나 z-fighting 없게 (데크 y −1.0 그대로) · Collider 없음 · 그림자 끔 · Static
- 확인: 16:9 · 16:10 · 21:9 게임 카메라에서 바닥 없는 검은 곳 0 (UI 패널 뒤 제외)

## 테스트 (바꾼 클래스만 — 전체는 마감 직전 1번)
- Prep 중 hold → 10초 흘려도 `PrepRemaining` 그대로 · 소환 · 머지 됨
- hold 해제 → 다시 줄어듦 · 0 되면 평소처럼 `WaveStarted`
- hold 중 `RequestStartWave` → 바로 시작 · hold 풀림
- Restart · GoToTitle 뒤 hold false
