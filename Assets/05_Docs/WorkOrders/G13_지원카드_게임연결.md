## 1. 흐름 (기획서 「흐름」)
- 웨이브 1 · 2 클리어 → (U14 영수증) → **카드 선택 대기** → 고르면 → (U15 작업 지시서) → 준비 시간 시작
- 선택 대기 = `SetPrepHold(true)` (G12) 재사용 — 고를 때까지 준비 시간 안 줄어듦. 고르면 hold 해제
- 웨이브 3 클리어 · 패배(동시 패배 우선) → 선택 없음
- 판 시작 때 `RunModifiers` · 뽑기 `IRandom` (`SupportCardDrawer.DrawSeed(RuleConfig.RandomSeed)`, V01 8장) 새로, 판 끝 · Restart 때 비움
- `StatResolver.SetWave(index + 1)` (C12 웨이브 3 한정 — activeWave 1부터)
- 순서 맞추기: U14 영수증 `Finished` 뒤 선택 화면 → 선택 뒤 U15 지시서. **이벤트로 R4 가 맞출 수 있게** (아래 3)

## 2. 효과 연결
| 카드 | 연결 |
|---|---|
| C01 · C02 · C04 · C10 · C12 (공격 · 간격 · 사거리) | `DroneCombat` 이 공격 때 `StatResolver.Get/GetInt` 로 최종 값 (캐시 — 할당 0). 이미 배치 · 새 소환 · 머지 드론 모두 |
| C03 (냉각 감속) | 감속률 · 지속 최종 값 (상한 70%) |
| C05 · C16 (할인 · 무료) | `SummonController` → `Summoner` 견적 소환 (K02) · 비용 표시 (`SummonCostChanged`) 도 견적 값 |
| C14 (종류 지정) | 횟수 남아 있으면 소환 때 **종류 선택 요청 이벤트** → U19 창 (1 · 2 · 3 키) → 고르면 `TrySummonChosen`, 닫으면 취소 (코인 · 횟수 그대로) |
| C06 (즉시 코인) · C08 (해치 회복) · C09 (예비 드론) | 고르는 순간 1번 — 지갑 · `HatchModel.Heal` · `TryPlaceFreeDrone` (선택 시점 빈 칸 예약) · 기존 이벤트 (`CoinChanged` · `HatchHpChanged` · `DroneSpawned`) 발행 |
| C07 (처치 보상 +1) · C11 (머지 +5) | `KillRewarder` · 머지 보상 최종 값 |
| C13 (해치 피해 무효) | 해치 피해 때 K02 `TakeDamage(dmg, mods, out blocked)` — blocked 면 **무효 이벤트** (U19 연출용) |
| C15 (1등급 머지 → 3등급) | `GridModel.Drop(to, mods)` (K02) — `DroneMerged` 의 newGrade 가 3 |
- 보정값이 바뀌면 (`RunModifiers.Version` 비교) 캐시 비우기 + 이벤트

## 3. 이벤트 · 읽기 API (U19 용 — 이름 자유, V02 갱신 보고)
- `SupportOffered(int waveIndex, SupportCardSpec[] cards)` — 선택 화면 열기 (배열은 미리 만든 것 재사용)
- `SupportPicked(SupportCardSpec card, int stack)` · `ModifiersChanged()` — HUD 칩 갱신
- `SummonTypeRequested()` · C14 창 열기 / `GameLoop.ChooseSummonType(DroneType?)` (null = 취소)
- `HatchDamageBlocked(SlimeView)` — C13 연출
- 공개 API: `GameLoop.PickSupport(int index)` (1 · 2 · 3 키 · 클릭 → R4 가 부름, 첫 입력만 · 연출 중 잠금은 R4) · 읽기 `CurrentOffer` · `ActiveSupports` (칩 표시용 · 남은 횟수)
- Esc: 선택 중 Esc → 휴게 화면 → 닫으면 선택으로 복귀 (건너뛰기 없음) — 기획서 예외 표
- Alt+Tab: 선택 상태 유지
