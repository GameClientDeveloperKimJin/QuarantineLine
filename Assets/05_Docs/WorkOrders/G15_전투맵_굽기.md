## 할 것
1. 에디터 메뉴 `Quarantine Line/전투맵 굽기` — 지금 `StageBuilder` 가 만드는 것과 **똑같은 결과**를 Game 씬 `[Stage]` 아래 프리팹 인스턴스로 생성 (데이터 그대로, 겉보기 변화 0). 이미 구운 게 있으면 묻고 다시 굽기
2. 메뉴 `전투맵 굽기 되돌리기` — 구운 오브젝트 지우고 런타임 생성으로 복귀
3. `StageBuilder`: 구운 맵이 있으면 **생성하지 않고 씬 것을 그대로 사용** (레인 발광선 · 바깥 데크 · 소품 · 벽 등). 없으면 지금처럼 생성
4. **수정 금지 묶음** — 게임 규칙과 연결된 위치 (그리드 칸 · 레인 · 격리선 · 스폰 게이트 · 해치 · `GridSpace` 기준 오브젝트) 는 `[Stage]/_Locked (수정 금지)` 아래로 모으고 이름 · 아이콘으로 표시 (옮기면 드래그 · 점액 경로 어긋남). 자유 편집 묶음 = `[Stage]/Editable` (바깥 데크 · 컨테이너 더미 · 벽 소품 · 조명 장식 · 레인 사이 발광선 외 장식)
5. Static · Collider 없음 · 그림자 설정은 굽는 결과에 그대로 (G10 · G09 규칙)
6. 사람 편집 안내: `_Verify/G15/편집안내.md` — 무엇을 바꿔도 되고 무엇은 안 되는지 · 새 소품 추가 방법 (프리팹 경로) · 되돌리는 법

## 테스트 (관련 클래스만)
- 구운 씬 Play = 생성 씬 Play 와 오브젝트 수 · 위치 같음 (오차 0.001)
- 구운 맵 있으면 StageBuilder 가 중복 생성 0
- Editable 오브젝트 하나 옮긴 뒤 Play → 옮긴 위치 그대로 · 게임 동작 (드래그 · 점액) 영향 0
- 되돌리기 → 생성 모드 복귀
