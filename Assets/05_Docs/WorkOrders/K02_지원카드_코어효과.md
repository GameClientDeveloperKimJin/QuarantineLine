# K02. 업무 지원 카드 — 기존 Core 에 효과 고리 달기
> 🎯 **이 작업은** K01 이 만든 보정값 · 횟수형 카드가 실제 규칙에 먹히도록 기존 Core 클래스에 고리를 단다 — 소환 비용 · 무료 소환 · 종류 지정 소환 · 해치 회복 상한 · 해치 피해 무효 · 머지 등급 +1. 게임 쪽 연결(입력 · 화면 · 이벤트)은 G13.

| | |
|---|---|
| 역할 | R2 코어 (`R2 코어 세션`) |
| 선행 | K01 (코드 · 같은 Unity 차례에 함께 컴파일 · 테스트) |
| 소유 파일 | `Core/Economy/Summoner.cs` (비용 오버로드 · 종류 지정 · 무료) · `Core/Flow/HatchModel` (Heal 최대치 상한 · 피해 무효 1회) · `Core/Grid/MergeRule` · `GridModel` (등급 +1 추가 — C15 1등급 머지 → 3등급) · 필요하면 `GameFlow` · EditMode 테스트 |
| 쓰지 않는 것 | `02_Scripts/Game/**` · UI · FX |
| 예상 | 1.5시간 |
| 기준 | 기획서 「카드 목록」 · 「예외 처리」 표 (C05 · C08 · C13 · C14 · C15 · C16 줄) |

## 할 것
- C05 · C16: `Summoner` 가 `StatResolver.QuoteSummon/CommitSummon` 결과 비용으로 소환 (무료가 할인보다 먼저 · 최소 10 · 무료는 소환 횟수 포함)
- C14: 종류 지정 소환 API (횟수 소모 · 취소하면 코인 · 횟수 그대로)
- C08: `HatchModel.Heal(n)` — 최대치에서 멈춤, 남는 양 버림
- C13: 해치 피해 무효 1회 (같은 프레임 여러 마리면 먼저 처리된 1마리만) · 변이 3 피해도 막음
- C15: 다음 1등급끼리 머지 1회 → 3등급 (2등급 머지에선 소모 안 함) — 최고 등급 · SwapClean(G11) 규칙과 충돌 없게
- 기존 동작은 카드 없을 때 그대로 (기존 테스트 전부 통과)

## 테스트
- 위 각 줄 + 기획서 예외 표 해당 줄 · 카드 없음 = 기존 결과 동일
