## 목표
시스템 기획서 「그리드 · 배치」 · 「머지」 · 「예외 처리」를 화면 없이 판정한다.
G02(마우스 드래그)는 **이 판정 결과만 받아** 3D 모델을 옮긴다. 화면이 규칙을 다시 계산하지 않게 하는 경로다.

```
GridModel (상태)                          MergeRule (판정만, static, 상태 없음)
 ├ BeginDrag(from)                         Resolve(fromCell, toCell, fromIdx, toIdx, catalog)
 ├ Drop(to) ──── Resolve 호출 ─────────►      → DropOutcome
 │      ◄──────── DropOutcome ────────────
 │   결과 적용 + DropResult 반환
 ├ CancelDrag()
 └ Tick(dt)  — 머지 잠금 시간 감소
```

## 만들 것 — 네임스페이스 `QL.Core.Grid`

### 1. `Cell.cs` — 칸 하나의 읽기 전용 스냅샷
```csharp
public readonly struct Cell
{
    public bool HasDrone { get; }
    public DroneType Type { get; }      // HasDrone 일 때만 의미
    public int Grade { get; }           // HasDrone 일 때만 의미
    public bool IsContaminated { get; }
    public bool IsLocked { get; }       // 머지 연출 중 (남은 잠금 > 0)
    public CellState State { get; }     // 아래 규칙으로 계산
}
```
**`State` 계산 규칙** — 오염이 드론보다 우선한다:
`IsContaminated` → `Contaminated` / 아니고 `HasDrone` → `Occupied` / 아니면 `Empty`

> 오염 칸에도 드론이 있을 수 있다 (시스템 기획서 「오염 칸 드론」 · 머지 표 4행). 그래서 상태는 **드론 유무 + 오염 여부 두 값**으로 들고, `CellState` 는 계산 결과로만 쓴다.

### 2. `DropOutcome.cs`
```csharp
public enum DropOutcome { Move, Merge, Swap, MergeClean, Reject, Return }
```
| 값 | 뜻 | 화면 (G02 · U03 참고용) |
|---|---|---|
| `Move` | 빈 칸으로 이동 | 흰 하이라이트 |
| `Merge` | 놓은 칸에 등급 +1 1대, 원래 칸 비움 | 초록 |
| `Swap` | 두 드론 위치 교환 | 노랑 |
| `MergeClean` | 오염 칸 위 머지 + 청소 | 초록 |
| `Reject` | 오염 칸이라 거부, 원위치 | 빨강 |
| `Return` | 놓을 수 없는 곳 — 그리드 밖 · 같은 칸 · 잠긴 칸 | 하이라이트 없음, 원위치 |

### 3. `MergeRule.cs` — 판정만 하는 정적 클래스
```csharp
public static class MergeRule
{
    // toIndex < 0 = 그리드 밖
    public static DropOutcome Resolve(in Cell from, in Cell to, int fromIndex, int toIndex, UnitCatalog catalog);
}
```
**판정 순서 — 위에서 처음 맞는 것 하나만** (시스템 기획서 머지 표 + 예외 처리)
| 순서 | 조건 | 결과 |
|---|---|---|
| 0-a | `toIndex < 0` | `Return` |
| 0-b | `toIndex == fromIndex` | `Return` |
| 0-c | `to.IsLocked` (머지 연출 중) | `Return` |
| 1 | `to.State == Empty` | `Move` |
| 2 | `Occupied` · 같은 종류 · 같은 등급 · `catalog.CanUpgrade(type, grade)` | `Merge` |
| 3 | `Occupied` · 그 외 (종류 다름 · 등급 다름 · 둘 다 최고 등급) | `Swap` |
| 4 | `Contaminated` · 드론 있음 · 같은 종류 · 같은 등급 · `CanUpgrade` | `MergeClean` |
| 5 | `Contaminated` · 그 외 (빈 오염 칸 포함) | `Reject` |

- `from` 에 드론이 없으면 `ArgumentException` (호출 쪽 버그)
- 최고 등급은 `catalog.MaxGrade` 로만 안다. **`3` 을 쓰지 않는다**

### 4. `DropResult.cs`
```csharp
public readonly struct DropResult
{
    public DropOutcome Outcome { get; }
    public int From { get; }
    public int To { get; }            // Return(그리드 밖)이면 -1
    public DroneType Type { get; }    // 끌던 드론의 종류
    public int NewGrade { get; }      // Merge · MergeClean 이면 올라간 등급, 아니면 끌던 드론 등급
}
```
G02 가 이 값 하나로 3D 연출을 고르고, R3 의 `GameEvents.DroneMerged` 등(`V01` 5장) 인자가 된다.

### 5. `GridModel.cs` — 15칸 상태
```csharp
public sealed class GridModel
{
    public GridModel(RuleConfig config, UnitCatalog catalog);

    public int LaneCount { get; }            // config 에서
    public int RowCount { get; }
    public int CellCount { get; }            // LaneCount * RowCount
    public int IndexOf(int lane, int row);   // V01 3장: row * laneCount + lane. 범위 밖 = -1
    public void CoordOf(int index, out int lane, out int row);
    public Cell Get(int index);
    public bool HasEmptyCell { get; }        // 드론 없고 오염 안 된 칸이 하나라도 (L04 소환이 씀)

    // 배치 — L04 소환 · 테스트가 쓴다
    public void Place(int index, DroneType type, int grade);   // 빈 칸 · 비오염이 아니면 InvalidOperationException

    // 드래그 — 한 번에 하나
    public int DraggingIndex { get; }        // 없으면 -1
    public bool IsDragging(int index);       // L06 · G05: 집어 든 드론은 공격 안 함
    public bool BeginDrag(int from);         // 드론 없음 · 잠김 · 이미 드래그 중 → false
    public DropResult Drop(int to);          // 드래그 중이 아니면 InvalidOperationException. 판정 → 적용 → 드래그 종료
    public void CancelDrag();                // 드래그 중이 아니어도 안전 (게임 종료 · Alt+Tab · 우클릭 · Esc)

    // 오염 — 지금은 상태 토글만. 시간 · 무작위 칸 선택은 O01
    public void Contaminate(int index);
    public void Clean(int index);

    // 시간
    public void Tick(float dt);              // 머지 잠금 남은 시간 감소. 0 이하면 해제
}
```
드래그 결과는 `Drop` 의 반환값 하나로만 나온다.

**`Drop` 적용 규칙**
| Outcome | from 칸 | to 칸 | 잠금 |
|---|---|---|---|
| `Move` | 드론 비움 (오염 여부는 그대로) | 끌던 드론 | — |
| `Merge` | 드론 비움 | 같은 종류 · 등급 +1 | to 에 `config.MergeLockDuration` |
| `Swap` | to 에 있던 드론 | 끌던 드론 | — |
| `MergeClean` | 드론 비움 | 등급 +1 · **오염 해제** | to 에 `MergeLockDuration` |
| `Reject` · `Return` | 그대로 | 그대로 | — |

- 드래그 중에도 원래 칸은 **드론이 있는 상태 그대로**다 (시스템 기획서 드래그 규칙 1 — 그 칸에 소환 불가)
- 드래그 중 원래 칸이 오염돼도 `Drop` 은 그때 상태로 판정한다 (예외 처리 표 3행)
- 청소 보상 코인(`cleanReward`)은 여기서 주지 않는다 — 경제는 L04, 오염 보상 연결은 O01
- 머지 후 공격 쿨다운 0 은 L06 · G05 몫. 여기선 다루지 않는다
- **이벤트(`event`)는 만들지 않는다.** 결과는 반환값으로만. Game 쪽이 받아 `GameEvents` 로 내보낸다
