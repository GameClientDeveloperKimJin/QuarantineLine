## ⚠ 먼저 — 좌표 규격이 바뀌었다 (코어 세션이 L05 이후 처음 보는 변경)
사람 결정으로 **격리선이 드론 칸 앞(z = 0)** 으로 갔고, **사거리는 격리선부터** 센다 (`V01` 3장 · `_결정기록.md`).
- 점액 위치 = `(lane, dist)`, `dist` = 격리선까지 남은 칸
- 드론 사거리 안 = **`0 ≤ dist ≤ range`** — 드론이 몇 번째 줄에 있든 같다. 그래서 이 작업의 판정 함수에는 **줄(row) · 칸 z 가 들어가지 않는다**
- 타겟 우선 = 사거리 안에서 `dist` 가 가장 작은 점액

## 목표
G05(드론 공격)는 이 판정을 그대로 부른다 — 화면이 "누구를 때릴지" 를 계산하지 않게 한다. G04(점액 이동)는 `SlimeCombat.SpeedMultiplier` 로 감속 · 빙결을 반영한다.
매 프레임 부르는 함수라 **할당 0** 이 핵심 조건이다 (3웨이브 동시 점액 수십 마리 — `V01` 6장).

```
G05 매 프레임: SlimeTarget[] (살아 있는 점액 스냅샷, 미리 잡은 배열) 채움
드론마다:  AttackTimer.Tick(dt) → 준비됐으면
            SelectSingle / SelectCone → 결과 인덱스를 int[] 버퍼에 (할당 0)
            맞은 점액의 SlimeCombat.ApplyHit / ApplySlow / ApplyBurn
냉각 3등급: FreezeTimer 준비 + 주 타겟 있음 → SelectInRadius → ApplyFreeze
점액마다:  SlimeCombat.Tick(dt) → 잔열 피해 · 감속/빙결 시간 감소 → SpeedMultiplier
```

## 만들 것 — 네임스페이스 `QL.Core.Combat`

### 2. `TargetRule.cs` — 정적, 상태 없음, **할당 0**
모든 함수는 `(SlimeTarget[] slimes, int count, int[] results)` 를 받고 **고른 개수**를 돌려준다. `results` 에는 `slimes` 배열의 **인덱스**를 넣는다. `results` 가 모자라면 들어가는 만큼만.
```csharp
public static bool InRange(float dist, float range);                  // 0 <= dist <= range
public static int SelectSingle(int lane, float range, int pierceCount,
                               SlimeTarget[] slimes, int count, int[] results);
public static int SelectCone(int lane, int laneSpread, int laneCount, float range,
                             SlimeTarget[] slimes, int count, int[] results);
public static int SelectInRadius(int centerLane, float centerDist, float radius, int laneCount,
                                 SlimeTarget[] slimes, int count, int[] results);
```
| 함수 | 규칙 |
|---|---|
| `SelectSingle` (흡입 · 냉각) | 같은 레인 · 살아 있음 · 사거리 안 중에서 `Dist` 오름차순으로 **최대 `pierceCount` 마리** (관통 = 3등급 흡입 2마리). 같은 `Dist` 면 배열 앞쪽(먼저 스폰된 것) 우선 |
| `SelectCone` (소각) | 레인 `[lane - laneSpread, lane + laneSpread]` (0 ~ laneCount-1 로 자름) · 살아 있음 · 사거리 안 **전부** (순서 무관). `laneSpread` = `UnitStats.ConeLaneSpread` (자기 레인만 0 · 양옆 1) |
| `SelectInRadius` (냉각 3등급 빙결) | 중심 `(centerLane, centerDist)` 에서 거리 `√((Δlane)² + (Δdist)²) ≤ radius` 인 살아 있는 점액 전부 (레인 간격 = 1칸). 사거리 제한 없음 — 중심이 이미 사거리 안 타겟이다 |
- 정렬은 `results` 안에서 **삽입 정렬** 등 제자리로 (최대 `pierceCount` 개라 짧다). `Array.Sort` · LINQ · `List` 금지

### 3. `AttackTimer.cs` — 공격 간격
```csharp
public struct AttackTimer
{
    public AttackTimer(float interval);
    public float Interval { get; }
    public bool Ready { get; }             // 경과 >= Interval
    public void Tick(float dt);            // dt < 0 이면 예외
    public void Consume();                 // 공격했을 때: 경과 -= Interval (남은 시간 이월, 0 아래로 안 감)
    public void Restart();                 // 경과 = 0 — 머지 직후 (시스템 기획서 「머지 결과 드론의 공격 쿨다운은 0부터」)
}
```
- 소환 직후 첫 공격도 `Interval` 을 기다린다 (경과 0 에서 시작)
- 타겟이 없으면 `Ready` 상태로 대기 → 점액이 사거리에 들어오는 순간 바로 공격 (G05 가 `Consume` 을 안 부르면 된다)
- 냉각 3등급 빙결 주기도 같은 타이머 하나 더 (`Interval = FreezeInterval`)

### 4. `SlimeCombat.cs` — 점액 하나의 체력 · 상태이상 (클래스, G04 풀에서 재사용)
```csharp
public sealed class SlimeCombat
{
    public void Reset(int maxHp);                 // 풀에서 꺼낼 때. 상태이상 전부 해제
    public int Hp { get; }
    public bool Alive { get; }                    // Hp > 0
    public float SpeedMultiplier { get; }         // 빙결 중 0, 아니면 1 - 감속률
    public float SlowRate { get; }
    public bool Frozen { get; }

    public bool ApplyHit(int damage);             // 피해. 이번 피해로 죽었으면 true (이미 죽었으면 false — 과잉 피해는 허용하되 처치는 한 번만)
    public void ApplySlow(float rate, float duration);
    public void ApplyFreeze(float duration);
    public void ApplyBurn(float dps, float duration);
    public bool Tick(float dt);                   // 시간 감소 + 잔열 피해. 잔열로 이번에 죽었으면 true
}
```
| 상태이상 | 규칙 (R1 결정 포함) |
|---|---|
| 감속 | **가장 강한 값 하나만** (시스템 기획서). 새 감속이 지금 이상(`>=`)이면 비율 · 남은 시간을 새 값으로 갱신. **약하면 무시** (지금 감속이 끝난 뒤에 다시 맞으면 그때 적용). 시간이 0 이 되면 비율 0 |
| 빙결 | 남은 시간 = `max(남은 시간, 새 시간)`. 빙결 중 `SpeedMultiplier = 0`. 감속과 따로 센다 (빙결이 끝나면 남은 감속으로 돌아감) |
| 잔열 | **맞은 점액에 붙는 지속 피해** (R1 결정 — 「바닥에 남는 잔열」을 화면에서는 바닥 불꽃으로 보여 주되, 판정은 점액에 붙인다). 다시 맞으면 `dps` 는 큰 값, 시간은 새 시간으로 갱신. 피해는 소수점을 누적해 **1 이상 쌓일 때 정수로** 깎는다 |
- 과잉 피해 허용 · 예측 타겟팅 없음 (시스템 기획서 예외 표)
- 해치 도달 · 보상 지급은 여기서 하지 않는다 — G04 · G05 · L07
