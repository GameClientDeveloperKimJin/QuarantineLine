## 1. 연결 (O01 마감 메시지 목록 그대로)
- `WaveRunner.StartWave` → `new SpawnCursor(flow.CurrentSchedule)` (공용 `bootstrap.Rng` 로 Build 하던 것 제거) → **실제 스폰 = `GameFlow.Forecast`**
- 웨이브 클리어 지급: `step.Pay.Total` **한 번** → `Wallet.Add` → `CoinChanged(now, Total)` (지금 ClearBonus 자리)
- `_bonusEarned` (U11 결과 보너스) = `Pay.Total` 합 (마지막 웨이브 포함)
- 점액 도달: `NotifySlimeReachedLine` 옆에서 `Grid.ContaminateInLane(slime.Lane, Rng)` — 후보 없으면 (−1) 아무 일 없음
- 드롭 결과 `MergeClean` → `flow.NotifyMergeClean()` + 청소 이벤트
- `Grid.Tick` 반환값 + `TickCleanedCell(i)` → 자연 청소 칸 이벤트 · 표시 갱신
- **오염 칸 드론 공격 정지** (`DroneCombat` 이 그 칸 `IsContaminated` 면 타이머 · 공격 건너뜀). 꺼내서 다른 칸에 두면 바로 다시 공격
- 드래그 중 원래 칸이 오염됨 → 드롭 결과대로, 복귀(Return)면 오염 칸으로 돌아가 공격 정지 (기획서 예외 표)
- 오염 칸 위로의 드롭: 같은 종류 · 등급 = MergeClean, 그 밖 = Reject (Core 그대로 — U03 미리보기 색이 Reject 빨강으로 나오는지 확인만)

## 2. 이벤트 추가 (`GameEvents` — V01 5장 규칙: internal Raise, GameLoop 프레임 순서 한 곳)
| 이벤트 | 인자 | 언제 | 쓰는 곳 |
|---|---|---|---|
| `WavePrepStarted` | `int index, WaveForecast forecast` | 준비 시간 시작 (첫 웨이브 · 클리어 뒤 다음 준비) — `PrepTick` 보다 먼저 | U15 작업 지시서 · U16 |
| `WaveCleared` | `int index, PayBreakdown pay` | 웨이브 클리어 순간, **`CoinChanged`(수당) 바로 앞** · 마지막 웨이브도 | U14 영수증 |
| `CellContaminated` | `int cell, int lane, float duration` | 칸이 오염된 프레임 | O03 · U16 (「칸 오염」 트리거 — 레인 핑) |
| `CellCleaned` | `int cell, bool byMerge` | 머지 청소 · 자연 청소 | O03 |
| `KillRewarded` | `SlimeView slime, int reward` | **보류함 21** — KillRewarder 가 `CoinChanged` 직전 | U05 CoinFlyFx 전환 (R4 다음 작업) |
- 같은 프레임 순서를 V02 「같은 프레임 순서」 에 맞춰 정하고 보고 (예: … → `WaveCleared` → `CoinChanged`(수당) → `StateChanged` → `WavePrepStarted` → `PrepTick` …)
- 할당 0 (struct 인자 · 미리 만든 배열)

## 3. 임시 오염 표시 (O03 이 진짜 연출로 바꿈)
- 오염 칸 바닥에 반투명 초록 판(기존 재질 · `FX_Slime_Puddle` 그림 아무거나) 1장 + 남은 시간에 따라 알파 줄기 정도. **연출 수준 아님 — 테스트 · 캡처에서 오염 칸이 보이기만 하면 됨**
- 칸 수만큼 미리 만들어 켜고 끔 (풀 · 할당 0)

- `KillRewarded(SlimeView, int reward)` 추가 (위 표). `CoinChanged` 는 그대로 → 기존 구독자 영향 0. G09 목록에서 21 은 빠짐

## 테스트 (PlayMode)
- 레인 2 점액 도달 → 레인 2 칸 하나 오염 · `CellContaminated` 1번 · 다른 레인 그대로 · 레인 전체 오염이면 이벤트 없음
- 오염 칸 드론은 5초 동안 공격 0 → 자연 청소 뒤 다시 공격 · `CellCleaned(byMerge:false)`
- 오염 칸 위 같은 드론 머지 → 청소 · `CellCleaned(true)` · 그 웨이브 클리어 `WaveCleared` Pay.CleanCount 1 · Total = 50 + 10 · 지갑 +60 한 번
- 예보 = 실제: 웨이브마다 `WavePrepStarted.forecast` 의 SlimeCount · MutantCount · CautionLane 이 실제 스폰과 같다 (준비 중 소환 여러 번 섞어도)
- 이벤트 순서 (위 2) · 결과 BonusEarned = Pay.Total 합
- `KillRewarded` 가 처치마다 1번, reward = 실제 지급
- 기존 EditMode · PlayMode 전부 통과 (O01 로 L05 분포 숫자 바뀐 것 반영돼 있음)
