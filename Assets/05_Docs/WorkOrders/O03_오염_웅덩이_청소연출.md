## 1. 웅덩이 (오염)
- `CellContaminated(cell, lane, duration)` → 그 칸 바닥(`GridSpace.CellToWorld(cell)`, y 살짝 위)에 `FX_Slime_Puddle` 웅덩이
  - 번짐: Scale 0.3 → 1.1 → 1.0 (0.25초 OutBack) + 무작위 Y 회전 (칸마다 다르게 보이게)
  - 작은 튀김: 점액 방울 몇 개 (기존 FX 풀 재사용 또는 Feel `MMF_Particles` — 가볍게)
  - 은은한 출렁임 (Scale 1 ± 0.03 루프, 칸마다 위상 다르게)
- 드론 위에 덮어도 드론 · 종류색 링(F01) 이 보여야 함 — 웅덩이는 드론 **밑**, 알파 · 색은 FxConfig
- 오염 칸 드론은 공격을 멈춘다는 게 보이게: 그 칸 드론 종류색 링을 흐리게 (F01 링 재사용, R4 파일 안에서)

## 2. 타이머
- 웅덩이 위에 작은 월드 공간 표시 「오염 3.2」(Bagel Fat One, 화면에서 24px 이상) 또는 원형 게이지 — **둘 중 하나, 읽기 쉬운 쪽**. 남은 시간 = `GridModel.ContaminationRemaining(cell)` 읽기만
- 1초 남으면 깜빡임 (곧 마름)
- 숫자 갱신은 0.1초 단위 · 문자열 할당 0 (`SetText` 포맷 · 미리 만든 문자열 표)

## 3. 청소
- `CellCleaned(cell, byMerge: true)` → 충격파 링 (`FX_Ring` 가산, 초록 → 흰, Scale 0.5 → 2.5 + Fade 0.35초) + 웅덩이 튀며 사라짐 (Scale 1 → 1.2 → 0, 0.2초) + 작은 「+10」 은 **안 띄움** (청소 수당은 U14 영수증에서 — 결정기록)
- `CellCleaned(cell, byMerge: false)` (자연 마름) → 웅덩이 Scale 1 → 0.6 + Fade 0.5초, 링 없음
- 같은 프레임 오염 → 청소 · 판 재시작 · 결과 화면 진입 시 남은 웅덩이 정리 (`GameStarted` 에서 전부 반납)

## 4. 임시 판 끄기
- `Game.unity` 의 R3 `ContaminationView` 컴포넌트를 **꺼 둔다** (MCP · 필드 변경 1개). 코드는 그대로 → O02 테스트가 그걸 쓰면 깨지지 않게 확인. 깨지면 R1 보고 (R3 G09 에서 정리)

- 판 재시작 → 웅덩이 0
