## 목표
시스템 기획서 「UI 시스템」 의 화면 4개를 만든다. **HUD 5요소는 U02** — 이번엔 인게임 화면에 일시정지 버튼만. `TempHud`(IMGUI, R3)는 U02 에서 지운다 — 이번엔 그대로 둔다 (겹쳐 보여도 됨).

| 화면 | 들어가는 조건 | 구성 |
|---|---|---|
| 타이틀 (`Title.unity`) | 실행 | 로고 `UI_Logo_Title` · 시작 버튼 · 해상도 드롭다운 · 창 모드 토글 |
| 인게임 (`Game.unity` `[UI]`) | 시작 버튼 | 오른쪽 위 일시정지 아이콘 버튼 (`UI_Button_Icon_*` + `UI_Icon_Pause`) |
| 일시정지 | 일시정지 버튼 또는 Esc | 「일시정지」 · 계속하기 · 다시 하기. 뒤 게임 화면을 어둡게 |
| 결과 | `GameEnded` | 엠블럼(`UI_Emblem_Victory` / `_Defeat`, 280~400px) · 승패 문구 · 남은 해치 HP · 제거한 점액 수 · 최고 등급 드론 수(`UI_Icon_Grade` 옆) · 다시 하기 |

## 만들 것

### 1. UI 그림 import (보류함 3번 · `_아트납품.md`)
- **필터 Point → Bilinear** (사람 결정). 사람이 이미 고른 Sprite 모드 · 밉맵 끔 · wrap Clamp 는 그대로
- **Sprite Border (사방 같음, px)** — Panel_Main 24 · Panel_Warning 20 · Panel_Tooltip 16 · Button_Deploy 32 · Button_Std 24 · Button_Icon 20 · Gauge_Frame 24 · Bar_Fill · Bar_Bg 4 · Key_Cap 12 · Dropdown_Box 20 · Dropdown_List 20 · Dropdown_Item_Hover 12. `UI_Cell_Outline` 은 그림을 보고 테두리 폭을 재서 넣고 값 보고 (U03 이 씀)
- `UI_FX_Scanline` · `UI_Lane_Range` 는 wrap **Repeat** (Scanline 은 Image Type Tiled 로 패널 위에 깔기 · Lane_Range 는 U03)
- 버튼 그림은 아래 2~4px 짙은 턱 · Pressed 는 그만큼 내려간 그림 → Button Transition = **Sprite Swap** (Normal · Hover · Pressed · Disabled), 글자도 Pressed 때 같은 px 만큼 내린다
- 바꾸는 것은 `.meta` 의 필터 · Border · wrap 뿐. png 는 건드리지 않는다

### 2. 폰트 (보류함 9번 앞 단계)
- `Window > TextMeshPro > Import TMP Essential Resources` → `Assets/TextMesh Pro/` 생김 (그대로 커밋)
- `_ArtDelivery/Fonts/BagelFatOne-Regular.ttf` · `OFL.txt` 를 `Assets/04_Resources/Fonts/` 로 **복사** (OFL 라이선스 파일을 반드시 같이)
- TMP 폰트 에셋 `QL_BagelFatOne SDF` — **Dynamic** (한글 포함, 아틀라스 1024, Multi Atlas 켬). 프로젝트 기본 TMP 폰트로 지정
- **작은 글자 확인:** 18 · 24 · 32 · 48px 로 「해상도 1920×1080 창 모드 남은 점액 17 / 28」 을 찍어 본다. 18 · 24px 이 뭉개지면 보고 (R1 이 보조 폰트 결정 — 이번엔 바꾸지 않음)
- 스폰 게이트 `GateSign` 글자는 **U06** (이번엔 폰트 에셋만)

### 3. `UIRoot.prefab` — `Game.unity` `[UI]` 아래
- Canvas: Screen Space – Overlay · **Canvas Scaler** Scale With Screen Size 1920×1080 · match 0.5 (세부 비율 대응은 U10)
- EventSystem: **Input System UI Input Module** (옛 Input 금지). 씬에 이미 있으면 하나만
- 자식: `InGameScreen` · `PauseScreen` · `ResultScreen` (각자 CanvasGroup, 시작 때 일시정지 · 결과는 숨김)
- 톤: 레퍼런스 메모 「홀로그램 단말 패널: 어두운 반투명 + 청록 테두리 + 굵은 숫자」 → `UI_Panel_Main` 9-slice + `UI_FX_Scanline` Tiled 얇게

### 4. 화면 스크립트 (`QL.UI`) — **구독만** (S3 규칙 1, 보류함 7번)
| 스크립트 | 듣는 것 | 하는 일 |
|---|---|---|
| `PauseScreen` | `StateChanged(GameState)` | `Paused` 면 보이기 · 아니면 숨기기. 계속하기 · 일시정지 버튼 → **`GameLoop.HandleEscape()`** (Esc 와 같은 길 — Esc 키는 UI 가 읽지 않는다, G06 「Esc 한 곳」). 다시 하기 → `GameLoop.Restart()` |
| `ResultScreen` | `GameEnded(ResultSummary)` | 엠블럼 · 문구 · 값 채우고 보이기. 다시 하기 → `GameLoop.Restart()`. `GameEnded` 바로 뒤 `timeScale 0` 이므로 **모든 트윈 `SetUpdate(true)`** |
| `InGameScreen` | `StateChanged` | 일시정지 버튼은 `GameLoop.CanAct` 일 때만 누를 수 있게 (결과 중 잠금) |
| `TitleScreen` | — | 시작 → `SceneManager.LoadScene("Game")`. 해상도 드롭다운 = `Screen.resolutions` 중 중복 제거 · 높은 순, 창 모드 토글 = `FullScreenMode.Windowed` / `FullScreenWindow` → `Screen.SetResolution`. 저장은 Unity 기본(플레이어 설정 기억)에 맡김 — PlayerPrefs 따로 안 씀 |
- 첫 표시 값이 필요하면 `GameLoop.Flow` 에서 직접 읽는다 (V02 「시작값」)
- 화면 전환 연출: 패널 Fade 0.2초 + Scale 0.95 → 1 정도 (`FxConfig` 수치, `SetUpdate(true)`). 반복 트윈은 `SetAutoKill(false)` + `Restart`
- 결과 문구: 승리 「격리 성공」 · 패배 「격리 실패」 (엠블럼 영어 도장과 함께). 값 라벨 「남은 해치 HP 5 / 20」 · 「제거한 점액 96」 · 「최고 등급 드론 3」
- 텍스트는 `SetText("{0}", v)` — 값 바뀔 때만 (V01 6장). 결과 화면 채우기는 판 끝 1회라 할당 허용

### 5. 씬 · 빌드 설정
- Build Settings 씬 순서: `Title` (0) → `Game` (1)
- **`Game.unity` 를 바로 Play 해도 지금처럼 시작된다** (개발 · 테스트 편의 — 타이틀을 거치지 않아도 됨)
- `Game.unity` 는 `[UI]` 아래 `UIRoot` 하나 끼우는 것 말고 바꾸지 않는다

## 숫자를 코드에 쓰지 않는다
