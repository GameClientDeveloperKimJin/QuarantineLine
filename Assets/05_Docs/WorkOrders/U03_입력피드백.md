R3 는 G 작업이 없어 대기 중이고 바꿀 줄이 적어 U03 이 직접 한다. **아래 범위 밖은 건드리지 않는다.**

## 만들 것

### 1. 소환 버튼 3상태 (기획서 · S3 U03)
| 상태 (`SummonBlock`) | 버튼 | 클릭 · Space 때 (`SummonRejected`) |
|---|---|---|
| `None` | 기본 | 소환 (기존) |
| `NoCoin` | **눌림 가능**으로 바꿈 (U02 는 비활성) · 비용 숫자 **빨강** | 버튼 **흔들림** (Shake 0.25초 안팎) + 비용 숫자 Punch |
| `NoCell` | `UI_Button_Deploy_Disabled` 그림 · 버튼 아래 말풍선 **「칸이 가득 찼습니다」** (`UI_Panel_Tooltip` + `TooltipTail`, 꼬리는 본체 아래 2px 겹침) | 말풍선 Punch |
- `GameLoop.CanAct` 가 false(일시정지 · 결과)면 `interactable = false` 그대로
- 보류함 11번: `UI_Button_Icon_Disabled` 는 **만들지 않는다** (아이콘 버튼이 잠기는 때는 결과 화면이 덮음) → 닫음

### 2. 호버 — 드론 위 마우스 (드래그 아닐 때)
- `CellHoverChanged(cell)` → 그 칸 위에 **청록 외곽선** (`HoverOutline.prefab` — `UI_Cell_Outline` 월드 쿼드, 칸보다 살짝 크게 · 살짝 Punch). 풀 1개
- **사거리 레인 미리보기** (`RangePreview.prefab` — `UI_Lane_Range` 월드 쿼드 1개): 그 드론 레인에서 **격리선(z 0)부터 사거리만큼** (사거리는 격리선 기준 · 행과 무관 — V01 3장). 길이 = `UnitData.Range` (`bootstrap.Catalog` / `Grid.Get(cell)` 의 종류 · 등급), 색 = 그 드론 `UnitData.TintColor`. 텍스처 아래 = 격리선 쪽, 위로 투명 (A10 표)
  - 소각(부채꼴)은 레인 하나가 아니라 범위가 넓을 수 있다 — `AttackKind` 가 부채꼴이면 레인 폭을 사거리 판정과 같은 폭으로 (판정 코드 `ConeAttack` 의 폭 값을 읽어서. 숫자를 새로 쓰지 않는다). 못 읽으면 레인 하나로 하고 보고
- `-1` 이면 둘 다 숨김. 드래그 시작 때도 숨김

### 3. 드래그 중
- 집은 칸: `CellHighlighter` 의 origin 색을 **반투명**으로 (S3 「집기 시 원래 칸 반투명」 — 테두리 칸이 흐려 보이게)
- 대상 칸: 기존 색 (머지 초록 · 이동 흰 · 교환 노랑 · 거부 빨강) — 테두리 칸 스타일에서도 넷이 확실히 구분되게 색 · 알파 조정
- `DropPreviewChanged` → 대상 칸에 **사거리 미리보기를 끌고 있는 드론 기준**으로 옮겨 보여 줌 (머지면 머지 뒤 등급의 사거리). `has=false` 면 숨김
- 머지 결과 말풍선 (「결합 가능 → 흡입 드론 2등급」) · 커서까지 점선 곡선은 **이번 범위 아님** (레퍼런스 새 요소 — R1 이 필요하면 따로)

### 4. UI 버튼 호버
- `PressableButton` 에 Hover 때 Scale 1.03 · 0.08초 (`FxConfig`), Exit 때 되돌림. 일시정지 · 결과 화면 버튼은 `SetUpdate(true)`
