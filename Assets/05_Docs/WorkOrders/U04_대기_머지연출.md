S3 U04 행: 드론 호버링 Yoyo · 점액 스쿼시 · 스트레치 · 머지 Sequence · 이펙트 풀. **연출은 판정을 기다리게 하지 않는다** — 머지 연출 전체 길이 = `GameConfig.mergeLockDuration` (지금 0.3초, Core 의 칸 잠금 시간과 같게 — S3 규칙 3).

## 건드려도 되는 곳 — 「자식 `Model` 만」 (R1 결정)
- `DroneView` · `SlimeView` (R3) 는 **루트**의 위치 · 크기 · 회전을 매 순간 정한다 (`PlaceOver` · `SetLifted` · 등급 크기 · `EnemyData.scale`). **R4 트윈은 루트를 절대 건드리지 않는다**
- 드론: 루트 아래 자식 `Model` 의 `localPosition` · `localScale` 만 트윈 (G07 구조 — 이름으로 찾기, 프리팹 전체 공통)
- 점액: 루트 아래 `Model_A` · `Model_B` 중 켜진 것의 `localScale` 만 (Y 180° 회전은 건드리지 않는다)
- 찾기는 처음 한 번 (`Transform.Find` 결과 캐시, 뷰 인스턴스별). R3 파일 · 프리팹 수정 없음

## 만들 것

### 1. 드론 대기 — 호버링 Yoyo
- `DroneSpawned` · `DroneMoved` · `DroneSwapped` · `DroneMerged` 때 그 칸 뷰(`DroneBoard.ViewAt`)의 `Model` 에 **위아래 Yoyo** (`localPosition.y` ± `FxConfig.droneHoverAmp`, 주기 `droneHoverPeriod`, `SetLoops(-1, Yoyo)` · `SetAutoKill(false)`). 뷰마다 트윈 하나를 만들어 두고 재사용 (`Restart` 아님 — 계속 돌게)
- 위상은 칸 번호로 어긋나게 (모두 같이 출렁이지 않게 — 무작위 대신 칸 번호로, 할당 없음)
- 드래그 중(`DragStarted`)엔 그 뷰 Yoyo 를 멈추고 `Model` 을 원래 높이로 · `DragEnded` 때 다시
- 뷰가 풀로 돌아갈 때(칸이 비면) 트윈을 `Pause` — 다시 꺼내질 때 위 이벤트에서 `Play`

### 2. 점액 출렁임 — 스쿼시 · 스트레치
- `SlimeSpawned(view)` → 켜진 모델의 `localScale` 을 (가로 ↑ 세로 ↓) ↔ (가로 ↓ 세로 ↑) Yoyo — 피벗이 바닥이라 바닥에 붙은 채 출렁임 (`_아트납품.md` A04). 세기 · 주기 `FxConfig`. 변이 점액은 더 느리고 묵직하게 (`slimeWobbleMutant…`)
- `SlimeKilled` · `SlimeReachedHatch` → 그 뷰 트윈 `Kill` 이 아니라 **`Pause` + 스케일 원복** (풀 재사용 — S3 규칙 4 「풀 반납 시 Kill」 대신 뷰가 풀 안에서 재사용되므로 트윈도 재사용. 둘 중 하나로 통일하고 보고)
- 처치 순간 납작해지며 흩어지는 연출은 **U05**

### 3. 머지 Sequence (`DroneMerged(from, to, type, newGrade)`) — 전체 = `mergeLockDuration`
1. **끌려옴** — 놓은 순간 `to` 뷰 `Model` 이 놓은 쪽(`from` 방향)으로 살짝 밀려 있다가 제자리로 (짧게)
2. **Scale** — `Model` 0.8 → 1.25 → 1.0 (`FxConfig.mergeScale…`)
3. **Punch** — 마지막에 `DOPunchScale` 약하게
4. **Color · 빛** — 칸 위에 이펙트 풀에서 **`FX_Ring` 퍼짐 + `FX_Spark` 몇 개 + `FX_Glow_Dot` 섬광**, 색 = 새 등급 드론의 `UnitData.TintColor` (흰 틴트 텍스처 — A10). 머티리얼 색 대신 이펙트로 표현 (아트 프리팹은 MPB 틴트를 끔 — G07)
- 같은 칸에서 연출 도중 또 머지가 오면 앞 Sequence 를 `Complete` 하고 새로 (잠금 시간 때문에 드묾)
- 「머지 순간 등급 색이 바뀐다」 = 등급 부품(링 · 포드)이 붙는 순간과 섬광이 겹치게 — 부품 토글은 R3 `DroneView.Show` 가 이미 함
- 머지 소리는 U08

### 4. 소환 팝 (`DroneSpawned`)
- `Model` 0 → 1.1 → 1.0 짧게 + 칸에 작은 `FX_Ring`. 소환 소리는 U08

### 5. 이펙트 풀 (`FxPool`)
- 링 · 반짝임 · 섬광 프리팹별로 **시작 때 미리 만든다** (크기 = `FxConfig` 값, 동시 머지 몇 번 분량). 모자라면 가장 오래된 것을 재사용 (새로 만들지 않음)
- 이펙트 트윈은 `SetAutoKill(false)` + `Restart` · 끝나면 비활성. U05 · U06 이 같은 풀을 쓰게 일반화 (종류 enum 또는 프리팹 키)
- 블렌딩은 A10 표 그대로 (Ring 가산(알파 가능) · Spark · Glow_Dot 가산)

## 숫자를 코드에 쓰지 않는다
- 진폭 · 주기 · 크기 · 풀 크기 · 이펙트 크기는 `FxConfig`. 머지 전체 길이는 `GameConfig.mergeLockDuration` 을 읽는다 (복사 금지)

## 금지 사항
- ❌ 뷰 **루트** 트랜스폼 트윈 (R3 가 매 프레임 정함 — 섞이면 드래그 · 이동이 튄다)
- ❌ R3 파일 · 프리팹 (`DroneView` · `SlimeView` · `Drone_*` · `Slime_*`) 수정 — 필요하면 R3 전달 요청
- ❌ 이벤트 핸들러 · 트윈 콜백 할당 (`new` · 람다 캡처 매번 생성 · `string`) — 트윈은 뷰별 · 이펙트별로 한 번 만들어 재사용
- ❌ 처치 · 코인 · 데미지 숫자 (U05) / 배너 · 피격 (U06) / 발광 · 블룸 (U07) / 소리 (U08)
- ❌ 테스트 뒤 전역 `AssetDatabase.SaveAssets` (보류함 5번) / 씬 저장 때 UIRoot 가짜 오버라이드 커밋 (README 8장 「씬 저장 주의」)
