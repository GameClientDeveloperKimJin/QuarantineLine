## 쓰는 이벤트 (V02)
| 이벤트 | 연출 |
|---|---|
| `SlimeDamaged(view, damage, source)` | 데미지 숫자 |
| `SlimeKilled(view)` | 납작 터짐 + 코인 튀어나옴 (직접 · 잔열 처치 모두) |

| `SlimeSpawned` · `SlimeKilled` · `SlimeReachedHatch` | 불꽃 대상 목록 관리 |

## ⚠ 점액은 죽는 즉시 풀로 돌아간다
`SlimeRegistry.Despawn` 은 `SlimeKilled` 직후 같은 프레임에 `Release` 한다 → **죽은 점액 자체를 트윈하지 않는다** (바로 다른 점액으로 재사용됨). 대신:
- `SlimeDeathFx` = 풀에 든 **대역** 오브젝트. `SlimeKilled` 순간 켜진 `Model_A/B` 의 `sharedMesh` · `sharedMaterial` · 월드 위치 · 크기 · 회전을 복사해 그 자리에서 재생 (복사는 참조 대입 — 할당 없음)
- 대역 연출: 납작(y 1 → 0.15, xz 1 → 1.5) 0.18초 + 페이드 → 꺼짐. 바닥에 `FX_Slime_Splat` 퍼짐 0.25초 → `FX_Slime_Puddle` 0.6초 뒤 사라짐. 초록 반짝임 몇 점
- 점액 루트 · 자식은 여전히 건드리지 않는다 (U04 규칙)

## 1. 데미지 숫자
- 월드 위치 → 화면 좌표의 **UI 숫자 풀** (TMP, 오버레이 캔버스 한 장). 점액 머리 위에서 튀어 오르며(Jump) 위로 · 페이드, 0.5초
- 글자 최소 24px (S3 규칙 8), 큰 피해(≥ 기준값, FxConfig)는 더 크고 종류색. 기본 흰색
- **겹침 방지**: 같은 점액에 0.12초 안에 또 맞으면 새 숫자를 띄우지 않고 떠 있는 숫자에 **합산 + 톡 튐**. 서로 다른 점액 숫자는 x 무작위 ±오프셋
- 잔열 피해는 숫자 없음 (보류함 6 결정 — 이벤트도 안 옴)
- 풀 크기 FxConfig (시작 24), 모자라면 가장 오래된 것 재사용

## 3. 코인 비행 · 꽂힘 · 굴림
- `SlimeKilled` 위치에서 코인(`UI_Icon_Coin`) 1개가 톡 튀어 올랐다가 곡선(DOPath 또는 2단 트윈)으로 HUD 코인 아이콘까지 0.45~0.6초 비행 (거리 비례, FxConfig)
- 도착 순간: HUD 코인 아이콘 펀치 + **그 코인 몫만큼** HudCoin 숫자 굴림. 진짜 지갑(`Wallet`)은 이미 바뀌어 있다 — 표시만 늦게 따라간다. 소환 버튼 비용 · 가능 여부는 지금처럼 지갑 기준
- 웨이브 클리어 보너스(`CoinChanged` delta > 0 인데 처치가 아님): 화면 가운데에서 코인 여러 개(FxConfig, 시작 8) 흩뿌려 차례로 날아감
- 소환 지출(delta < 0)은 지금처럼 바로 굴림
- **겹침 방지**: 동시에 나는 코인 최대 수(FxConfig, 시작 16). 넘치면 새 코인은 날리지 않고 그 몫을 바로 표시에 더한다. 판이 끝나면(`GameEnded`) 날던 코인 몫을 전부 즉시 반영 — 결과 화면 전에 숫자가 맞아야 한다
- 일시정지 중엔 멈춘다 (timeScale 0 따라감). 결과 화면 트윈만 SetUpdate(true)

## 4. 잔열 불꽃 (보류함 6)
- `SlimeCombat.Burning` 인 점액 위에 주황 불꽃(가산 — `FX_Glow_Dot` · `FX_Spark` 틴트, 작은 위로 솟는 반짝임 + 깜빡이는 빛) 표시. 꺼지면 바로 사라짐
- 점액에 붙이지 않고(부모 변경 금지) **LateUpdate 에서 위치만 따라감**. 대상 목록은 이벤트로 관리 (생성 · 제거 시 할당 없음 — 미리 만든 배열/풀)
- 불꽃 풀 크기 FxConfig (시작 16)
