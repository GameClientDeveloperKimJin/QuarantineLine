## 1. 웨이브 경고 배너
- 화면 가운데 위쪽(준비 카운트다운 숫자와 겹치지 않는 높이)에 `UI_Panel_Warning` + `UI_Icon_Warning` + 스캔라인 홀로그램 띠. 윗줄 「WAVE 2 / 3」, 아랫줄 `banner` 문구 (예: 「C-2 화물칸, 변이 반응 감지」)
- 등장: 가로로 펼쳐짐(scaleX 0 → 1) + 깜빡임 2번 → 1.2초 유지 → 접히며 사라짐. 전체 ≈ 1.8초 (FxConfig)
- **판정 · 입력을 막지 않는다** — Raycast Target 끔. 마지막 웨이브는 색 · 문구 강조(「FINAL WAVE」 등, FxConfig 문자열)
- 글자 최소 24px (S3 규칙 8)

## 2. 해치 경고등
- 무대 `Posts` (A09 M2 경고등 기둥) 의 발광 부분을 **MaterialPropertyBlock** 으로 점멸 (`_EmissionColor` 세기). 재질 · 프리팹 파일은 고치지 않는다
- 웨이브 시작: 배너와 함께 2초 빠르게 점멸 → 평소 값. 위기 상태: 느린 붉은 점멸 유지
- 발광 칸 이름을 못 찾으면 보고에 적기 (G09 · U07 에서 정리)

## 3. 점액 히트 플래시
- 맞은 점액의 켜진 `Model_A/B` 아래 Renderer 에 MPB 로 흰색(또는 드론 종류색 섞음, FxConfig) 0.08초 번쩍 → 원래. **트랜스폼 · 재질 에셋은 건드리지 않는다** (U04 규칙 — 크기 트윈과 독립)
- 같은 점액이 연속으로 맞으면 타이머만 다시 시작 (트윈 쌓지 않음)
- 플래시 대상 추적은 미리 만든 배열 (할당 0). `SlimeKilled` · `SlimeReachedHatch` 때 즉시 MPB 비우기
- U05 납작 대역은 sharedMaterial 을 복사하므로 영향 없음 — 확인만

## 4. 해치 피격 — 카메라 · HUD 흔들림
- `SlimeReachedHatch` 마다: `CameraRig.SetShakeOffset` 로 0.25초 흔들림 (세기 FxConfig, 위기 상태면 1.5배). 여러 마리 연속이면 **세기 상한** 안에서 시간만 연장 — 화면이 멀미 나게 쌓이지 않게
- HUD 해치 패널(`HudHatch`) 흔들림 + 깎인 칸 빨강 번쩍
- 끝나면 반드시 `SetShakeOffset(Vector3.zero)`. 일시정지 · 결과 때 즉시 원위치
- timeScale 0 이면 멈춘다 (결과 화면 등장만 SetUpdate(true) 규칙 그대로)

## 5. HP 위기 경고 (`IsCritical`)
- HP ≤ `hatchCriticalHp` 가 되는 순간: 화면 가장자리 붉은 비네트(UI 이미지 한 장, 알파 점멸 느리게) + HUD 해치 패널 붉게 점멸 + 경고등 붉은 점멸(2)
- 게임 영역을 가리지 않게 비네트 알파 상한 FxConfig (시작 0.25). HP 0 → 결과 화면 때 정리
