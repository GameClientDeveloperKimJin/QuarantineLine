## 1. 조명 · 그림자
- 어두운 실내: Environment 조명은 스카이박스 대신 **색 지정** (아주 어두운 남색/청록, 레퍼런스 톤) · 반사 강도 낮게
- 주 조명: 위에서 살짝 비스듬한 Directional 1개 (복도 칸 · 드론 · 점액이 잘 읽히게) · URP 소프트 그림자 · 그림자 거리는 복도 길이만큼 (바깥 더미 그림자가 칸에 안 떨어지게 — G10 4번)
- 복도 안쪽이 바깥보다 밝아야 함 (시선이 복도로)
- 칸 · UI 색 읽기가 나빠지면 안 됨: U03 호버 · 사거리 띠 · F01 머지 표시 · O03 웅덩이가 그대로 보이는지 확인

## 2. 발광 · 블룸 (보류함 10 · 22)
- 발광 마스크 있는 재질 `_EMISSION` 켜고 `_EmissionMap` 연결, `_EmissionColor` 세기 맞춤:
  - 무대: `QL_Stage_{FloorTile,LinePost,LineSill}_Emission` · A11 바깥 `QL_Stage_Outer_*_Emission` (경고등 · 표시등)
  - 점액: 형광 초록 (변이는 지금 색 그대로 더 강하게)
  - 드론 (A13): 종류색만 — 흡입 청록 · 소각 주황 · 냉각 하늘. **흰 몸체는 안 빛남**
- U06 경고등 MPB `_EmissionColor` 가 이제 실제로 보임 → 가산 빛 쿼드와 둘 다 쓰면 너무 밝지 않게 세기 다시 맞춤 (FxConfig)
- Volume: Bloom (Threshold 높게 — 발광만 번지게, 흰 UI · 흰 몸체는 안 번짐) · Tonemapping (ACES 또는 Neutral — 비교 캡처 1장씩 보고 고름) · 필요하면 Vignette 약하게
- **Screen Space Overlay UI 는 블룸 영향 없음** 확인 (Canvas 가 Camera 모드면 보고)

## 3. 안개 · 배경 (보류함 17)
- 카메라 Clear = 단색 (Environment 와 같은 어두운 색) — 카메라 컴포넌트 배경 값만 U07 예외
- 먼 쪽(스폰 게이트 너머) · 바깥 더미가 어둡게 가라앉는 안개 (RenderSettings Linear 또는 Exponential) — 복도 칸은 안개 영향 거의 없게
- 21:9 에서 맨 바깥이 비어 보이는지 p4 로 보고 (판단은 U10)

## 규칙
- 성능: 실시간 조명은 Directional 1개 + 필요하면 Point 몇 개 (그림자 없음). 블룸은 URP 기본 품질. 숫자는 P01~P04 에서 재므로 지금은 「눈에 띄게 무겁지 않게」 만
- 재질 파일 바꾼 목록 전부 보고 (어느 재질 · 무엇)
- ProjectSettings · URP Asset 을 바꿨으면 이유 한 줄

## 테스트 (바꾼 클래스만 — 전체는 마감 직전 1번)
