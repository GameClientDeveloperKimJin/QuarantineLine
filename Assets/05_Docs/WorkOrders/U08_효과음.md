## 할 것
1. `SfxTable` SO — 항목별 클립 · 볼륨 · 피치 무작위 범위 · 같은 소리 최소 간격 · 우선순위 · Mixer 그룹. 코드 수정 없이 바뀌게
2. `SfxPlayer` — `AudioSource` 풀 (8개쯤), 동시 재생 수 제한 · 같은 소리 최소 간격(처치 몰릴 때 0.05초) · 꽉 차면 우선순위 낮은 것 버림
3. 시간: 게임 소리는 일시정지 때 멈춤(`AudioSource.Pause`) · UI 소리(클릭 · 휴게 · 결과)는 멈춤 무시
4. 임포트: 짧은 소리 Decompress On Load · 2D (공간음 없음) · Force Mono
5. Mixer: Master · Sfx · Ui — 볼륨 설정 UI 는 안 만듦 (값만 노출)
