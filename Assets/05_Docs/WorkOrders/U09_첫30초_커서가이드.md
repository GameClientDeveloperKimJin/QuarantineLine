# U09. 첫 30초 커서 가이드
> 🎯 **이 작업은** 처음 하는 사람이 설명서 없이 「소환 → 같은 드론끼리 겹쳐 머지」 까지 하게 만든다 — 첫 판에만 손가락 커서가 드론 투입 버튼을 가리키고, 소환이 되면 같은 종류 · 등급 드론 둘 사이에 드래그 화살표를 그려 주며, 첫 머지가 성공하면 사라진다.

## 단계
| # | 시작 | 보이는 것 | 끝 |
|---|---|---|---|
| 1 | 웨이브 1 준비 시간 시작 (U15 지시서 흡수가 끝난 뒤) | 손가락이 「드론 투입」 버튼을 톡톡 누르는 루프 + 짧은 문구 「드론을 투입하세요 (SPACE)」 | `DroneSpawned` 1번 |
| 2 | 같은 종류 · 같은 등급 드론 2기가 생기는 순간 (없으면 1단계 문구를 「한 번 더」 로 유지) | 두 드론 사이 점선 화살표 + 손가락이 한쪽을 집어 다른 쪽으로 끄는 루프 + 「같은 드론을 겹치면 합쳐져요」 | `DroneMerged` 1번 |
| 3 | 첫 머지 | 가이드 페이드아웃 0.3초 · 끝 (저장) | — |
- 사용자가 화살표와 다른 쌍을 머지해도 3단계로 (머지를 했으면 목적 달성)
- 2단계 중 쌍이 사라지면(이동 · 스왑) 다음 쌍으로 다시 그림, 없으면 1단계로
- 드래그 중(`DragStarted` ~ `DragEnded`)엔 손가락 숨김 (F01 머지 표시가 대신)
- 30초 안에 끝 안 나도 계속 (강제 아님) · 웨이브 2 시작되면 조용히 끝

## 「첫 판」 저장
- `PlayerPrefs` 키 1개 (`QL.GuideDone`, int) — R4 소유 키. 결과 화면 「처음부터 다시」 에선 다시 안 뜸
- 디버그: 에디터 메뉴 또는 인스펙터 체크로 초기화 (빌드엔 영향 없음)

## 화면
- 글자 Bagel Fat One · 24px 이상 · 문구는 짧게 (SO)
- 메신저(U16) · 지시서(U15) · 영수증(U14) 과 겹치지 않는 자리. U15 지시서가 떠 있으면 1단계 대기
- 화살표 · 손가락은 raycastTarget 끔 (클릭 · 드래그 방해 금지)
- 게임 시간 (일시정지 때 멈춤)

## 테스트 (바꾼 클래스만 — 전체는 마감 직전 1번)
- GuideDone 0 → 1단계 표시 · 소환 → 같은 쌍 생김 → 2단계 · 화살표 끝점 = 두 칸 월드 → 화면 위치 (오차 10px)
- 머지 → 끝 · GuideDone 1 · 재시작해도 안 뜸
- 다른 쌍 머지 → 끝 / 쌍 사라짐 → 다음 쌍 또는 1단계
- 지시서 떠 있는 동안 1단계 대기 · 드래그 중 손가락 숨김
- 할당 0 (대기 프레임) · Instantiate 0
