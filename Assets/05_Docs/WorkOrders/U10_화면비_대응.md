## 1. 비율 3종 (1920×1080 · 1920×1200 · 2560×1080)
- Canvas Scaler match 값 재검토 (0.5 그대로 / 높이 기준 1) — 세 비율에서 글자 24px 이상 유지 · 패널 겹침 0
- 모든 HUD 패널 앵커가 모서리 · 가장자리 기준인지 (가운데 고정 패널이 21:9 에서 떠 보이지 않게)
- 연출 패널 (U12 휴게 · U13 결과 · U14 영수증 · U15 지시서 · U16 메신저 · U09 가이드) 각 비율 확인
- 안전 영역: 가장자리 여백 최소 24px

## 2. 스폰 입구 · 게이트 표기판 (보류함 9 · 13)
- 지금: 해치 HP 패널(위 가운데)이 복도 끝 스폰 입구를 가리고, 게이트 표기판 `GateSign` 은 화면 위로 잘림
- 목표: 스폰 직후 점액이 패널 아래로 보이고, 표기판 「C-1」 이 보이거나 (안 보이면 지우는 게 낫다고 판단되면 보고)
- 조정 순서: ① 해치 패널 높이 · 위치 줄이기 → ② `CameraRig` `pitch` · `margin` 값 (코드 아님) → ③ 그래도 안 되면 R1 보고 (R3 카메라 작업)
- 값을 바꾸면 그리드 · 격리선이 세 비율 모두 화면 안 · 드래그 정확도 그대로 (기존 드래그 테스트 통과)

## 3. 창 · 전체 화면
- 창 모드 크기 조절 시 레이아웃 따라감 (Resolution 바뀜 → CameraRig 이미 재계산, UI 는 Scaler)
