## 배치 (위에서 아래로, 와이어프레임 그대로)
| 줄 | 승리 | 패배 |
|---|---|---|
| ① 헤더 | 초록 띠 · 체크 아이콘 · 「격리 성공」 · 부제 「C-3 화물칸 · 3웨이브 모두 방어」 | 빨강 띠 · X 아이콘 · 「격리 실패」 · 부제 「웨이브 2에서 해치 HP 0」 |
| ② 진행 | 「웨이브 진행」 + 오른쪽 `3 / 3` + 웨이브 수만큼 칸 막대 (깬 웨이브 채움) | 같은 틀, 도달 웨이브까지 빨강 채움 · 나머지 빈 칸 |
| ③ 지표 2칸 | 첫 칸(강조 테두리) 「14/20 · 남은 해치 HP」 / 둘째 「96 · 제거한 점액」 | 첫 칸 「2/3 · 도달한 웨이브」 / 둘째 같음 |
| ④ 정보 줄 | 「웨이브 클리어 보너스 · +150 코인」 | 「많이 뚫린 레인 · 3레인」 |
| ⑤ 버튼 | 「다시 하기」 · 「타이틀로」 (둘 다 같음) | 같음 |
| ⑥ 키 안내 | 「R 다시 하기 · Esc 타이틀로」 | 같음 |

- **와이어프레임은 배치 · 비율만.** 색 · 판은 지금 UI 키트(A08 · 어두운 홀로그램 패널)로 입힌다 — 흰 배경 금지. 초록 · 빨강은 헤더 띠 · 막대 · 강조 테두리에만, `FxConfig` 값으로
- 체크 · X 아이콘: 지금 엠블럼(`UI_Emblem_Victory/_Defeat`)을 헤더 아이콘 자리로 줄여 쓴다. 맞는 그림이 없으면 보고에 적기 (아트 요청은 R1 이)
- 「최고 등급 드론」 줄은 **뺀다** (와이어프레임에 없음). `MaxGradeDrones` 필드는 남겨도 됨
- 글자 최소 24px (S3 규칙 8)
- 부제 「C-3 화물칸」 은 Inspector 문자열 (스테이지 이름 · 나중에 데이터로)

## 필요한 값 (ResultSummary 에 추가)
| 값 | 출처 |
|---|---|
| `WaveReached` (1부터) · `WaveCount` | `GameFlow.WaveIndex + 1` · `GameFlow.WaveCount` |
| `WavesCleared` | 승리 = WaveCount, 패배 = WaveReached − 1. **막대 채움 수는 승리 WaveCount · 패배 WaveReached** (그림 「도달 웨이브까지 빨강」, R1 확정 2026-11-10) |
| `BonusEarned` | 판 동안 GameLoop 가 `Wallet.Add(step.ClearBonus)` 한 합 |
| `MostBreachedLane` (1부터) · 그 횟수 | `SlimeReachedHatch` 때 `SlimeView.Lane` 별로 GameLoop 가 센다. 동점이면 낮은 번호. 한 번도 안 뚫렸으면 「없음」 |
- 집계는 지금처럼 판 끝 `Collect` 1회 + 판 중 int 카운터만 (할당 없음)

## 입력 · 흐름
- `GameLoop.GoToTitle()` 신설: `timeScale = 1` → Title 씬 로드 (U01 이 Build Settings 에 넣은 씬)
- 결과 상태에서만: **R = Restart · Esc = GoToTitle**. Esc 는 지금처럼 GameLoop 한 곳에서 읽는다 (G06 규칙). 결과 아닐 때 R 은 아무것도 안 함
- 버튼 「다시 하기」 = `Restart` · 「타이틀로」 = `GoToTitle`
- 등장 연출은 지금 ScreenFader 그대로 (`SetUpdate(true)`). 추가로 진행 막대 칸이 차례로 차오르기(칸당 ~0.08초, FxConfig) 정도만 — 과하게 넣지 않는다

## 테스트
- 기존 PlayMode 결과 테스트 갱신 + 추가: 승리 · 패배 각각 헤더 문구 · 첫 지표 · 정보 줄 값, Esc → Title 씬, R → 같은 씬 재로드
- EditMode 전부 통과 유지
