## 화면 (시안 1-5)
- 어둡게 Dim 검정 60% (U01 의 불투명 Backing 은 이 카드에선 빼도 됨 — 시안처럼 뒤 게임이 흐리게 보이게)
- 카드 560×560 가운데, 홀로그램 패널 (A08 `UI_Panel_Main`, 청록 테두리)
- 커피잔 그림 + 김 3줄 → **A12 납품 `UI_Cup` · `UI_Steam`** (도착 전엔 임시 그림, 같은 파일 이름으로 바꿔 끼우기)
- 제목 「휴게 시간」 · 상태 줄 「근무 중 02:41 · 웨이브 2 / 3 · 해치 14/20」 (숫자 강조색)
- 버튼: **업무 복귀 `ESC`** (주 버튼, 청록) = HandleEscape · **처음부터 다시** = Restart · **퇴근하기** = GoToTitle
- 팁 줄 (점선 테두리) 「TIP 같은 드론 두 대를 겹치면 상위 모델로 결합돼요」 — `TipTable` SO 의 문자열, 6초마다 다음 것으로 크로스페이드 0.2초 (처음 열 때 무작위 시작)
- 글자 최소 24px

## 값
- **근무 시간** = `Time.timeSinceLevelLoad` (timeScale 따라감 → 일시정지 시간 자동 제외, 다시 하기 = 씬 재로드로 0). `SetText("{0:00}:{1:00}")`
- 웨이브 = `Flow.WaveIndex + 1` / `WaveCount` · 해치 = `Flow.Hatch.Hp` / `MaxHp`. **열 때 1회** 채움

## 시퀀스 (전부 `SetUpdate(true)` — 원본 표 그대로)
- 0.00 Dim 0 → 0.6 (0.2초) · 0.05 카드 Scale 0.9 → 1 OutBack + Fade (0.25초)
- 루프: 김 3줄 `DOLocalMoveY +12` + Fade, 1.2초 Yoyo, 0.3초씩 어긋남 · 팁 6초 교체 (`DOVirtual.DelayedCall(...).SetUpdate(true)`)
- 복귀: 거꾸로 0.15초 → **끝난 뒤** 재개가 아니라, 재개는 지금처럼 GameLoop 가 즉시 한다 (판정 우선 — S3 규칙 3). 카드 닫힘 연출만 0.15초
- 닫힐 때 루프 트윈 전부 Pause/Kill → 대기 프레임 할당 0
- Sequence 는 한 번 만들어 `SetAutoKill(false)` + `Restart()` (원본 DOTween 규칙)

## 규칙 · 예외 (원본 + 확인)
- 결과 화면 중엔 안 열림 (Result 상태 Esc = GoToTitle 그대로)
- 열리는 순간 드래그 중 드론은 원래 칸 (지금 HandleEscape 가 drag.Cancel — 확인만)
- 열려 있는 동안 그리드 · 소환 · Space 막힘 (`CanAct` false — 확인)
- Alt+Tab 으로 열린 뒤 돌아와도 카드는 그대로, 업무 복귀를 눌러야 재개

## 테스트
- Esc · 버튼 · `OnApplicationFocus(false)` 세 경로 모두 Paused + 카드 켜짐 · Esc 로 닫힘
- 이미 Paused · Result 에서 포커스 잃음 → 상태 변화 없음
- timeScale 0 에서 카드 · 김 · 팁 트윈이 진행됨 (팁 6초 교체 확인)
- 근무 시간 = 일시정지 전 값과 같음 (일시정지 3초 뒤에도 안 늘어남)
- 퇴근하기 → Title 씬 · timeScale 1 / 처음부터 다시 → 같은 씬 재로드 · timeScale 1
- 열려 있는 동안 Space · 클릭 → 소환 · 드래그 없음
- 기존 테스트 전부 통과
