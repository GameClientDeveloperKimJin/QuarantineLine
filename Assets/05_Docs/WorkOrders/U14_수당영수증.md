## 트리거 · 범위
- `WaveCleared` 중 **마지막 웨이브가 아닐 때만** (index < WaveCount − 1). 마지막 웨이브는 결과 화면(U13)이 보너스를 보여 줌
- **U05 웨이브 클리어 보너스 코인 흩뿌림은 없앤다** (영수증이 대신. 마지막 웨이브는 GameEnded 즉시 맞춤 그대로)
- **보류함 21 후속**: `CoinFlyFx` 의 「같은 프레임 SlimeKilled 보상액 짝짓기」 → `KillRewarded(slime, reward)` 로 바꿈 (추정 제거)

## 화면 (시안 1-4)
- 코인 패널 바로 아래 (앵커 Top Right, Pivot Top). 일시정지 버튼 · 코인 패널과 겹치지 않음
- 종이 `UI_Paper` (**Image Type Tiled** — 점선 주기 8px) + 아래 `UI_Paper_TornBottom` (가로 반복)
- 줄: 「청소 수당 명세」 · 팀 이름 「정거장 청소 · 격리 1팀」 → 「웨이브 N 근무 완료」 → 항목 줄 (「클리어 수당 +50」 · 「오염 칸 청소 ×2 +20」 — **값 0 인 줄은 안 띄움**, 미리 만든 줄 최대 4 켜고 끔) → 「합계 +70」 → 바코드 → 「다음 근무 · 웨이브 N+1」 → 「지급」 도장 (`UI_Stamp_Paid`, 각도 무작위 −14°~−8°)
- 문구는 SO 또는 Inspector 문자열 (팀 이름 · 항목 이름)
- 화면 위 가운데 배너 「웨이브 N 클리어!」 (U06 꺼 둔 WaveBanner 를 재사용해도 됨) · 글자 최소 24px

## HUD 코인 표시값 (원본 규칙)
- 실제 지갑은 `CoinChanged` 순간 이미 늘었다. HUD 표시값만 영수증 끝(1.9초)에 따라감 — **표시 목표 = 지갑 − 날고 있는 처치 코인 몫 − 진행 중 영수증 합계**
- 소환 버튼 가능 여부는 지금처럼 실제 지갑 기준
- 영수증 중 소환(지출) → 지출은 바로 굴림, 마지막 굴림 목표는 그 시점 실제값으로 다시 잡음
- `GameEnded` · 다시 하기 → 즉시 실제값 (U05 규칙 그대로)

## 테스트
- 웨이브 0 · 1 클리어 → 영수증 켜짐, 마지막 웨이브 → 안 켜짐 · 배너도 0 · 1 만
- 청소 0 회 → 청소 줄 꺼짐 · 2 회 → 「×2 +20」 · 합계 = `Pay.Total`
- 2.0초 뒤 HUD 표시 = 지갑 (영수증 중 소환 섞은 경우 포함)
- 끝남 알림 1회 · `IsPlaying` false
- 일시정지 중 영수증 멈춤 → 재개 후 이어서
- `KillRewarded` 로 코인 비행 · 짝짓기 코드 없음 · 보너스 흩뿌림 없음
- 연출 프레임 이후 할당 0 · Sequence 재사용
