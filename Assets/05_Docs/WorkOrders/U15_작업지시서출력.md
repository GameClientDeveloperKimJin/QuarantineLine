## ⚠ 준비 카운트다운과 겹침 (R1 결정)
- U02 가운데 큰 카운트다운(`HudCountdown`)이 준비 시간 내내 화면 가운데 위에 뜬다 → 지시서 종이(해치 패널 아래 ~430px)와 겹침
- **지시서가 화면에 있는 동안(출력 ~ 흡수 끝) 카운트다운 숨김** → 흡수가 끝나면 남은 초부터 다시 보임. 카운트다운 숫자 · 타이밍 로직은 그대로
- 준비 5초 웨이브: 영수증 2.0 + 지시서 1.7 = 3.7초 → 카운트다운은 마지막 1초쯤만 보임. 괜찮다 (지시서가 「온다」 역할). 겹치면 안 되는 것만 지킨다

## 화면 (시안 1-1)
- 화면 위 가운데, **해치 HP 패널 바로 아래** (앵커 Top Center, Pivot Top). 21:9 · 16:10 에서도 해치 패널과 겹치지 않음
- 슬롯 `UI_Slot` (청록 발광 선) → 종이 `UI_Paper` (Tiled) 가 아래로 출력 (RectMask2D 높이 0 → 끝)
- 머리: 「작업 지시서」 · 「No. C3-W0n」 · 「정거장 청소 · 격리 1팀」
- 줄 (왼쪽 라벨 · 오른쪽 값, 항목당 TMP 2개): 현장 「C-3 화물 브릿지」 · 작업 「외계 점액 격리」 · 예상 오염량 「점액 28 · 변이 3」 · 주의 레인 「3레인 (변이 반응)」 / 변이 0 이면 「없음」 · 담당 「청소 · 격리 담당」 — 현장 · 작업 · 담당 문구는 `WaveOrderText` SO (웨이브별 현장 이름 가능)

- 글자 최소 24px — 시안보다 종이가 커져도 됨 (가로 폭은 해치 패널 폭 안)

## 시퀀스 (게임 시간 — 일시정지 때 멈춤 · Sequence 한 번 + Restart)
| 시점 | 대상 | 동작 |
|---|---|---|
| 0.00 | 슬롯 | 발광 Fade 0 → 1, 0.15초 |
| 0.10 | 종이 | 높이 0 → 끝 0.45초 OutQuad + ShakeRotation(0.3초, 2°) |
| 0.60 | 도장 | Scale 1.6 → 1, 0.18초 InBack + Fade |
| 0.78 | 종이 · 카메라 | PunchScale(0.04) + 작은 카메라 흔들림 |
| 1.20 | 종이 | Scale 1 → 0.1 + 웨이브 패널 위치로 이동 0.4초 InQuad |
| 1.60 | 웨이브 패널 | PunchScale(0.12) 0.2초 |
- **종이 클릭 → 바로 1.20 흡수로 건너뜀**. 종이 밖은 raycastTarget 끔 — 연출 중에도 소환 · 머지 됨

## 테스트
- 웨이브 1 · 2 · 3 준비마다 1번 재생 · 값 = `forecast` (SlimeCount · MutantCount · CautionLane+1 / 「없음」)
