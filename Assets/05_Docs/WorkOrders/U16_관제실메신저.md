## 트리거 (우선순위 1 = 가장 높음)
| # | 트리거 | 우리 이벤트 | 대사 (OpsLineTable 초안 — 원본 표) | 핑 위치 |
|---|---|---|---|---|
| 1 | 해치 HP 위기 (판에 1번) | `HatchHpChanged` + `Flow.Hatch.IsCritical` 처음 true | 「해치 얼마 안 남았어요! 퇴근은 해야죠!!」 | — |
| 2 | 변이 점액 등장 | `SlimeSpawned` 중 `Type == Mutant` | 「{lane}레인 또 샜어요!! 변이 점액이에요. 냉각 드론 붙여 주세요」 | 그 점액 위치 (게이트 쪽) |
| 3 | 해치 피격 | `SlimeReachedHatch` (`slime.Lane`) | 「{lane}레인에서 뚫렸어요. 청소비 누가 내요…」 | 그 레인 격리선 |
| 4 | 칸 오염 | `CellContaminated(cell, lane, …)` | 「드론이 점액에 묻었어요. 같은 드론으로 결합하면 씻겨져요!」 | 그 칸 |
| 5 | 3등급 결합 (판에 1번) | `DroneMerged` 의 newGrade = 최고 등급 | 「오, 상위 모델 승인됐습니다. 예산 팀이 울겠네요」 | — |
- `{lane}` = **1부터** (화면 표기). 같은 트리거 대사는 목록 순서대로 돌림
- 대사 · 우선순위 · 핑 여부 전부 SO — 코드 수정 없이 바뀌게

## 규칙 (원본)
- 전체 쿨다운 8초. 쿨다운 중 **더 높은 우선순위**(숫자 작음)가 오면 바로 띄움. 같거나 낮으면 버림 (쌓아 두지 않음)
- 같은 프레임에 여러 개 → 가장 높은 것 하나
- 화면 말풍선 최대 2개 (새 것 아래 · 이전 것은 위로 밀리며 흐려짐 `UI_Bubble_Dim`)
- 휴게 시간 · 결과 화면 중엔 새 메시지 없음 (Paused · Result 상태면 무시, 게임 시간이라 떠 있는 것도 멈춤)
- `{lane}` 치환으로 메시지당 문자열 1회 할당 허용. 대기 프레임 할당 0
- 말풍선 · 핑은 풀 (Instantiate 0회)

## 화면 (시안 1-3)
- 머리: 초록 점 「관제실 채널 · 업무 중」 · 오른쪽 플레이 시간 (`Time.timeSinceLevelLoad`, U12 근무 시간과 같은 값)
- 말풍선: 아바타 `UI_Avatar_Ops` · 이름 「박 대리 · 관제실」 · 본문. 새 말풍선은 주황 테두리 `UI_Bubble`
- 입력 줄 「김 사원 입력 중 ●●●」 (이름 SO)
- 핑: 월드 공간 링 3개 (`FX_Ring` 가산, 주황), 바닥에서 퍼짐

## 시퀀스 (게임 시간)
| 시점 | 대상 | 동작 |
|---|---|---|
| 0.00 | 입력 줄 | 「입력 중」 표시, 점 3개 Fade 루프 0.1초씩 어긋남 |
| 0.50 | 이전 말풍선 | 위로 +84 + Fade 1 → 0.45, 0.2초 |
| 0.50 | 새 말풍선 | Scale 0.6 → 1, 0.25초 OutBack (입력 줄 숨김) |
| 0.50 | 핑 | 링 3개 Scale 0.5 → 2 + Fade 1 → 0, 1초 × 2회 |
| 4.50 | 가장 오래된 말풍선 | Fade 0 + 높이 0, 0.25초 → 풀 반납 |
