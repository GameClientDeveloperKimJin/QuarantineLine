## 화면 (시안 1)
- 배경 어둡게 (U12 Dim 재사용) · 위 제목 「업무 지원 신청」 · 부제 「웨이브 N 근무 완료 · 다음 근무 웨이브 N+1 · 1장을 승인하세요」
- 카드 3장 (`UI_Card_Frame` + `UI_Card_Tag` 분류 색 틴트 + `UI_Card_Icon_Cxx`) — 분류 · 번호 · 아이콘 · 이름 · 설명 (`{value}` 치환) · 큰 수치 · 종류 배지 (지속 · 횟수형 · 즉시 / C12 「웨이브 3 한정」) · 아래 결재란 · 「중첩 n / max」
- 카드 아래 1 · 2 · 3 키캡 (A16 `UI_KeyCap` 재사용)
- 아래 「적용 중 지원」 줄 — 이미 고른 칩들 + 빈 칸 「이번 선택」
- 호버 = 살짝 커지고 뜸 (1.05 · Y+10, 0.12초) · 클릭 또는 1 · 2 · 3 → `GameLoop.PickSupport(i)` (G13 이름 확인) · **첫 입력만, 연출 중 잠금**

## 연출 시퀀스 (기획서 표)
| 시점 | 대상 | 동작 |
|---|---|---|
| 0.00 | 배경 | 어둡게 0 → 0.5 (Linear 0.85 규칙 — U12 와 같게), 0.2초 |
| 0.15 | 카드 3장 | 아래 +80 → 0, 0.3초 OutBack, 0.08초씩 |
| 선택 | 고른 카드 | 「승인」 도장 (`UI_Stamp_Approved`) Scale 1.6 → 1 0.15초 InBack + 카드 펀치 0.05 |
| +0.15 | 나머지 2장 | 아래 −60 + Fade 0, 0.2초 |
| +0.45 | 고른 카드 | HUD 칩 자리로 Scale 1 → 0.2 + 이동 0.35초 InQuad → 칩 펀치 |
| +0.80 | 게임 | 화면 닫힘 → G13 이 준비 시간 재개 → U15 작업 지시서 |
- U14 영수증이 끝난 뒤에 열림 (G13 이벤트 순서) · U15 지시서는 선택 뒤에

## HUD 「적용 중 지원」 칩 (시안 2)
- 웨이브 패널 바로 아래 (`UI_Chip` 9-slice) — 아이콘 (64) · 이름 · 수치 · 횟수형은 「남은 n」 배지 (`UI_Chip_Count`) · C12 「발동 중」 은 웨이브 3 에서만 밝게
- 최대 2장 (판당 선택 2번) — 같은 카드 중첩이면 칩 하나 「×2」
- 마우스 올리면 툴팁 (카드 이름 · 번호 · 효과 · 현재 최종 값 예: 「3등급 흡입 드론 45 → 67.5」 — G13 읽기 API)
- 보정값 바뀌면 (G13 이벤트) 갱신 · 할당 0

## C14 종류 선택 창 (결정기록 K02)
