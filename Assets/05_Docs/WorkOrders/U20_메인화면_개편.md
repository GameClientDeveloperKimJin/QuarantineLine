## 사람 결정 (2026-11-12)
- **배경 = 이미지** (A16 `UI_Title_Bg`, 3D 아님). 선택: `UI_Title_Bg_Glow` 로 해치 초록 · 천장 조명 은은한 숨쉬기
- **사원 카드 = 시안 값 고정**: 「사원」 · 「격리 1팀 사원」 · 「사번 QL-0427」 · 「최고 평가 A」 · 「주임 승진까지 340 / 500」 + 진행 바 68% — **문구 · 값은 SO** (나중에 직급 시스템이 생기면 값만 연결)
- **근무 기록 = 비활성 (준비 중)**: 메뉴엔 보이되 흐리게, 누르면 작은 「준비 중」 토스트

## 화면 (시안 그대로 — 1920×1080 기준 좌표는 시안 ÷ 2)
- 왼쪽 위 로고 `UI_Logo_Main`
- **출근하기** 큰 버튼: ▶ · 「출근하기」 · 부제 「C-3 화물 브릿지 · 경보 2단계」 (SO) · 오른쪽 [ENTER] 키캡. 바깥 발광 · 호버 · 눌림 (U03 3상태 재사용)
- 메뉴 3줄 (왼쪽 세로 막대 + 글자): **근무 기록** (비활성) · **설정** (기존 U01 해상도 · 창 모드 패널 + U10 DisplayModeToggle 재사용 — 시안 톤으로 다시 입힘) · **퇴근하기** [ESC] (`Application.Quit`, 에디터에선 Play 종료)
- 오른쪽 위 사원 카드 `UI_Title_Card` + 배지 `UI_Title_RankBadge`
- 왼쪽 아래 「Prototype v0.1 · Unity 6」 (버전은 `Application.version`)
- 오른쪽 아래 단축키 안내: [ENTER] 출근 · [↑↓] 선택 · [ESC] 퇴근
- 글꼴: 시안은 두 글꼴처럼 보이지만 **Bagel Fat One 하나** (규칙 8) — 작은 글자 · 사번 · 버전도 Bagel, 24px 이상 (1080 기준)

## 조작
- ↑↓ 로 출근하기 → 근무 기록 → 설정 → 퇴근하기 이동 (선택 표시 = 왼쪽 막대 밝게 + 글자 흰색), ENTER 실행, ESC 퇴근 (설정 패널이 열려 있으면 ESC = 패널 닫기)
- 마우스 호버 = 선택과 같음

## 연출 (가볍게)
- 들어올 때 배경 페이드 0.4초 → 로고 · 버튼 · 메뉴 · 카드 순서대로 0.08초씩 어긋나 올라옴
- 배경 Glow 숨쉬기 (3초 주기, 알파 0.6 ↔ 1)
- 출근하기 누르면 버튼 펀치 → 화면 어두워지며 다음 씬

## M01 연결
- 출근하기 → 다음 씬 이름을 고르는 곳을 **한 메서드**로 둔다 (`NextSceneName()` 같은 것). 지금은 `Game`. R7 M01 이 그 한 메서드만 고쳐 「처음이면 Intro」 로 바꿈 (M01 지시서의 Title 1줄과 같은 자리)

## 테스트 (새 기능 — 관련 클래스 + 마감 직전 전체 1번)
