# U22. 본문 글꼴 얇게 (Pretendard 추가)
> 🎯 **이 작업은** 「글꼴 Bagel Fat One 하나」 규칙을 바꿔 (사람 2026-11-13 「얇게 하고 싶다」), 설명문 · 작은 글자는 얇은 본문 글꼴 **Pretendard** 로 바꾸고, 제목 · 큰 숫자 · 버튼 · 로고 느낌 글자는 Bagel Fat One 그대로 둔다.

|---|---|

| 선행 | 없음 (Unity 비어 있을 때) |

| 예상 | 1시간 |

## 글꼴
- **Pretendard** (SIL OFL 1.1, 무료 상업 이용) — `https://github.com/orioncactus/pretendard` 릴리스에서 받음. 굵기 **Medium (500)** 을 기본 본문, 강조용 **SemiBold (600)** 1개 더 (둘만). 라이선스 파일 같이 넣음
- TMP 폰트 에셋은 Dynamic (Atlas 2048, 필요하면 Fallback) — 기존 Bagel 에셋은 그대로

## 어디를 바꾸나
| Pretendard (얇게) | Bagel Fat One (그대로) |
|---|---|
| 설명문 · 카드 설명 · 툴팁 · 말풍선 본문 (메신저 · 튜토리얼) · 영수증 · 지시서 항목 줄 · 휴게 팁 · 사원 카드 작은 글자 (사번 · 승진까지) · 버전 표기 · 단축키 설명 글자 · 설정 패널 라벨 | 화면 제목 (업무 지원 신청 · 휴게 시간 · 결과 도장) · 큰 숫자 (웨이브 · HP · 코인 · 카운트다운 · 데미지) · 버튼 글자 (출근하기 · 드론 투입 · 작업 시작) · 카드 이름 · 큰 수치 · 로고 · 게이트 표기판 |
- 애매하면 「한 줄이 문장이면 Pretendard, 단어 · 숫자 하나면 Bagel」
- 크기: Pretendard 는 같은 pt 에서 작아 보임 → 본문은 지금 크기 +2~4 (최소 24px 규칙은 그대로)
- 색 · 정렬 그대로. 넘치면 줄바꿈 · 박스 크기만 조정

## 확인 (테스트 · 캡처 최소 — 사람 지시)
- 컴파일 에러 0 · 콘솔 경고 0
- 📷 2~3장만 (메인 화면 · 카드 선택 · 튜토리얼 말풍선) 전후 — 사람이 플레이로 최종 확인
