## 연출
- 그림: 전체 화면 (화면비 달라도 꽉 채움 — 잘림 허용, 레터박스 X · U10 규칙) · 컷마다 아주 느린 줌인 (1.00 → 1.05) · 컷 사이 0.4초 크로스페이드
- 자막: 하단 가운데 · 반투명 검은 띠 · **Pretendard SemiBold** (U22 — 문장) · 1080p 기준 40~46px · 한 글자씩 타자 (빠르게, 0.6초 안에 다 나옴)
- 자동 넘김: 자막 다 나온 뒤 2.5초 (컷당 약 3~3.5초, 전체 약 45초)
- **클릭 · Space · Enter** = 자막 타자 중이면 바로 다 보이기, 다 보였으면 다음 컷
- **건너뛰기**: 오른쪽 위 「건너뛰기」 버튼 (Bagel) + ESC — 누르면 바로 Game
- 1번 컷 시작: 화면 노이즈 0.3초 (가능하면 — 없어도 됨) · 14번 컷 끝: 검게 페이드 → Game
- 컷 진행 표시: 하단 점 14개 또는 「3 / 14」 (작게, 선택)
- 효과음: U08 소리 아직 없음 → 자리만 (14번 도장 컷에 「쾅」 자리)

## 흐름
- Title → Main → (**처음이면** Intro) → Game
- `MainScreen.NextSceneName()`: PlayerPrefs `QL.IntroSeen` 이 0 이면 `"Intro"`, 아니면 기존 그대로 · Intro 끝 (또는 건너뛰기) 에서 `QL.IntroSeen = 1` 저장 후 Game
- 디버그: 에디터 메뉴 또는 인스펙터에서 `QL.IntroSeen` 지우기 (사람이 다시 볼 수 있게)
- Game 씬 쪽 (튜토리얼 · 카운트다운) 은 손대지 않음 — 그대로 이어짐
