## 이벤트
- 피격: `SlimeDamaged(SlimeView, int damage, DroneType source)` (V02 — `AttackLibrary.cs:64`, 드론 직접 공격만) → `source` 로 분기
- 상태: `SlimeCombat.SlowRate` · `Frozen` · `Burning` 읽기 (BurnFx 와 같은 방식 — 살아 있는 점액 목록 · LateUpdate)

## 이펙트
| 종류 | 맞은 순간 (0.3~0.5초) | 상태 (지속) |
|---|---|---|
| 흡입 (청록) | 점액 위 `FX_Suck_Swirl` 이 돌며 줄어듦 + `FX_Goo_Droplet` 3~5개가 **드론 방향으로** 뜯겨 날아감 · 점액 살짝 드론 쪽으로 늘어남 (Scale 펀치, 기존 히트 플래시와 겹쳐도 됨) | — |
| 소각 (주황) | `FX_Plasma_Burst` 짧게 펑 + `FX_Ember` 위로 튐 + `FX_Smoke_Puff` 회색 한 덩이 | 잔열 불꽃 = 기존 BurnFx 그대로 |
| 냉각 (하늘) | **`FX_Ice_Wave` 가 점액 발밑 바닥에서 고리로 퍼짐 (빙하 물결, 0.5초, 반경 점액 2배)** + `FX_Ice_Shard` 튐 | 감속 중: 발밑 `FX_Frost_Ground` + 점액 색 살짝 하늘색 (MPB) · 빙결 중: `FX_Ice_Crust` 덮음 · 풀릴 때 `FX_Ice_Shard` 깨짐 |
- 등급 3 은 크기 1.3배 · 입자 수 +50% (등급 구분 — 선택)
- 소각 부채꼴은 여러 마리 동시에 맞음 → 맞은 점액마다 나옴 (상한 아래)

## 성능 (필수 — 웨이브 3 대량)
- 전부 **풀링** (BurnFx · FxPool 방식) · 런타임 Instantiate 0 · 매 프레임 GC 할당 0
- 동시 상한 `FxConfig` (예: 종류별 피격 24 · 서리 원 32 · 얼음 껍질 16) — 넘치면 오래된 것부터 재사용
- 같은 점액 같은 종류 피격은 **0.15초 쿨다운** (흡입 고속 공격 도배 방지)
- 색 = MaterialPropertyBlock / 파티클 색 (재질 복제 X)
