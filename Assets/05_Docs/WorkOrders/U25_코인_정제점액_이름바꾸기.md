## 바꿀 곳 (사람에게 보이는 글자 · 그림만)
| 위치 | 지금 | 바뀐 뒤 |
|---|---|---|
| 오른쪽 위 HUD (`HudCoin`, UIRoot) | 코인 아이콘 + 숫자 | 「정제 점액」 라벨 + `UI_Icon_Refined` + 숫자 |
| DEPLOY 드론 투입 버튼 (`HudSummonButton`) | 코인 아이콘 + 비용 | `UI_Icon_Refined` + 비용 |
| 처치 연출 (`CoinFlyFx` · `FlyingCoin`) | 코인이 HUD 로 날아감 | 정제 점액 방울 (`FX_Refined_Drop` 또는 아이콘) 이 HUD 로 — 목적지 · 타이밍 그대로 |
| 튜토리얼 (`TutorialSteps`) | 「보급 코인」 · 「코인으로 드론을 투입」 | 「정제 점액」 — 처치한 점액이 정제돼 들어온다는 한 줄 |
| 결과 화면 (`ResultScreen` `bonusFormat`) | `+{0} 코인` | `+{0} 정제 점액` |
| 수당 영수증 (`PayslipReceipt`) · 지원 카드 설명 (`SupportCardInfo` · 카드 SO 설명문) · `SummonTypePicker` | 「코인」 | 「정제 점액」 (길면 「점액」) |
| 인트로 자막 6번 | 「보급 코인으로 빈 칸에…」 | 그대로 둠 (그림이 코인 — 나중 재작업 때) |

- 전체 검색 `코인` (UI · Data · 문구 SO · 프리팹 글자) → 사람에게 보이는 것만 바꿈. 주석 · 코드 이름은 그대로
- 글자가 길어져 박스를 넘으면 글자 크기 자동 맞춤 또는 줄임말 「점액」
