### 봐야 할 것
1. Windows 빌드(File > Build And Run)를 실행해 타이틀 화면에서 해상도 드롭다운으로 다른 크기를 고르고, 창 모드 토글을 켰다 껐다 해 본다. 창 크기가 고른 해상도로 바뀌고 토글에 따라 창 모드와 전체 화면이 실제로 바뀌면 통과다. (에디터에서는 `Screen.SetResolution` 이 동작하지 않아 사진으로 확인할 수 없다.)
2. 타이틀에서 시작을 눌러 게임에 들어간 뒤 웨이브 중에 Esc 키와 오른쪽 위 일시정지 버튼을 번갈아 눌러 본다. 누를 때마다 바로 멈추고 바로 다시 움직이며, 버튼을 누르는 순간 버튼 그림과 글자가 함께 살짝 내려가 눌리는 느낌이 있으면 통과다.
