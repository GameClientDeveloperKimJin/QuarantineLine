# F03 검증표 — T1 반영 연출 (R1 판정 대기)

캡처: Game.unity, Game 뷰 1920×1080 (p5 21:9 만 2560×1080), 게임 카메라 그대로. Unity MCP(HTTP)로 Play → `ScreenCapture.CaptureScreenshot`.
드론은 `Grid.Place` + `DroneBoard.SyncCell` 로 놓았다 (DroneSeeder 끔). 캡처 중 `DragController` 끔 (사람 입력 차단, 씬 저장 없음).
에디터가 포커스를 잃으면 Play 가 멈춰서 캡처하는 동안만 `Application.runInBackground = true` (런타임 값 — ProjectSettings 변경 없음, 끝나고 false). 포커스가 빠질 때 U12 휴게(Paused)로 들어가면 `HandleEscape` 로 되돌린 뒤 찍었다.
전 · 후 비교는 FxConfig 값을 런타임에 F01 값(전) / F03 값(후)으로 바꿔 같은 장면을 다시 만들었다 (전 · 후 모두 끝나고 F03 값으로 저장).
최종 판정은 R1 이 한다. 아래 「판단」은 내 판단이고 모두 **R1 판정 대기** 다.
