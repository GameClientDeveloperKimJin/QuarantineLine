## Enter 키 자체
- p2 캡처는 실제 키 대신 `RequestStartWave()` 를 불렀다. 에디터가 포커스 없는 상태에서 가상 키보드 이벤트가 Input System 에 들어가지 않았다.
- Enter 키 경로는 PlayMode 테스트 `GameLoopTests.EnterKey_InPrep_StartsWaveNow` 가 확인한다 (가상 키보드 Enter → 그 프레임 `GameLoop.Update` → 남은 시간 0 → 다음 Step 에 WaveStarted 1번). 통과.
- 실제 Enter 의 느낌은 🖐 항목에서 사람이 본다.
