# G15 전투맵 편집 안내

Game 씬의 전투맵은 「구운」 상태다. 씬에 실제 오브젝트로 놓여 있어서 Scene 뷰에서 바로 옮기고, 돌리고, 지우고, 복제할 수 있다. 고친 뒤 **Ctrl+S 로 씬을 저장**하면 Play 할 때 그 배치가 그대로 쓰인다.

## 어디를 고쳐도 되나

`[Stage]` 아래 묶음이 두 개 있다.

### `Editable` — 마음대로 고쳐도 된다 (초록 이름표)
| 묶음 | 내용 |
|---|---|
| `Walls` | 복도 좌우 벽 토막 (`WallPanel_L_*` · `_R_*`) |
| `Pipes` | 벽 안쪽 배관 토막 |
| `Crates` | 복도 옆 화물 상자 |
| `Outer/Deck` | 복도 바깥 격납고 데크 판 |
| `Outer/Stacks` | 복도 바깥 컨테이너 더미 (`_High` · `_Low`) |

옮기기 · 돌리기 · 크기 바꾸기 · 지우기 · 복제(Ctrl+D) 전부 된다. 묶음(`Walls` 등) 자체를 옮겨도 된다.

### `_Locked (수정 금지)` — 고치지 않는다 (빨간 이름표)
| 묶음 | 왜 안 되나 |
|---|---|
| `Cells` | 드론 칸. 마우스 판정은 좌표 계산(GridSpace)으로 하므로, 옮기면 보이는 칸과 실제로 놓이는 칸이 어긋난다 |
| `Lanes` · `LaneLines` | 레인 바닥 · 레인 구분 발광선. 점액이 다니는 길과 어긋난다 |
| `Hatch` · `Laser` · `Posts` | 격리선 턱 · 레이저 · 경고등 기둥. 점액이 막히는 줄과 어긋나고, 경고등 연출이 기둥을 찾는다 |
| `SpawnGate` · `SpawnLine` | 점액이 나오는 문. 점액이 문 밖 허공에서 나온다 |
| `Floor` | 복도 바닥 판. 판정 바닥 높이(y = 0)와 맞춰져 있다 |

바닥(Floor)은 위치 고정 — 재질만 바꿔도 됨.

여기를 옮겨도 게임 규칙은 그대로 돌지만 **겉모습만 어긋난다**. `_Locked` 묶음 자체를 옮기면 Play 때 콘솔에 경고가 뜬다.

## 새 소품 넣기

1. Project 창에서 `Assets/03_Prefabs/Game/Stage/` 를 연다
2. 프리팹을 Hierarchy 의 `[Stage]/Editable` 아래 (예: `Editable/Crates`) 로 끌어 놓는다
3. Scene 뷰에서 자리를 잡고 Ctrl+S

| 프리팹 | 무엇 |
|---|---|
| `Stage_Prop_Crate` | 화물 상자 |
| `Stage_Prop_Pipe` | 배관 토막 |
| `Stage_WallPanel` | 벽 토막 |
| `Stage_Outer_Deck` | 바깥 데크 판 (4×4 칸) |
| `Stage_Outer_StackHigh` · `Stage_Outer_StackLow` | 컨테이너 더미 (높음 · 낮음) |

- 같은 모양을 하나 더 원하면 기존 것을 선택하고 Ctrl+D 가 제일 쉽다 (색 B 재질도 그대로 따라온다)
- 소품에 Collider 를 붙이지 않는다. 프리팹에는 없다
- `Editable` 밖 (`[Stage]` 바로 아래나 `_Locked` 안) 에 넣지 않는다

## 되돌리는 법

- 방금 한 수정: Ctrl+Z
- 저장 안 한 것 전부: 씬을 저장하지 않고 다시 연다
- **처음 배치로 다시**: 메뉴 `Quarantine Line/전투맵 굽기` → 「다시 굽기」. 데이터 좌표대로 다시 구워지고, 고친 배치는 사라진다
- **굽기 전(런타임 생성)으로**: 메뉴 `Quarantine Line/전투맵 굽기 되돌리기`. 구운 오브젝트가 지워지고, Play 때마다 데이터로 만드는 예전 방식으로 돌아간다

둘 다 Ctrl+Z 로 취소할 수 있다. 결과를 남기려면 Ctrl+S 로 저장한다.

## 알아 둘 것

- Play 를 누르면 Hierarchy 에서 두 묶음 안의 오브젝트가 `[Stage]` 바로 아래로 나와 보인다. 연출 코드가 이름으로 찾기 때문이고 정상이다. Play 를 끝내면 원래대로 돌아온다
- 칸 수 · 레인 수 · 길이 (GameConfig) 를 바꾸면 메뉴로 다시 구워야 한다. 칸 수가 안 맞으면 Play 때 에러를 띄우고 그 실행만 생성 방식으로 대신한다
- Play 중에 고친 것은 저장되지 않는다 (Unity 기본 동작)
