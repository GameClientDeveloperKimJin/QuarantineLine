# O03 검증표 — 📷 사진 확인 (R1 판정 통과)

Unity MCP(HTTP)로 Game.unity 를 Play 하고 Game 뷰 1920×1080 에서 `ScreenCapture.CaptureScreenshot` 으로 찍었다.
Play 중에만 `GameLoop` · `DragController` 를 껐다 (준비 시간이 흐르지 않게 · 사람 입력 막기, 씬에 저장 안 함). 드론 10대를 `Grid.Place` + `DroneBoard.SyncAll` 로 놓고 `GameLoop.Step(0.05)` 로 웨이브 1 까지 진행했다.
트리거는 전부 진짜 경로다. 오염 = `SlimeRegistry.Spawn` + `Despawn(ReachedLine)` → `GameLoop.OnSlimeReachedHatch` 가 칸을 고름 (그 순간만 루프를 켬). 머지 청소 = `DragController.BeginAt` / `ReleaseAt` (MergeClean). 자연 마름 = `GameBootstrap.Update` 의 `Grid.Tick` (게임 시간) 뒤 `GameLoop.PublishNaturalCleans` → `CellCleaned(false)`.
시점은 `Time.captureDeltaTime = 1/60` 으로 게임 시간을 프레임마다 정확히 흘리고, `EditorApplication.update` 훅이 「트리거 뒤 t 초」 프레임에 `timeScale 0` 으로 세운 뒤 찍었다. 측정값은 그 프레임 값이다 (화면 px, 원점 왼쪽 아래).

## 다르게 한 곳 (지시서 대비)
1. **번짐 이징** — 「0.3 → 1.1 → 1.0 · 0.25초 OutBack」 을 두 구간으로: 0.3 → 1.1 (OutQuad, 앞 60%) → 1.0 (InOutSine). 꼭대기 1.1 을 정확히 맞추려는 것.
2. **청소 링 색** — 초록 → 흰 가산이지만, 같은 칸 U04 머지 이펙트(종류색 링 · 반짝임)와 겹쳐 캡처에서는 금색으로 보인다 (p3 0.13초). 🖐 에서 머지와 구분되는지 본다.
3. **웅덩이 색** — 그림(FX_Slime_Puddle)이 밝은 초록이라 그대로 두면 가산 종류색 링이 묻혀 안 보였다. 색을 (0.6, 0.7, 0.6) 으로 낮춰 링이 비치게 했다.
4. **타이머 위치** — 칸 앞쪽(카메라 쪽) 가장자리. 드론 몸체는 안 가리지만 아래 줄 드론 윗부분에 살짝 걸친다 (p1 「오염 4.0초」).
5. **판 시작 정리** — 지시서의 `GameStarted` 이벤트는 없어서 `WavePrepStarted(0)` · `GameEnded` 에서 전부 반납한다 (R1 승인). 판 재시작은 씬을 다시 읽는다.
6. **임시 판** — ContaminationView 는 끄지 않고 씬 값 `maxAlpha 0 · minAlpha 0` (R1 결정, 지시서 4번 변경).
