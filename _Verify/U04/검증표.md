# U04 검증표 — 📷 사진 확인 (R1 판정 대기)

Unity MCP 로 Game.unity Play · Game 뷰 1920×1080 (`PlayModeWindow.SetCustomRenderingResolution`) · 캡처 `ScreenCapture.CaptureScreenshot`.
연속 프레임은 **에디터를 일시정지하고 `EditorApplication.Step()` 으로 한 프레임씩** 넘겼다. 한 Step = 0.02초 × `Time.timeScale` 이라 timeScale 로 간격을 맞췄다 (0 = 시간 그대로 다시 그림, 2.5 = +0.05초, 5 = +0.1초, 14 = +0.28초).
배치는 `Grid.Place` + `DroneBoard.SyncCell` + `GameEvents.RaiseDroneSpawned`(리플렉션 — 실제 소환과 같은 이벤트), 머지는 `DragController.BeginAt` · `ReleaseAt` (실제 판정 · `DroneMerged`), 소환 팝은 `SummonController.RequestSummon`. 실제 마우스 · Space 가 끼어들지 않게 `DragController` · `SummonController` 컴포넌트는 껐다 (메서드 호출은 그대로 됨).
카메라 · 무대 · 드론 프리팹은 G07 그대로. 측정값은 Play 중 `execute_code` 로 각 뷰의 자식 `Model` (`localPosition` · `localScale`) 과 `FxPool.ActiveCount` 를 읽었다.

## 트윈 수 (누수 확인)
3웨이브 끝까지 (`GameLoop.Step(0.02)` 반복 + 자동 소환 · 머지, 코인 +3000 으로 승리까지): 시작 직후 `DOTween.TotalActiveTweens` **87** (이펙트 풀 60 + UI 27) → 웨이브 1 시작 96 → 웨이브 2 시작 139 → 웨이브 3 시작 142 → **끝 156 (+69)**. 결과 Victory · 처치 111 · 머지 13 · 소환 28 · 이펙트 재생 210 · 풀 생성 60 그대로.
늘어난 69 = 연출을 처음 받은 뷰마다 한 번 만든 트윈 (드론 뷰 17 × 호버 · 팝 · 머지 Sequence 최대 3 + 점액 뷰 21 × 출렁임 1). 기준 「이펙트 풀 60 + 뷰 38 = 98 이내」 안. 이벤트 수(재생 210)와 무관하게 뷰 수에서 멈춘다.
