# U05 검증표 — 📷 사진 확인 (R1 판정 대기)

Unity MCP(HTTP)로 Game.unity Play · Game 뷰 1920×1080 (`PlayModeWindow.SetCustomRenderingResolution`) · 캡처 `ScreenCapture.CaptureScreenshot`.
원하는 순간은 `EditorApplication.update` 에 조건 감시를 걸어 **그 프레임에 에디터 일시정지** → `EditorApplication.Step()` 으로 한 프레임씩 넘기며 찍었다 (Step 하나 = 0.02초 × `Time.timeScale`, 그래서 timeScale 0 = 같은 순간 다시 그림 · 5 = +0.1초).
배치: `Grid.Place` + `DroneBoard.SyncCell` — row0 소각 3등급 레인 1 · 3 (부채꼴 + 잔열), row1 흡입 2등급 레인 0 · 2 · 4, row2 흡입 1등급 레인 1 · 3. 실제 마우스 · Space 가 끼어들지 않게 `DragController` · `SummonController` 컴포넌트만 껐다 (씬 저장 없음). 웨이브 · 처치 · 보상은 실제 흐름 그대로 (`GameConfig.randomSeed` 고정이라 다시 하기마다 같은 순간이 재현된다).
측정값은 Play 중 `execute_code` 로 각 연출 컴포넌트의 공개 값(숫자 `anchoredPosition` · 대역 `localScale` · 코인 위치 · HudCoin `Shown/Target/Wallet` · 불꽃 위치)을 읽었다.
