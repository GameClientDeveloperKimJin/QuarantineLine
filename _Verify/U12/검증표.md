# U12 검증표 — 📷 사진 확인 (R1 판정 대기)

Unity MCP(HTTP)로 Game.unity Play · Game 뷰 해상도 `PlayModeWindow.SetCustomRenderingResolution` · 캡처 `ScreenCapture.CaptureScreenshot` (끝나고 1920×1080 으로 되돌림).
판: `Grid.Place` + `DroneBoard.SyncAll` 로 드론 8대 (흡입 · 소각 · 냉각, 1 · 2등급 번갈아) → `GameLoop.Step(0.05)` 로 웨이브 2 시작 → `timeScale 6` 으로 약 1초 실제로 흘림 (근무 시간이 0 이 아니게) → `GameLoop.HandleEscape()` (= Esc 와 같은 길). 실제 마우스 · Space 가 끼어들지 않게 `DragController` · `SummonController` 컴포넌트만 Play 중 껐다 (씬 저장 없음).

## 다르게 한 곳 (원본 · 시안 대비)
1. **어둡게 알파 0.6 → 0.85**: 프로젝트가 Linear 색 공간이라 검정 0.6 을 얹으면 화면 밝기가 sRGB 로 약 64% 남는다 (실측: 같은 자리 배경 픽셀 103 → 66). 시안의 「검정 60%」(밝기 40% 남음) 처럼 보이게 0.85 로 맞췄다 — `FxConfig.breakDimColor`
2. **카드 받침 `Backing` 한 장 유지**: `UI_Panel_Main` 알파 0.8 하나만이면 Linear 에서 뒤 무대(점액)가 제목 글자와 겹쳐 보였다 (첫 캡처). U01 반려와 같은 결함이라 받침 한 장을 남겼다 — 뒤 게임은 아주 흐리게만 보인다
3. **팁 줄 왼쪽 정렬 · 팁 9개 모두 24px 한 줄**: 시안은 작은 글자 가운데 정렬. 24px 규칙으로 글자 칸이 432px 라 문구를 그 안에 맞춰 썼다 (PlayMode 테스트가 모든 팁 폭 ≤ 칸 폭을 확인). 크로스페이드 때 「TIP」 이 흔들리지 않게 머리말을 따로 두고 본문만 왼쪽 정렬
4. **버튼 그림**: 시안의 둥근 알약 · 회색 테두리 대신 A08 키트 `UI_Button_Std` (보조 버튼은 `breakSecondaryTint` 회청색 틴트). 아이콘은 뺐다 (시안에 없음)
5. **커피잔 · 김 = 임시 그림** (`Assets/03_Prefabs/UI/Temp/UI_Cup.png` · `UI_Steam.png`, PIL 로 그림) — A12 납품 전. 점선 테두리 `Assets/03_Prefabs/UI/Sprites/UI_Frame_Dashed.png` (40×40 · Border 10 · Tiled) 도 직접 그렸다
6. **휴게 카드 전용 Canvas (정렬 30)**: 코인 비행 캔버스(정렬 20)가 timeScale 0 에 멈춘 채 카드 위로 보였다 (첫 캡처). 카드만 따로 정렬해 맨 위로
7. 블러 · 효과음 없음 (지시서 「바꾼 점」)
